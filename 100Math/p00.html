Phase 0 · Days 1–9 · Lessons 1–11

Number Sense & Algebraic Machinery

Phase 0 rebuilds the algebra that every later phase takes for granted, from the number systems and the rules they obey through divisibility, exponents and logarithms, factoring, partial fractions, inequalities, sums and the Binomial Theorem. It is the floor under Phase 1's functions and Phase 2's proofs: linear algebra, calculus and probability all assume these manipulations are fast, exact and checked.

By the end of this phase you can

  • Run the Euclidean algorithm, back-substitute for Bézout coefficients, and solve a linear congruence such as \(17x \equiv 3 \pmod{43}\).
  • Prove that \(\sqrt p\) is irrational for a prime \(p\), and find the supremum and infimum of a set, saying whether each is attained.
  • Simplify expressions with rational exponents and logarithms, solve exponential equations, and read a power law's exponent off a log-log plot.
  • Factor polynomials with the Rational Root Theorem and synthetic division, and decompose any proper rational function into partial fractions.
  • Solve radical, absolute-value and rational inequalities with sign charts, catching every extraneous root.
  • Prove the triangle, AM–GM, Cauchy–Schwarz and Bernoulli inequalities from a blank page and use them to bound expressions.
  • Evaluate arithmetic, geometric, power and telescoping sums in closed form, and extract any coefficient from a binomial expansion.

Course Map, Study Method & the Number Systems

32m video40m practice

Each number system was invented because the previous one could not solve some equation, and every later algebraic manipulation is a legal move only because of a short list of rules (closure, identity, inverse, associativity, commutativity, distributivity) that the system obeys.

What the prerequisites are, and in what order

"Mathematical prerequisites" means the mathematics that machine learning, statistics and quantitative work assume you already have. The phases are ordered by dependency, not by tradition.

Reading maths versus doing maths

Reading a proof means checking that each line follows from the last. Doing maths means producing those lines from a blank page. Only the second transfers to new problems, and the gap is invisible while you read, because every step looks obvious once it is in front of you.

Study method
  • Pause and try. Before any worked example is solved, stop and attempt it. A failed attempt makes the solution memorable; a passive viewing does not.
  • Index cards. One card per definition, theorem or technique: a prompt on the front ("State and prove the Factor Theorem"), the answer on the back. Review on a widening schedule (for instance after 1, 3, 7, 14 and 30 days), and move a card back to the start whenever you miss it.
  • Error log. For every mistake, write the problem, the wrong step, the correct step, and a category: concept, algebra slip, misread question, missing technique. Re-solve logged problems weekly; a few recurring slips (signs, dropped domain conditions) usually cause most lost marks.

The number system tower

$$\N \subset \Z \subset \Q \subset \R \subset \C.$$

Here \(\N = \{1, 2, 3, \dots\}\); some books include 0, so check each book's convention. Each extension exists because an equation with coefficients in the smaller system had no solution there.

  • \(\N \to \Z\): subtraction. \(x + 5 = 3\) has no solution in \(\N\). Adding zero and the negatives makes \(\Z\) closed under subtraction.
  • \(\Z \to \Q\): division. \(3x = 2\) has no integer solution. Fractions \(p/q\) with \(q \ne 0\) make division by nonzero numbers always possible.
  • \(\Q \to \R\): limits and roots. \(x^2 = 2\) has no rational solution (proved in L3), and sequences of rationals that settle down can converge to a gap. \(\R\) fills every gap.
  • \(\R \to \C\): \(\sqrt{-1}\). \(x^2 = -1\) has no real solution because real squares are non-negative. Adjoining \(i\) with \(i^2 = -1\) gives \(\C\), in which every polynomial equation has a root (L22).

The rules everything is built from

Definition

Properties of an operation \(\ast\) on a set \(S\).

  • Closure: \(a, b \in S \Rightarrow a \ast b \in S\).
  • Associativity: \((a \ast b) \ast c = a \ast (b \ast c)\) for all \(a, b, c \in S\).
  • Commutativity: \(a \ast b = b \ast a\) for all \(a, b\).
  • Identity: there is \(e \in S\) with \(a \ast e = e \ast a = a\) for every \(a\) (0 for \(+\), 1 for \(\times\)).
  • Inverse: for each \(a\) there is \(a' \in S\) with \(a \ast a' = a' \ast a = e\) (\(-a\) for \(+\); \(1/a\) for \(\times\), when \(a \ne 0\)).
  • Distributivity ties the two operations together: \(a(b + c) = ab + ac\).

In \(\Q\), \(\R\) and \(\C\) all of these hold for both operations (only 0 lacks a multiplicative inverse); such a system is a field. \(\Z\) lacks multiplicative inverses; \(\N\) also lacks 0 and additive inverses. Every step of "simplifying" is one of these rules: expanding \((x+1)(x+2)\) is repeated distributivity, and cancelling is multiplying by an inverse.

Worked example · closed under + but not −

Take \(\N\). If \(a, b \ge 1\) are whole numbers then \(a + b\) is a whole number \(\ge 2\), so \(\N\) is closed under \(+\). But \(3 - 5 = -2 \notin \N\). One counterexample is enough to destroy closure; proving closure needs an argument that covers every pair.

Worked example

\(\Q\) is closed under ÷ but not under limits.

Division. If \(b, c, d \ne 0\) then \(\frac{a}{b} \div \frac{c}{d} = \frac{ad}{bc}\), a ratio of integers with \(bc \ne 0\). So \(\Q\) is closed under division by nonzero rationals.

Limits. The truncated decimals \(1,\ 1.4,\ 1.41,\ 1.414,\ 1.4142, \dots\) are each rational (\(1.414 = 1414/1000\)). The \(n\)-th one is within \(10^{-n}\) of \(\sqrt 2\), so the sequence converges to \(\sqrt 2\), which is not rational (L3). Another rational sequence does the same much faster: \(x_1 = 1\), \(x_{k+1} = \tfrac12\big(x_k + 2/x_k\big)\) gives \(1,\ \tfrac32,\ \tfrac{17}{12},\ \tfrac{577}{408} \approx 1.4142157\). Rationals can approach a point that is not a rational: \(\Q\) has holes, and \(\R\) is \(\Q\) with the holes filled.

Common errors
  • \(\in\) versus \(\subseteq\). \(1 \in \{1, 2\}\) and \(\{1\} \subseteq \{1, 2\}\), but "\(1 \subseteq \{1,2\}\)" is meaningless: 1 is not a set of numbers.
  • Reading \(\Rightarrow\) as \(\Leftrightarrow\). \(x = 2 \Rightarrow x^2 = 4\) is true; the converse is false. Most invalid algebra (squaring both sides, L8) is this mistake.
  • Proving closure with examples. "\(2 + 4 = 6\) is even" checks one pair. Closure is a claim about all pairs and needs a general argument.
  • Forgetting zero. \(\Q\) is closed under division only by nonzero elements; \(\Q \setminus \{0\}\) is closed under \(\div\).

Practice · 40 min

  1. Prove it. The set of even integers \(E = \{2k : k \in \Z\}\) is closed under \(+\) and \(\times\), but not under \(\div\). Hint: write two arbitrary elements as \(2a\) and \(2b\) and factor a 2 out of the result; for \(\div\), one counterexample suffices.
    Proof sketch

    Let \(x = 2a\), \(y = 2b\) with \(a, b \in \Z\). Then \(x + y = 2(a + b)\) and \(xy = 2(2ab)\), and \(a + b\) and \(2ab\) are integers because \(\Z\) is closed under \(+\) and \(\times\). So both lie in \(E\). For division: \(2, 2 \in E\) but \(2 \div 2 = 1\) is odd, and \(2 \div 4 = \tfrac12\) is not even an integer. (Also \(2 \div 0\) is undefined.)

  2. Decide closure, with a proof or a counterexample: (a) odd integers under \(+\) and under \(\times\); (b) \(\{-1, 0, 1\}\) under \(\times\); (c) the irrationals under \(+\); (d) the positive rationals under \(\div\).
    Answer

    (a) Not under \(+\): \(1 + 1 = 2\). Under \(\times\) yes: \((2a+1)(2b+1) = 2(2ab + a + b) + 1\). (b) Yes; check the nine products. (c) No: \(\sqrt2 + (-\sqrt2) = 0\). (d) Yes: \(\frac{a}{b} \div \frac{c}{d} = \frac{ad}{bc}\) with all four positive.

  3. Read aloud, then decide true or false: (a) \(\forall x \in \R\ \exists y \in \R:\ y > x\); (b) \(\exists y \in \R\ \forall x \in \R:\ y > x\).
    Answer

    (a) "For every real \(x\) there is a real \(y\) larger than \(x\)": true, take \(y = x + 1\). (b) "There is a real \(y\) larger than every real \(x\)": false, since \(x = y\) is a counterexample. Swapping the quantifiers changes the meaning.

  4. On \(\Z\) define \(a \ast b = a + b - 1\). Is \(\ast\) closed, associative and commutative? Find its identity element and the inverse of \(a\).
    Answer

    Closed, and commutative. Associative: both \((a \ast b) \ast c\) and \(a \ast (b \ast c)\) equal \(a + b + c - 2\). Identity: \(a + e - 1 = a\) gives \(e = 1\). Inverse: \(a + a' - 1 = 1\) gives \(a' = 2 - a\).

  5. Show that \(\C\) cannot be ordered so that the product of two positive numbers is positive. Hint: \(i \ne 0\), so either \(i\) or \(-i\) would have to be positive.
    Answer

    If \(i > 0\) then \(i \cdot i = -1 > 0\). If \(-i > 0\) then \((-i)(-i) = -1 > 0\). Either way \(-1 > 0\). But then \(1 = (-1)(-1) > 0\) too, and an order allows exactly one of \(x\), \(-x\) to be positive for each \(x \ne 0\): a contradiction.

L2 · DAY 2

Integers, Divisibility & Modular Arithmetic

38m video50m practiceheavy lesson

Almost all of elementary number theory flows from one fact: the remainder in a division is smaller than the divisor. That gives the Euclidean algorithm, Bézout's identity, unique prime factorization, and modular inverses, in that order.

Divisibility and the Division Algorithm

Definition

For integers \(a, b\), \(a \mid b\) ("\(a\) divides \(b\)") means \(b = ak\) for some \(k \in \Z\). Properties: \(a \mid a\); if \(a \mid b\) and \(b \mid c\) then \(a \mid c\); if \(a \mid b\) and \(b \ne 0\) then \(|a| \le |b|\); if \(a \mid b\) and \(b \mid a\) then \(a = \pm b\); and if \(d \mid a\), \(d \mid b\) then \(d \mid ax + by\) (the Prove it below).

Theorem · Division Algorithm

For \(a \in \Z\) and \(b > 0\) there are unique integers \(q, r\) with \(a = bq + r\) and \(0 \le r < b\).

Proof

Existence. \(S = \{a - bk : k \in \Z,\ a - bk \ge 0\}\) is non-empty (take \(k = -|a|\)), so by well-ordering it has a least element \(r = a - bq \ge 0\). If \(r \ge b\), then \(r - b = a - b(q+1)\) is a smaller element of \(S\), a contradiction. So \(0 \le r < b\).

Uniqueness. If \(bq + r = bq' + r'\) with both remainders in \([0, b)\), then \(b(q - q') = r' - r\). The right side has absolute value below \(b\) and is a multiple of \(b\), so it is 0. Hence \(r = r'\) and \(q = q'\).

Primes and the Fundamental Theorem of Arithmetic

An integer \(p \ge 2\) is prime if its only positive divisors are 1 and \(p\); an integer \(n \ge 2\) that is not prime is composite. (1 is neither.)

Theorem · Fundamental Theorem of Arithmetic

Every \(n \ge 2\) is a product of primes, and this factorization is unique up to the order of the factors.

Proof sketch

Existence (strong induction): if \(n\) is prime we are done; otherwise \(n = ab\) with \(1 < a, b < n\), and both factor by hypothesis. Uniqueness rests on Euclid's lemma: if a prime \(p\) divides \(ab\), then \(p \mid a\) or \(p \mid b\) (proved below from Bézout). If \(p_1 \cdots p_k = q_1 \cdots q_l\), then \(p_1\) divides some \(q_j\), so \(p_1 = q_j\); cancel it and induct on \(k\).

Theorem · Euclid: there are infinitely many primes

Suppose \(p_1, \dots, p_k\) were all the primes. Let \(N = p_1 p_2 \cdots p_k + 1\). \(N \ge 2\) has a prime factor \(p_i\), which divides both \(N\) and \(p_1 \cdots p_k\), hence divides their difference 1. Impossible.

GCD, LCM and the Euclidean Algorithm

\(\gcd(a, b)\) is the largest integer dividing both; \(\operatorname{lcm}(a, b)\) the smallest positive integer both divide. Writing \(a = \prod p^{\alpha_p}\) and \(b = \prod p^{\beta_p}\), \(\gcd = \prod p^{\min(\alpha_p, \beta_p)}\) and \(\operatorname{lcm} = \prod p^{\max(\alpha_p, \beta_p)}\). Since \(\min + \max = \alpha_p + \beta_p\) for every prime, \(\gcd(a,b)\cdot\operatorname{lcm}(a,b) = ab\) for positive \(a, b\).

Algorithm · Euclid
  1. Given \(a \ge b > 0\), divide: \(a = bq + r\) with \(0 \le r < b\).
  2. If \(r = 0\), return \(b\). Otherwise replace \((a, b)\) by \((b, r)\) and repeat.

It works because \(\gcd(a, b) = \gcd(b, r)\): any common divisor of \(a, b\) divides \(r = a - bq\), and any common divisor of \(b, r\) divides \(a = bq + r\). The remainders strictly decrease, so it stops.

Worked example

\(\gcd(1071, 462)\).

$$1071 = 2 \cdot 462 + 147, \qquad 462 = 3 \cdot 147 + 21, \qquad 147 = 7 \cdot 21 + 0.$$

The last nonzero remainder is \(\gcd = 21\). Check: \(1071 = 21 \cdot 51\), \(462 = 21 \cdot 22\), and \(\gcd(51, 22) = 1\). So \(\operatorname{lcm} = 1071 \cdot 462 / 21 = 23{,}562\).

Bézout's identity and the extended algorithm

Theorem · Bézout

For integers \(a, b\) not both 0, there are integers \(x, y\) with \(ax + by = \gcd(a, b)\). Moreover \(\gcd(a,b)\) is the smallest positive integer of the form \(ax + by\).

Proof

Let \(d\) be the least positive value of \(ax + by\). Divide: \(a = qd + r\), \(0 \le r < d\). Then \(r = a - q(ax + by) = a(1 - qx) + b(-qy)\) is also of that form and is smaller than \(d\), so \(r = 0\) and \(d \mid a\). Likewise \(d \mid b\). Any common divisor of \(a, b\) divides \(ax + by = d\), so \(d\) is the greatest.

Euclid's lemma follows. If \(p \mid ab\) and \(p \nmid a\), then \(\gcd(p, a) = 1\), so \(1 = px + ay\). Multiply by \(b\): \(b = pbx + (ab)y\). \(p\) divides both terms, so \(p \mid b\).

To find \(x, y\) in practice, run Euclid and substitute backwards, expressing each remainder in terms of \(a\) and \(b\). This is the extended Euclidean algorithm.

Congruence and arithmetic in \(\Z_n\)

Definition

\(a \equiv b \pmod n\) means \(n \mid a - b\). It is an equivalence relation: reflexive (\(n \mid 0\)), symmetric (\(n \mid a-b \Rightarrow n \mid b-a\)), transitive (\(a - c = (a-b) + (b-c)\)). Its classes \(\{[0], [1], \dots, [n-1]\}\) form \(\Z_n\).

Congruence respects \(+\) and \(\times\): if \(a \equiv a'\) and \(b \equiv b'\), then \(ab - a'b' = a(b - b') + b'(a - a')\) is a multiple of \(n\). So you may reduce mod \(n\) at any stage of a computation. Division is the exception.

Theorem · modular inverses

\(a\) has an inverse mod \(n\) (some \(x\) with \(ax \equiv 1\)) if and only if \(\gcd(a, n) = 1\). Hence every nonzero element of \(\Z_p\) is invertible when \(p\) is prime.

Proof. \(ax \equiv 1 \pmod n\) iff \(ax + ny = 1\) for some \(y\). If such \(x, y\) exist, \(\gcd(a,n)\) divides 1. Conversely, Bézout produces them when the gcd is 1.

Worked example

Solve \(17x \equiv 3 \pmod{43}\).

Euclid: \(43 = 2\cdot17 + 9\), \(17 = 1\cdot 9 + 8\), \(9 = 1 \cdot 8 + 1\). Back-substitute:

$$1 = 9 - 8 = 9 - (17 - 9) = 2\cdot 9 - 17 = 2(43 - 2\cdot17) - 17 = 2\cdot 43 - 5\cdot 17.$$

So \(17 \cdot (-5) \equiv 1\), and \(17^{-1} \equiv -5 \equiv 38 \pmod{43}\). Multiply both sides of the equation by it: \(x \equiv 3 \cdot 38 = 114 \equiv 28 \pmod{43}\). Check: \(17 \cdot 28 = 476 = 11 \cdot 43 + 3\).

Fermat's Little Theorem and Euler's totient

Theorem · Fermat, Euler

Fermat. If \(p\) is prime and \(p \nmid a\), then \(a^{p-1} \equiv 1 \pmod p\).

Euler. Let \(\varphi(n)\) count the integers in \(\{1, \dots, n\}\) coprime to \(n\); then \(\varphi(n) = n\prod_{p \mid n}(1 - 1/p)\). If \(\gcd(a, n) = 1\), then \(a^{\varphi(n)} \equiv 1 \pmod n\). Fermat is the case \(n = p\), \(\varphi(p) = p - 1\).

Why Fermat holds: multiplying the residues \(1, 2, \dots, p-1\) by \(a\) permutes them (multiplication by an invertible element is injective). Comparing products, \(a^{p-1}(p-1)! \equiv (p-1)!\), and \((p-1)!\) is invertible mod \(p\), so it cancels.

Worked example

\(7^{100} \bmod 13\).

13 is prime and \(13 \nmid 7\), so \(7^{12} \equiv 1\). Since \(100 = 12 \cdot 8 + 4\), \(7^{100} = (7^{12})^8 \cdot 7^4 \equiv 7^4\). Now \(7^2 = 49 \equiv 10\) and \(7^4 \equiv 10^2 = 100 \equiv 9\). So \(7^{100} \equiv 9 \pmod{13}\).

Common errors
  • \(a \mid b\) is a statement, \(a/b\) is a number. \(3 \mid 12\) is true; "\(3 \mid 12 = 4\)" is nonsense.
  • Euclid's \(N\) need not be prime. \(2\cdot3\cdot5\cdot7\cdot11\cdot13 + 1 = 30031 = 59 \cdot 509\). The proof only needs \(N\) to have a prime factor outside the list.
  • Cancelling in a congruence. \(2x \equiv 2 \pmod 4\) has solutions \(x \equiv 1\) and \(x \equiv 3\). You may cancel \(c\) only when \(\gcd(c, n) = 1\).
  • Reducing exponents mod \(p\). Fermat lets you reduce exponents mod \(p - 1\), not mod \(p\), and only when \(p \nmid a\).
  • Negative remainders. In the division algorithm \(-7 = 3\cdot(-3) + 2\), so \(-7 \bmod 3 = 2\), not \(-1\).

Practice · 50 min

  1. Prove it. If \(d \mid a\) and \(d \mid b\), then \(d \mid ax + by\) for all integers \(x, y\). Hint: unpack the definition of \(\mid\) into equations.
    Proof sketch

    Write \(a = dm\) and \(b = dn\) with \(m, n \in \Z\). Then \(ax + by = d(mx + ny)\), and \(mx + ny \in \Z\), so \(d \mid ax + by\). This one line powers Euclid's algorithm, Bézout and the inverse theorem above.

  2. Find \(\gcd(252, 198)\), integers \(x, y\) with \(252x + 198y = \gcd\), and \(\operatorname{lcm}(252, 198)\).
    Answer

    \(252 = 198 + 54\), \(198 = 3\cdot54 + 36\), \(54 = 36 + 18\), \(36 = 2\cdot 18\): gcd 18. Back: \(18 = 54 - 36 = 4\cdot54 - 198 = 4\cdot252 - 5\cdot198\). lcm \(= 252\cdot198/18 = 2772\).

  3. Which of 6 and 7 has an inverse mod 15? Find it.
    Answer

    \(\gcd(6, 15) = 3\), so 6 has none. \(\gcd(7, 15) = 1\); \(7 \cdot 13 = 91 = 6\cdot 15 + 1\), so \(7^{-1} \equiv 13\).

  4. Compute \(3^{200} \bmod 7\) and the last two digits of \(7^{40}\).
    Answer

    \(3^6 \equiv 1 \pmod 7\), \(200 = 6\cdot33 + 2\), so \(3^{200} \equiv 9 \equiv 2\). \(\varphi(100) = 100\cdot\tfrac12\cdot\tfrac45 = 40\) and \(\gcd(7, 100) = 1\), so \(7^{40} \equiv 1 \pmod{100}\): last two digits 01.

  5. Show that \(\gcd(n, n+1) = 1\) for every integer \(n\), and deduce that consecutive integers share no prime factor.
    Answer

    Any common divisor divides \((n+1) - n = 1\) by the Prove it with \(x = -1\), \(y = 1\).

L3 · DAY 2

Rationals, Irrationals & the Structure of the Real Line

24m video30m practiceheavy lesson

The rationals are dense, so they crowd every interval, yet they are full of holes such as \(\sqrt 2\). The real numbers are defined by having no holes, and the precise statement of "no holes", the Completeness Axiom, is what makes limits and calculus possible.

Rationals as classes of integer pairs

Definition

On pairs \((a, b)\) of integers with \(b \ne 0\), set \((a, b) \sim (c, d)\) iff \(ad = bc\). This is an equivalence relation, and the rational number \(a/b\) is the class of \((a, b)\): \(\tfrac12\), \(\tfrac24\) and \(\tfrac{-3}{-6}\) are three names for one number.

Transitivity is the only step needing care: from \(ad = bc\) and \(cf = de\), multiply to get \(adf = bcf = bde\), so \(d(af - be) = 0\), and \(d \ne 0\) gives \(af = be\). Because a number has many names, every operation must give the same answer whichever name you use (it must be well defined); \(\frac ab + \frac cd = \frac{ad + bc}{bd}\) is. Each class has exactly one name in lowest terms, \(\gcd(a, b) = 1\) with \(b > 0\): divide by the gcd. Uniqueness: if \(a/b = c/d\) are both reduced, \(ad = bc\) gives \(b \mid ad\) with \(\gcd(a,b) = 1\), so \(b \mid d\); symmetrically \(d \mid b\), hence \(b = d\) and \(a = c\).

Terminating and repeating decimals

Theorem · decimal expansions of rationals

(i) A reduced fraction \(p/q\) has a terminating decimal iff the prime factors of \(q\) lie in \(\{2, 5\}\). (ii) Every rational has an eventually repeating decimal, and every eventually repeating decimal is rational.

Proof

(i) Terminating means \(p/q = m/10^k\), i.e. \(p \cdot 10^k = mq\). Then \(q \mid p\cdot 10^k\) with \(\gcd(p, q) = 1\), so \(q \mid 10^k = 2^k 5^k\). Conversely, if \(q = 2^a 5^b\), multiply top and bottom by \(5^{a-b}\) or \(2^{b-a}\) to get denominator \(10^{\max(a,b)}\).

(ii) Long division of \(p\) by \(q\) produces remainders in \(\{0, 1, \dots, q-1\}\). Within \(q\) steps a remainder repeats, and from then on the digits repeat. The converse is the shifting trick below.

Worked example

\(0.\overline{45} = 5/11\).

Let \(x = 0.454545\ldots\). The block has length 2, so multiply by \(10^2\): \(100x = 45.4545\ldots\). Subtract: \(99x = 45\), so \(x = \tfrac{45}{99} = \tfrac{5}{11}\). With a non-repeating prefix, shift twice: for \(x = 0.1\overline{6}\), \(100x - 10x = 16.\overline{6} - 1.\overline{6} = 15\), so \(x = \tfrac{15}{90} = \tfrac16\).

Irrational numbers

Theorem

\(\sqrt 2 \notin \Q\).

There are no integers \(p, q\) with \(q \ne 0\) and \((p/q)^2 = 2\).

Proof by contradiction

Suppose \(\sqrt2 = p/q\) in lowest terms. Then \(p^2 = 2q^2\), so \(p^2\) is even. Then \(p\) is even, because an odd \(p = 2k+1\) has odd square \(4k^2 + 4k + 1\). Write \(p = 2k\): \(4k^2 = 2q^2\), so \(q^2 = 2k^2\) and \(q\) is even too. Both even contradicts lowest terms.

The same pattern works for \(\sqrt p\) with \(p\) prime, using Euclid's lemma from L2 (\(p \mid n^2 \Rightarrow p \mid n\)). Two famous constants are also irrational, though the proofs need calculus: \(e\) (Euler, 18th century) and \(\pi\) (Lambert, 1760s). Irrationals are exactly the reals whose decimals never become periodic.

Bounds, supremum, infimum and completeness

Definition

Let \(S \subseteq \R\). \(u\) is an upper bound if \(s \le u\) for all \(s \in S\). The supremum \(\sup S\) is the least upper bound: an upper bound \(u\) such that no smaller number is an upper bound, i.e. for every \(\varepsilon > 0\) some \(s \in S\) has \(s > u - \varepsilon\). Lower bound and infimum \(\inf S\) are the mirror images. If \(\sup S \in S\), it is the maximum.

Axiom · Completeness

Every non-empty subset of \(\R\) that is bounded above has a supremum in \(\R\).

\(\Q\) satisfies every algebraic and order rule \(\R\) does, so this axiom is the only thing that separates them. In \(\Q\) it fails: \(S = \{x \in \Q : x > 0,\ x^2 < 2\}\) is bounded above, but for any rational upper bound \(u\) (so \(u^2 > 2\)), \(u' = \tfrac12(u + 2/u)\) is a smaller rational with \(u'^2 - 2 = \tfrac14(u - 2/u)^2 > 0\), still an upper bound. No rational is least; the supremum \(\sqrt 2\) exists only in \(\R\).

Theorem

\(\Q\) is dense in \(\R\).

For reals \(a < b\) there is a rational \(q\) with \(a < q < b\).

Proof. By the Archimedean property (a consequence of completeness: \(\N\) is not bounded above), pick \(n \in \N\) with \(1/n < b - a\). Let \(m\) be the least integer with \(m > na\), so \(m - 1 \le na < m\). Then \(a < m/n \le a + 1/n < b\).

Worked example

\(S = \{1/n : n \in \N\}\).

Sup. Every \(1/n \le 1\), and \(1 \in S\). So \(\sup S = 1\), attained: it is the maximum.

Inf. 0 is a lower bound since every \(1/n > 0\). Nothing larger is: given \(\varepsilon > 0\), choose \(n > 1/\varepsilon\); then \(1/n < \varepsilon\), so \(\varepsilon\) is not a lower bound. Hence \(\inf S = 0\), and it is not attained, because \(0 \ne 1/n\) for every \(n\). \(S\) has no minimum.

Interval notation

\((a, b) = \{x : a < x < b\}\) is open; \([a, b] = \{x : a \le x \le b\}\) is closed; \([a, b)\) and \((a, b]\) are half-open. Unbounded intervals \((a, \infty)\), \([a, \infty)\), \((-\infty, b]\) and \(\R = (-\infty, \infty)\) always use a round bracket at \(\pm\infty\), which is a direction, not a number. A closed bounded interval contains its sup and inf; an open one contains neither.

Common errors
  • \(0.\overline{9} \ne 1\). It equals 1: \(10x - x = 9.\overline9 - 0.\overline9 = 9\) gives \(x = 1\). Two different decimals can name one real.
  • "Irrational plus irrational is irrational." False: \(\sqrt2 + (-\sqrt2) = 0\) and \(\sqrt2 \cdot \sqrt2 = 2\). Rational plus irrational is irrational.
  • Applying the \(\{2, 5\}\) test to an unreduced fraction. \(3/12\) terminates (it is \(1/4\)) even though \(12\) has the factor 3.
  • Assuming \(\sup S \in S\). It need not be; when it is, call it a maximum.
  • Skipping "\(p^2\) even \(\Rightarrow p\) even". This is the step that carries the proof and the step that fails for \(\sqrt 4\).

Practice · 30 min

  1. Prove it. \(\sqrt 3\) is irrational. Then explain exactly where the same argument breaks for \(\sqrt 4\). Hint: you need "\(3 \mid p^2 \Rightarrow 3 \mid p\)"; justify it by cases on \(p \bmod 3\) or by Euclid's lemma.
    Proof sketch

    Suppose \(\sqrt3 = p/q\) in lowest terms, so \(p^2 = 3q^2\) and \(3 \mid p^2\). If \(p \equiv \pm1 \pmod 3\) then \(p^2 \equiv 1\), so \(3 \mid p\). Write \(p = 3k\): \(9k^2 = 3q^2\), so \(q^2 = 3k^2\) and \(3 \mid q\). Contradiction. For \(\sqrt4\): \(p^2 = 4q^2\) gives \(4 \mid p^2\), but \(4 \mid p^2\) does not imply \(4 \mid p\) (take \(p = 2\)). The step needs a prime, and 4 is not prime; indeed \(p/q = 2/1\) is a genuine solution.

  2. Write \(1.2\overline{3}\) as a reduced fraction, and decide which terminate: \(7/40\), \(3/48\), \(11/12\), \(21/60\).

    \(100x - 10x = 123.\overline3 - 12.\overline3 = 111\), so \(x = 111/90 = 37/30\). \(7/40\) yes (\(40 = 2^3 \cdot 5\)); \(3/48 = 1/16\) yes; \(11/12\) no; \(21/60 = 7/20\) yes (0.35).

    \(x = a + (b - a)/\sqrt2\) lies in \((a, b)\) because \(0 < 1/\sqrt2 < 1\). If \(x\) were rational, \(\sqrt2 = (b - a)/(x - a)\) would be rational.

Exponents, Radicals & Orders of Magnitude

26m video40m practiceheavy lesson

Exponent laws are bookkeeping for repeated multiplication. Zero, negative and fractional exponents are not new ideas but the only definitions that keep those laws true, and the laws in turn tell you which quantities dwarf which.

The seven laws, from counting factors

For \(n \in \N\), \(a^n := a \cdot a \cdots a\) (\(n\) factors). Every law below is a statement about counting those factors.

LawWhy
\(a^m a^n = a^{m+n}\)\(m\) factors followed by \(n\) more is \(m + n\) factors
\(a^m / a^n = a^{m-n}\) (\(a \ne 0\))for \(m > n\), \(n\) factors cancel and \(m - n\) remain
\((a^m)^n = a^{mn}\)\(n\) blocks of \(m\) factors
\((ab)^n = a^n b^n\)reorder \(abab\cdots ab\) (commutativity)
\((a/b)^n = a^n / b^n\) (\(b \ne 0\))same, with \(1/b\) in place of \(b\)
\(a^0 = 1\) (\(a \ne 0\))forced, see below
\(a^{-n} = 1/a^n\) (\(a \ne 0\))forced, see below
Derivation · zero and negative exponents are forced

"\(a\) multiplied by itself zero times" has no meaning, so we are free to choose. If we want the first law to keep holding, there is only one choice: \(a^0 \cdot a^n = a^{0+n} = a^n\), and dividing by \(a^n \ne 0\) gives \(a^0 = 1\). Then \(a^{-n} \cdot a^n = a^0 = 1\) forces \(a^{-n} = 1/a^n\). With these definitions all five laws hold for every integer exponent, and the quotient law no longer needs \(m > n\).

Rational exponents and radicals

Push the same idea one step further. If \((a^{1/n})^n = a^{(1/n)\cdot n} = a\) is to hold, then \(a^{1/n}\) must be an \(n\)-th root of \(a\). For \(a > 0\) we take the unique positive one, \(a^{1/n} := \sqrt[n]{a}\), and define

$$a^{m/n} := \big(\sqrt[n]{a}\big)^m = \sqrt[n]{a^m} \qquad (a > 0,\ n \in \N,\ m \in \Z).$$

The two forms agree because both are positive numbers whose \(n\)-th power is \(a^m\), and a positive \(n\)-th root is unique (\(t \mapsto t^n\) is strictly increasing on \((0, \infty)\)). That same uniqueness is what the Prove it below needs. With \(a, b > 0\), all seven laws hold for rational exponents.

Techniques · radicals
  • Simplify by pulling out perfect powers: \(\sqrt{72} = \sqrt{36 \cdot 2} = 6\sqrt2\); \(\sqrt[3]{54} = 3\sqrt[3]{2}\).
  • Denest \(\sqrt{a + 2\sqrt b} = \sqrt x + \sqrt y\) when \(x + y = a\) and \(xy = b\) (square the right side to check). Example: \(\sqrt{5 + 2\sqrt6} = \sqrt3 + \sqrt2\); \(\sqrt{7 - 4\sqrt3} = \sqrt{7 - 2\sqrt{12}} = 2 - \sqrt3\).
  • Rationalize a denominator: \(\frac{1}{\sqrt a} = \frac{\sqrt a}{a}\); for a binomial surd multiply by the conjugate, since \((\sqrt p - \sqrt q)(\sqrt p + \sqrt q) = p - q\) has no roots.
Worked example

Simplify \((8x^6y^{-3})^{2/3}\), with \(x, y > 0\).

Distribute the power over the product (law 4), then multiply exponents (law 3):

$$(8x^6y^{-3})^{2/3} = 8^{2/3}\,(x^6)^{2/3}\,(y^{-3})^{2/3} = \big(\sqrt[3]{8}\big)^2 x^{4} y^{-2} = \frac{4x^4}{y^2}.$$
Worked example

Rationalize \(\dfrac{1}{\sqrt5 - \sqrt2}\).

$$\frac{1}{\sqrt5 - \sqrt2}\cdot\frac{\sqrt5 + \sqrt2}{\sqrt5 + \sqrt2} = \frac{\sqrt5 + \sqrt2}{5 - 2} = \frac{\sqrt5 + \sqrt2}{3}.$$

Scientific notation and orders of magnitude

Write a positive number as \(a \times 10^k\) with \(1 \le a < 10\) and \(k \in \Z\); \(k\) is roughly its order of magnitude. Multiplying multiplies the mantissas and adds the exponents, so estimates become arithmetic on small integers. A year is about \(3.15 \times 10^7\) seconds (a handy mnemonic: \(\pi \times 10^7\)). A model with \(7 \times 10^9\) parameters stored at 2 bytes each needs \(1.4 \times 10^{10}\) bytes, about 14 GB. Getting the exponent right matters far more than the second digit: an estimate that is off by a factor of 2 is useful, one that is off by \(10^3\) is not.

Comparing growth

For large \(n\), and any fixed \(k > 0\), \(b > 1\):

$$\log n \ \ll\ n^k \ \ll\ b^n \ \ll\ n! \ \ll\ n^n,$$

where \(f \ll g\) means \(f(n)/g(n) \to 0\). The ratio test of consecutive terms explains each step. For \(n^k / b^n\) the ratio of successive terms is \(\big(\tfrac{n+1}{n}\big)^k \cdot \tfrac1b \to \tfrac1b < 1\), so eventually each term is less than a fixed fraction of the previous one and the sequence collapses geometrically. For \(b^n / n!\) the ratio is \(b/(n+1) \to 0\). For \(n!/n^n = \prod_{j=1}^{n} (j/n) \le 1/n\). And \(\log n\) against \(n^k\) is the polynomial-versus-exponential comparison again after substituting \(n = e^t\).

Worked example

Rank \(n^2,\ 2^n,\ n\log n,\ n!,\ \sqrt n\).

By the hierarchy: \(\sqrt n \ll n\log n \ll n^2 \ll 2^n \ll n!\). (\(\sqrt n = n^{1/2}\) and \(n \log n\) sits between \(n^1\) and \(n^{1+\varepsilon}\).) Numbers confirm it, though small \(n\) can mislead:

Common errors
  • Exponents do not distribute over sums. \((a + b)^2 \ne a^2 + b^2\) and \(\sqrt{a^2 + b^2} \ne a + b\).
  • \(-3^2 = -9\), but \((-3)^2 = 9\): the exponent binds tighter than the minus sign. Likewise \(2^{3^2} = 2^9\), not \(8^2\).
  • Negative bases with fractional exponents. \((-8)^{1/3} = -2\) as a real cube root, but \((-8)^{2/6} = \sqrt[6]{64} = 2\), although \(1/3 = 2/6\). This is why \(a^{m/n}\) is defined only for \(a > 0\).
  • \(a^{-1/2}\) is \(1/\sqrt a\), not \(-\sqrt a\). A negative exponent means reciprocal, never a negative number.
  • Trusting small \(n\). \(n^{100} > 1.01^n\) until \(n\) is about \(1.2 \times 10^5\); "eventually" can be very far away.

Logarithms

30m video40m practiceheavy lesson

A logarithm answers "what power?". Because it is the inverse of exponentiation it turns products into sums and powers into multiples, and that single property is why log scales linearize power laws and why statistics maximizes log-likelihood instead of likelihood.

Definition and graph

Definition

For a base \(b > 0\), \(b \ne 1\), and \(x > 0\): \(\ \log_b x = y \iff b^y = x\).

So \(\log_b\) is the inverse function of \(y \mapsto b^y\): \(b^{\log_b x} = x\) for \(x > 0\), and \(\log_b(b^y) = y\) for every real \(y\). Domain \((0, \infty)\), range \(\R\), \(\log_b 1 = 0\), \(\log_b b = 1\). For \(b > 1\) it is increasing, with \(\log_b x \to -\infty\) as \(x \to 0^+\): the line \(x = 0\) is a vertical asymptote. For \(0 < b < 1\) it is decreasing.

Its graph is the reflection of \(y = b^x\) in the line \(y = x\), because swapping inputs and outputs is what inversion does (L12). The exponential's horizontal asymptote \(y = 0\) becomes the logarithm's vertical one.

The three laws and change of base

Theorem · laws of logarithms

For \(x, y > 0\) and real \(r\): \(\ \log_b(xy) = \log_b x + \log_b y,\quad \log_b(x/y) = \log_b x - \log_b y,\quad \log_b(x^r) = r\log_b x.\)

Derivation

Let \(u = \log_b x\) and \(v = \log_b y\), so \(x = b^u\) and \(y = b^v\). Then \(xy = b^u b^v = b^{u+v}\), so \(\log_b(xy) = u + v\). Similarly \(x/y = b^{u - v}\) and \(x^r = (b^u)^r = b^{ru}\). Each log law is an exponent law from L4 read backwards.

Theorem · change of base

For any admissible bases \(a, b\): \(\displaystyle \log_b x = \frac{\log_a x}{\log_a b}\), in particular \(\log_b x = \dfrac{\ln x}{\ln b}\). (Proof: the Prove it below.)

So all logarithms are proportional to one another: \(\log_2 x \approx 1.4427 \ln x\) and \(\log_{10} x \approx 0.4343 \ln x\). Changing base rescales a log axis; it never changes its shape.

Worked example

Solve \(3^{2x+1} = 7\).

Take \(\ln\) of both sides (both are positive) and use the power law:

$$(2x + 1)\ln 3 = \ln 7 \quad\Longrightarrow\quad x = \frac{\ln 7 - \ln 3}{2\ln 3} = \frac{\ln(7/3)}{2\ln 3} \approx \frac{0.8473}{2.1972} \approx 0.3856.$$

Check: \(2x + 1 \approx 1.7712\) and \(3^{1.7712} = e^{1.7712 \times 1.0986} \approx e^{1.9459} \approx 7\).

Worked example

Expand \(\log\!\big(x^3\sqrt y / z^2\big)\), with \(x, y, z > 0\).

$$\log\frac{x^3 y^{1/2}}{z^2} = \log x^3 + \log y^{1/2} - \log z^2 = 3\log x + \tfrac12 \log y - 2\log z.$$

Log scales and log-log plots

A log scale measures ratios as distances. Decibels: \(L = 10\log_{10}(P/P_0)\), so +10 dB is ten times the power and +3 dB is about double (\(10\log_{10}2 \approx 3.01\)). pH: \(-\log_{10}[\mathrm H^+]\), so pH 3 has a hundred times the hydrogen-ion concentration of pH 5.

On a log-log plot a power law becomes a straight line, because

$$y = c\,x^k \quad\Longleftrightarrow\quad \log y = \log c + k\log x,$$

which is linear in \((\log x, \log y)\) with slope \(k\) and intercept \(\log c\). On a semi-log plot (only \(y\) logged), exponentials \(y = c\,b^x\) become straight lines instead.

Worked example · recover the exponent

Two points read off a straight log-log line are \((10, 300)\) and \((1000, 3\times10^6)\). Slope \(k = \dfrac{\log_{10}(3\times10^6) - \log_{10}300}{\log_{10}1000 - \log_{10}10} = \dfrac{\log_{10}(10^4)}{\log_{10}(10^2)} = \dfrac42 = 2\). Then \(c = 300/10^2 = 3\): the data follow \(y = 3x^2\). Note that the ratio of \(y\)-values over the ratio of \(x\)-values, both logged, is all you need; the base cancels.

Why statistics lives on the log scale

  • Products become sums. Multiplicative effects (\(y = \mu\cdot\varepsilon\), growth by percentages) become additive after \(\log\): \(\log y = \log\mu + \log\varepsilon\), which is the setting where averages and linear models behave.
  • Variance stabilizing. When the spread of positive data grows in proportion to its level (incomes, reaction times, counts of large magnitude), logs make the spread roughly constant across levels and right-skewed data roughly symmetric. To first order \(\Var(\log Y) \approx \Var(Y)/\mu^2\), which is constant exactly when the standard deviation is proportional to the mean.
  • Log-likelihood. For independent data the likelihood is a product \(L(\theta) = \prod_{i=1}^{n} p(x_i \mid \theta)\). Since \(\log\) is strictly increasing, \(\log L\) has the same maximizer, and it is a sum \(\sum_i \log p(x_i\mid\theta)\), whose derivative is a sum of simple terms. It also avoids underflow: 1000 probabilities of 0.01 multiply to \(10^{-2000}\), far below the smallest positive double-precision number (about \(10^{-308}\)), while their log is a modest \(-2000\ln 10 \approx -4605\). Maximum likelihood (L112) is almost always done this way.
Common errors
  • \(\log(x + y) \ne \log x + \log y\). There is no rule for the log of a sum. Also \(\dfrac{\log x}{\log y} \ne \log\dfrac xy\) (that ratio is \(\log_y x\)).
  • \(\log(x^2) = 2\log x\) only for \(x > 0\). In general \(\log(x^2) = 2\log|x|\); applying the law blindly loses the solutions with \(x < 0\).
  • \((\log x)^2 \ne \log(x^2)\). The first squares the output; the second doubles it.
  • Forgetting the domain. Solving \(\log_2 x + \log_2(x-2) = 3\) gives \(x = 4\) or \(x = -2\); only \(x = 4\) makes both logs defined.
  • Base ambiguity. "log" means \(\ln\) in most analysis and ML texts, \(\log_{10}\) on calculators and in older science, \(\log_2\) in computer science. Check before you compute.

Polynomials & the Factoring Toolkit

34m video50m practice

Polynomials divide like integers: every division leaves a remainder of lower degree. Dividing by \(x - a\) leaves the constant \(p(a)\), so roots and linear factors are the same thing, and factoring a polynomial means finding its roots.

Vocabulary and arithmetic

Definition

A polynomial is \(p(x) = a_n x^n + a_{n-1}x^{n-1} + \dots + a_1 x + a_0\) with \(a_n \ne 0\). Its degree is \(n\), its leading coefficient is \(a_n\), and it is monic if \(a_n = 1\). (The zero polynomial has no degree.)

Add by collecting like powers; multiply by distributing every term over every term. The coefficient of \(x^k\) in \(pq\) is \(\sum_{i+j=k} a_i b_j\), a convolution of the coefficient lists. Leading terms multiply to \(a_n b_m x^{n+m} \ne 0\), so \(\deg(pq) = \deg p + \deg q\), while \(\deg(p + q) \le \max(\deg p, \deg q)\) (the leading terms may cancel).

Theorem · division algorithm for polynomials

For polynomials \(p\) and \(d \ne 0\) there are unique polynomials \(q, r\) with \(p = dq + r\) and either \(r = 0\) or \(\deg r < \deg d\).

Long division builds \(q\) one term at a time: divide the leading term of what is left by the leading term of \(d\), multiply \(d\) by that term, subtract, repeat until the degree drops below \(\deg d\). For \((x^3 + 2x^2 - 5x + 1) \div (x^2 + 1)\): \(x^3/x^2 = x\), subtract \(x^3 + x\), leaving \(2x^2 - 6x + 1\); \(2x^2/x^2 = 2\), subtract \(2x^2 + 2\), leaving \(-6x - 1\). So \(q = x + 2\), \(r = -6x - 1\).

Remainder and Factor Theorems

Theorem · Remainder Theorem

The remainder when \(p(x)\) is divided by \(x - a\) is \(p(a)\).

Proof

Divide by \(d(x) = x - a\), which has degree 1: \(p(x) = (x - a)q(x) + r\), where \(r\) has degree below 1, i.e. \(r\) is a constant. This is an identity of polynomials, so it holds at \(x = a\): \(p(a) = 0 \cdot q(a) + r = r\).

The Factor Theorem, \((x - a) \mid p(x) \iff p(a) = 0\), follows at once (the Prove it). Its main consequence: a nonzero polynomial of degree \(n\) has at most \(n\) roots. Each root \(a_i\) splits off a factor \(x - a_i\) and lowers the degree by one, and a nonzero constant has no roots. L7 uses this to prove that partial fractions are unique.

A root \(a\) has multiplicity \(m\) if \((x - a)^m \mid p\) but \((x - a)^{m+1} \nmid p\). In \(x^2(x-1)^3\), 0 has multiplicity 2 and 1 has multiplicity 3. Multiplicity controls how a graph meets the axis (L16).

Synthetic division

Algorithm

Divide by \(x - a\).

  1. Write the coefficients of \(p\) in descending degree, with 0 for every missing power.
  2. Bring the first coefficient down. Then repeatedly multiply the last number written below the line by \(a\), add it to the next coefficient, and write the sum below.
  3. The final number is the remainder \(p(a)\); the others are the coefficients of the quotient, one degree lower.

The Rational Root Theorem

Theorem · Rational Root Theorem

If \(p(x) = a_n x^n + \dots + a_0\) has integer coefficients and \(r/s\) (in lowest terms) is a root, then \(r \mid a_0\) and \(s \mid a_n\).

Proof

Substitute and multiply by \(s^n\): \(a_n r^n + a_{n-1} r^{n-1}s + \dots + a_1 r s^{n-1} + a_0 s^n = 0\). Every term except \(a_0 s^n\) contains the factor \(r\), so \(r \mid a_0 s^n\). Since \(\gcd(r, s) = 1\), Euclid's lemma (L2) gives \(r \mid a_0\). Every term except \(a_n r^n\) contains \(s\), so likewise \(s \mid a_n\).

Worked example

Factor \(x^3 - 7x + 6\) fully.

Monic with constant term 6, so any rational root is an integer dividing 6: try \(\pm1, \pm2, \pm3, \pm6\). \(p(1) = 1 - 7 + 6 = 0\), so \(x - 1\) is a factor. Synthetic division by 1 on \(1, 0, -7, 6\) gives \(1, 1, -6\) with remainder 0, so

$$x^3 - 7x + 6 = (x - 1)(x^2 + x - 6) = (x - 1)(x - 2)(x + 3).$$

Symmetric polynomials

Expanding \((x - r_1)(x - r_2)(x - r_3) = x^3 - e_1 x^2 + e_2 x - e_3\) produces the elementary symmetric polynomials of the roots:

$$e_1 = r_1 + r_2 + r_3, \qquad e_2 = r_1 r_2 + r_1 r_3 + r_2 r_3, \qquad e_3 = r_1 r_2 r_3.$$

They are symmetric: unchanged by any permutation of the \(r_i\). The fundamental theorem of symmetric polynomials (statement only) says every symmetric polynomial is a polynomial in the \(e_k\). For two variables, \(x^2 + y^2 = e_1^2 - 2e_2\) and \(x^3 + y^3 = e_1^3 - 3e_1 e_2\). So symmetric expressions in the roots can be computed from the coefficients without finding the roots; this is Vieta's idea (L8). For \(x^3 - 7x + 6\): \(e_1 = 0\), \(e_2 = -7\), \(e_3 = -6\), and indeed \(1 + 2 - 3 = 0\), \(2 - 3 - 6 = -7\), \(1 \cdot 2 \cdot (-3) = -6\).

Common errors
  • Wrong sign in synthetic division. To divide by \(x + 2\), use \(a = -2\).
  • Missing zero placeholders. \(2x^4 - 3x^2 + 1\) has coefficients \(2, 0, -3, 0, 1\); dropping the zeros shifts every column.
  • Sign patterns for cubes. \(a^3 + b^3 = (a + b)(a^2 - ab + b^2)\): the binomial copies the sign, the middle term of the quadratic takes the opposite sign, the last term is always plus. The quadratic factor does not factor further over \(\R\).
  • \(x^2 + 4\) does not factor over \(\R\). There is no "sum of squares" rule over the reals (it does factor over \(\C\), L22).
  • Misusing the Rational Root Theorem. It needs integer coefficients and only lists candidates; each must still be tested.

Rational Expressions & Partial Fractions

28m video45m practice

A proper rational function whose denominator is factored splits, in exactly one way, into a sum of simple fractions, one for each factor and each power of a factor. Each simple piece is easy to integrate, invert or expand as a series, which is why the technique keeps returning.

Simplifying, and the restrictions that survive cancellation

A rational expression \(p(x)/q(x)\) is defined wherever \(q(x) \ne 0\). Simplify by factoring top and bottom and cancelling common factors, but the domain is fixed by the original denominator:

$$\frac{x^2 - 9}{x^2 + x - 6} = \frac{(x - 3)(x + 3)}{(x + 3)(x - 2)} = \frac{x - 3}{x - 2}, \qquad x \ne -3,\ 2.$$

The restriction \(x \ne -3\) is removable: the simplified formula is defined there, but the original is not, and the graph has a hole (L16). To add or subtract, rewrite over the least common denominator: \(\frac{2}{x^2 - 4} - \frac{1}{x - 2} = \frac{2 - (x + 2)}{x^2 - 4} = \frac{-x}{x^2 - 4}\). For a stacked (complex) fraction, multiply top and bottom by the LCD of all the small fractions: \(\dfrac{1/x - 1/y}{1/x + 1/y} = \dfrac{y - x}{y + x}\) (multiply by \(xy\)), valid for \(x, y \ne 0\), \(x \ne -y\).

Proper and improper; reduce by division first

Definition

\(p/q\) is proper if \(\deg p < \deg q\), otherwise improper. By polynomial division (L6), \(p = qs + r\) with \(\deg r < \deg q\), so every improper rational function is a polynomial plus a proper one: \(\ \dfrac pq = s + \dfrac rq.\)

Example: \(\dfrac{x^3 + 1}{x^2 - 1} = \dfrac{(x + 1)(x^2 - x + 1)}{(x + 1)(x - 1)} = \dfrac{x^2 - x + 1}{x - 1} = x + \dfrac{1}{x - 1}\), for \(x \ne \pm1\). Partial fractions apply only to the proper part.

The decomposition templates

Factor the denominator over \(\R\) into linear factors and irreducible quadratics (negative discriminant). Then each factor contributes:

Factor in the denominatorTerms in the decomposition
distinct linear \(x - a\)\(\dfrac{A}{x - a}\)
repeated linear \((x - a)^k\)\(\dfrac{A_1}{x - a} + \dfrac{A_2}{(x - a)^2} + \dots + \dfrac{A_k}{(x - a)^k}\)
irreducible quadratic \(x^2 + bx + c\)\(\dfrac{Bx + C}{x^2 + bx + c}\)
repeated quadratic \((x^2 + bx + c)^k\)\(\dfrac{B_1x + C_1}{x^2 + bx + c} + \dots + \dfrac{B_kx + C_k}{(x^2 + bx + c)^k}\)

The number of unknown constants always equals \(\deg q\), matching the number of coefficients you can compare.

Algorithm · partial fractions
  1. If improper, divide first and keep the polynomial part aside.
  2. Factor the denominator completely over \(\R\).
  3. Write the template from the table, with every power of every repeated factor.
  4. Multiply through by \(q(x)\) to get a polynomial identity.
  5. Solve for the constants: substitute the roots of \(q\) (each kills all but one term), then equate coefficients of matching powers for whatever is left.
  6. Check by recombining, or by evaluating both sides at one extra point.
Worked example

\(\dfrac{3x + 5}{(x - 1)(x + 2)}\).

Template \(\dfrac{A}{x - 1} + \dfrac{B}{x + 2}\). Clear denominators: \(3x + 5 = A(x + 2) + B(x - 1)\).

\(x = 1\): \(8 = 3A\), so \(A = \tfrac83\). \(x = -2\): \(-1 = -3B\), so \(B = \tfrac13\).

$$\frac{3x + 5}{(x - 1)(x + 2)} = \frac{8/3}{x - 1} + \frac{1/3}{x + 2}.$$

Check: \(\tfrac83(x + 2) + \tfrac13(x - 1) = \tfrac{9x + 15}{3} = 3x + 5\).

Worked example

\(\dfrac{x^2 + 1}{(x - 2)^2 (x^2 + 4)}\).

Proper (degree 2 over degree 4); \(x^2 + 4\) is irreducible. Template:

$$\frac{x^2 + 1}{(x - 2)^2(x^2 + 4)} = \frac{A}{x - 2} + \frac{B}{(x - 2)^2} + \frac{Cx + D}{x^2 + 4}.$$

Clear denominators: \(x^2 + 1 = A(x - 2)(x^2 + 4) + B(x^2 + 4) + (Cx + D)(x - 2)^2\).

Substitute \(x = 2\): \(5 = 8B\), so \(B = \tfrac58\). Equate coefficients of the expanded right side, \((A + C)x^3 + (-2A + B - 4C + D)x^2 + (4A + 4C - 4D)x + (-8A + 4B + 4D)\):

\(x^3\): \(A + C = 0\). \(x^1\): \(4(A + C) - 4D = 0\), so \(D = 0\). Constant: \(-8A + 4B = 1\), so \(-8A + \tfrac52 = 1\) and \(A = \tfrac3{16}\). Then \(C = -\tfrac3{16}\). The \(x^2\) equation checks: \(-\tfrac6{16} + \tfrac{10}{16} + \tfrac{12}{16} + 0 = 1\).

$$\frac{x^2 + 1}{(x - 2)^2(x^2 + 4)} = \frac{3/16}{x - 2} + \frac{5/8}{(x - 2)^2} - \frac{3x/16}{x^2 + 4}.$$

Spot check at \(x = 0\): left side \(\tfrac{1}{16}\); right side \(-\tfrac{3}{32} + \tfrac{5}{32} - 0 = \tfrac{1}{16}\).

Why the technique keeps returning

  • Integration (L72): each piece has an elementary antiderivative, e.g. \(\int \frac{dx}{(x - 1)(x + 2)} = \tfrac13 \ln\left|\tfrac{x - 1}{x + 2}\right| + C\).
  • Generating functions (L32): \(\frac{1}{(1 - x)(1 - 2x)} = \frac{2}{1 - 2x} - \frac{1}{1 - x}\), and expanding both geometric series shows the coefficient of \(x^n\) is \(2^{n+1} - 1\). Recurrences are solved exactly this way.
  • Laplace transforms: since \(1/(s - a)\) is the transform of \(e^{at}\), \(\frac{1}{(s - 1)(s + 2)} = \frac{1/3}{s - 1} - \frac{1/3}{s + 2}\) inverts to \(\tfrac13(e^{t} - e^{-2t})\). The roots of the denominator become the exponential rates of the solution.
Common errors
  • Decomposing an improper fraction. The templates assume \(\deg p < \deg q\). Divide first.
  • Missing powers of a repeated factor. \((x - 2)^2\) needs both \(\frac{A}{x - 2}\) and \(\frac{B}{(x - 2)^2}\); with only the second, the system has no solution.
  • A constant over a quadratic. An irreducible quadratic needs a linear numerator \(Bx + C\), not just \(C\).
  • Cover-up beyond its scope. Substituting a root finds the coefficient of the highest power of that factor only; the lower powers and the quadratic terms need equated coefficients.
  • Losing restrictions. After cancelling a common factor, the excluded point stays excluded.

Equations & Inequalities

36m video50m practice

Solving an equation means replacing it by simpler equations with the same solution set. Some moves preserve the solution set and some do not; knowing which is the difference between a derivation and a guess, and it is why some "solutions" have to be checked and thrown away.

Equivalent equations: which moves are safe

Two equations are equivalent if they have the same solutions. A move that only goes one way (\(\Rightarrow\)) can create solutions that fail the original; these are extraneous roots. A move that loses solutions is worse, because no check will find them.

Quadratics: completing the square, the discriminant and Vieta

A linear equation \(ax + b = 0\) with \(a \ne 0\) has the single solution \(x = -b/a\). For a quadratic, the key move is completing the square: \(x^2 + px = \left(x + \tfrac p2\right)^2 - \tfrac{p^2}{4}\). Applied to \(ax^2 + bx + c = 0\) it yields the quadratic formula (the Prove it):

$$x = \frac{-b \pm \sqrt{\Delta}}{2a}, \qquad \Delta = b^2 - 4ac.$$

The discriminant \(\Delta\) classifies the roots: \(\Delta > 0\), two distinct real roots; \(\Delta = 0\), one repeated root \(-b/2a\); \(\Delta < 0\), no real roots, but two complex conjugate ones (L21).

Worked example

Complete the square on \(2x^2 - 8x + 3\).

Factor the leading coefficient out of the \(x\) terms, complete the square inside, and compensate outside:

$$2x^2 - 8x + 3 = 2(x^2 - 4x) + 3 = 2\big[(x - 2)^2 - 4\big] + 3 = 2(x - 2)^2 - 5.$$

The vertex is \((2, -5)\), the minimum value is \(-5\), and the roots solve \((x - 2)^2 = \tfrac52\): \(x = 2 \pm \sqrt{5/2} = 2 \pm \tfrac{\sqrt{10}}{2}\). The formula agrees: \(\frac{8 \pm \sqrt{64 - 24}}{4} = 2 \pm \frac{\sqrt{40}}{4}\).

Theorem · Vieta's formulas

If \(r_1, r_2\) are the roots of \(ax^2 + bx + c\) (with multiplicity), then \(r_1 + r_2 = -b/a\) and \(r_1 r_2 = c/a\).

Proof. By the Factor Theorem (L6), \(ax^2 + bx + c = a(x - r_1)(x - r_2) = ax^2 - a(r_1 + r_2)x + a r_1 r_2\). Compare coefficients.

Equations that reduce to quadratics; radicals and absolute values

Substitution exposes a hidden quadratic: \(x^4 - 13x^2 + 36 = 0\) with \(u = x^2\); \(e^{2x} - 5e^x + 6 = 0\) with \(u = e^x\); \(x - 5\sqrt x + 6 = 0\) with \(u = \sqrt x\). Solve for \(u\), then undo the substitution and discard values the substitution cannot take (\(u = x^2\), \(e^x\) and \(\sqrt x\) cannot be negative).

Radical equations: isolate the radical, square, solve, and check every candidate in the original, because squaring is one-way. Absolute-value equations: \(|A| = B\) means \(B \ge 0\) and \(A = \pm B\). For \(|2x - 1| = x + 4\): \(2x - 1 = x + 4\) gives \(x = 5\); \(2x - 1 = -(x + 4)\) gives \(x = -1\); both have \(x + 4 \ge 0\), so both stand.

Worked example

\(\sqrt{x + 5} = x - 1\).

Square: \(x + 5 = x^2 - 2x + 1\), so \(x^2 - 3x - 4 = (x - 4)(x + 1) = 0\) and the candidates are \(4\) and \(-1\).

Check \(x = 4\): \(\sqrt9 = 3 = 4 - 1\). Valid. Check \(x = -1\): \(\sqrt4 = 2\) but \(-1 - 1 = -2\). Extraneous: it solves \(-\sqrt{x + 5} = x - 1\), the other equation that squares to the same thing. The solution set is \(\{4\}\). The quick filter: \(\sqrt{\cdot} \ge 0\), so any solution needs \(x - 1 \ge 0\).

Systems of linear equations

Substitution solves one equation for a variable and inserts it in the others. Elimination adds multiples of equations to cancel a variable. For \(2x + 3y = 7\), \(x - y = 1\): subtract twice the second from the first to get \(5y = 5\), so \(y = 1\), \(x = 2\). Geometrically each equation in two unknowns is a line, and there are exactly three possibilities: one intersection point, parallel lines (no solution), or the same line (infinitely many). Elimination done systematically on any number of equations is Gaussian elimination, the central algorithm of L39.

Inequalities and sign charts

The rules: adding anything preserves an inequality; multiplying by a positive number preserves it; multiplying by a negative number reverses it. Never multiply by an expression whose sign you do not know. A compound inequality is solved in all parts at once: \(-3 < 2x + 1 \le 5 \iff -4 < 2x \le 4 \iff -2 < x \le 2\).

Algorithm

Sign chart for \(f(x) \ge 0\), \(f\) a product or quotient of factors.

  1. Move everything to one side and combine into a single fraction; factor top and bottom.
  2. Mark the critical points: zeros of the numerator and of the denominator. They cut the line into intervals on which no factor changes sign.
  3. Record the sign of each factor on each interval; multiply the signs.
  4. Select the intervals with the required sign. Include numerator zeros for \(\ge\) or \(\le\); never include denominator zeros.
Worked example

\(\dfrac{(x - 1)(x + 2)}{x - 3} \ge 0\).

Critical points \(-2, 1, 3\). The chart below gives the sign pattern \(-, +, -, +\). Include the zeros \(-2\) and \(1\), exclude \(3\): the solution set is \([-2, 1] \cup (3, \infty)\).

Common errors
  • Cross-multiplying an inequality. From \(\frac{x + 1}{x - 2} < 2\) you may not conclude \(x + 1 < 2(x - 2)\): the sign of \(x - 2\) is unknown. Subtract 2 and use a sign chart.
  • Dividing by a variable. Cancelling \(x\) from \(x^2 = 3x\) loses \(x = 0\). Factor instead: \(x(x - 3) = 0\).
  • \(x^2 = 9 \Rightarrow x = 3\). It gives \(x = \pm 3\); \(\sqrt{9} = 3\) is a number, but the equation has two solutions.
  • Skipping the check after squaring, or "checking" in the squared equation instead of the original.
  • Including a denominator zero in a solution set because the inequality is non-strict.

    \(\sqrt{2x+3} = 1 + \sqrt{x+1}\); square: \(x + 1 = 2\sqrt{x + 1}\). With \(w = \sqrt{x+1} \ge 0\): \(w^2 = 2w\), so \(w = 0\) or \(2\), i.e. \(x = -1\) or \(3\). Both check: \(1 - 0 = 1\) and \(3 - 2 = 1\).

  6. Solve by elimination: \(x + y + z = 6\), \(2x - y + z = 3\), \(x + 2y - z = 2\).
    Answer

    Add eq. 1 and 3: \(2x + 3y = 8\). Add eq. 2 and 3: \(3x + y = 5\). Then \(y = 5 - 3x\), \(2x + 15 - 9x = 8\), so \(x = 1\), \(y = 2\), \(z = 3\).

L9 · DAY 7

Absolute Value, Intervals & Classical Inequalities

30m video45m practice

Most bounds in analysis, optimization and probability are assembled from four inequalities: the triangle inequality, AM–GM, Cauchy–Schwarz and Bernoulli. Each has a short proof from either "squares are non-negative" or a case split, and you should be able to reproduce every one of them.

Absolute value three ways, and solving with it

Definition

\(|x| = x\) if \(x \ge 0\) and \(|x| = -x\) if \(x < 0\). Equivalently \(|x| = \sqrt{x^2}\) (the non-negative root), and geometrically \(|x - a|\) is the distance between \(x\) and \(a\) on the line.

Each view proves something easily. From \(\sqrt{x^2}\): \(|ab| = \sqrt{a^2 b^2} = \sqrt{a^2}\sqrt{b^2} = |a||b|\), and \(|a/b| = |a|/|b|\) for \(b \ne 0\). From the cases: \(-|a| \le a \le |a|\). From distance: \(|x - a| < r\) is the open interval of radius \(r\) around \(a\).

For \(c > 0\): \(\ |f(x)| < c \iff -c < f(x) < c\) (one interval, "and"), while \(|f(x)| > c \iff f(x) < -c\ \text{or}\ f(x) > c\) (two pieces, "or"). If \(c \le 0\), \(|f| < c\) has no solutions. In set-builder notation, \(\{x \in \R : |x - 1| > 3\} = (-\infty, -2) \cup (4, \infty)\).

Worked example

\(|2x - 3| \le 7\).

$$-7 \le 2x - 3 \le 7 \iff -4 \le 2x \le 10 \iff -2 \le x \le 5.$$

Solution \([-2, 5]\). As a distance statement, \(|x - \tfrac32| \le \tfrac72\): the points within \(3.5\) of \(1.5\).

The triangle inequality

Theorem · Triangle inequality

For all real \(a, b\): \(\ |a + b| \le |a| + |b|\), and hence \(\ \big||a| - |b|\big| \le |a - b|\).

Proof

Add \(-|a| \le a \le |a|\) and \(-|b| \le b \le |b|\): \(-(|a| + |b|) \le a + b \le |a| + |b|\), which is \(|a + b| \le |a| + |b|\). (The Prove it asks for the case-by-case version.)

Reverse form. \(|a| = |(a - b) + b| \le |a - b| + |b|\), so \(|a| - |b| \le |a - b|\). Swapping \(a\) and \(b\) gives \(|b| - |a| \le |a - b|\). Both together are \(\big||a| - |b|\big| \le |a - b|\).

With \(a = x - y\), \(b = y - z\) it reads \(|x - z| \le |x - y| + |y - z|\): a detour through \(y\) is never shorter. The same statement for vectors (L36) is the defining property of a norm, and almost every \(\varepsilon\)–\(\delta\) proof (L60) splits an error into pieces with it.

AM–GM

Theorem · Arithmetic mean–geometric mean

For \(a, b \ge 0\): \(\ \dfrac{a + b}{2} \ge \sqrt{ab}\), with equality iff \(a = b\). More generally, for \(x_1, \dots, x_n \ge 0\): \(\ \dfrac{x_1 + \dots + x_n}{n} \ge \sqrt[n]{x_1 x_2 \cdots x_n}\), with equality iff all \(x_i\) are equal.

Proof (two variables)

\(0 \le (\sqrt a - \sqrt b)^2 = a - 2\sqrt{ab} + b\). Rearrange: \(a + b \ge 2\sqrt{ab}\). Equality holds iff \(\sqrt a = \sqrt b\). The \(n\)-variable version can be proved by induction (Cauchy's forward–backward argument) or from the concavity of \(\ln\) (L90).

Use. For \(x > 0\), \(x + \frac4x \ge 2\sqrt{x \cdot \frac4x} = 4\), with equality at \(x = \frac4x\), i.e. \(x = 2\): a minimum found without calculus. Among rectangles with perimeter \(2(x + y) = P\), the area \(xy \le \left(\frac{x + y}{2}\right)^2 = \frac{P^2}{16}\), so the square wins.

Cauchy–Schwarz

Theorem · Cauchy–Schwarz (scalar form)

For real \(a_1, \dots, a_n\) and \(b_1, \dots, b_n\): \(\ \Big(\sum_i a_i b_i\Big)^2 \le \Big(\sum_i a_i^2\Big)\Big(\sum_i b_i^2\Big)\), with equality iff one list is a scalar multiple of the other.

Proof · the discriminant trick

For every real \(t\), \(0 \le \sum_i (a_i t + b_i)^2 = A t^2 + 2Bt + C\), where \(A = \sum a_i^2\), \(B = \sum a_i b_i\), \(C = \sum b_i^2\). If \(A = 0\), all \(a_i = 0\) and both sides are 0. Otherwise this is a quadratic in \(t\) that is never negative, so it has at most one real root and its discriminant is \(\le 0\) (L8): \(4B^2 - 4AC \le 0\), i.e. \(B^2 \le AC\). Equality means a double root \(t_0\), so \(a_i t_0 + b_i = 0\) for every \(i\): the lists are proportional.

Worked example

Bound \((a + b + c)^2\).

Apply Cauchy–Schwarz to \((1, 1, 1)\) and \((a, b, c)\):

$$(1\cdot a + 1\cdot b + 1\cdot c)^2 \le (1^2 + 1^2 + 1^2)(a^2 + b^2 + c^2) \quad\Longrightarrow\quad (a + b + c)^2 \le 3(a^2 + b^2 + c^2),$$

with equality iff \(a = b = c\). Dividing by 9: the square of the mean is at most the mean of the squares, which is the statement that a variance is non-negative.

In vector language it says \(|u \cdot v| \le \|u\|\,\|v\|\), which is what makes \(\cos\theta = \frac{u\cdot v}{\|u\|\|v\|}\) a legitimate cosine (L36) and forces every correlation coefficient into \([-1, 1]\) (L104).

Bernoulli's inequality, and why these four matter

Theorem · Bernoulli

For \(x \ge -1\) and every integer \(n \ge 1\): \(\ (1 + x)^n \ge 1 + nx\).

Proof (induction). \(n = 1\) is equality. If it holds for \(n\), multiply by \(1 + x \ge 0\), which preserves the inequality: \((1 + x)^{n+1} \ge (1 + nx)(1 + x) = 1 + (n + 1)x + nx^2 \ge 1 + (n + 1)x\).

Bernoulli gives quick lower bounds on powers (\(1.01^{100} \ge 2\)) and drives the limits behind \(e\) (L17). Together: the triangle inequality controls sums of errors, AM–GM turns products into sums, Cauchy–Schwarz controls inner products, and Bernoulli controls powers.

Common errors
  • \(|a + b| = |a| + |b|\). True only when \(a, b\) have the same sign: \(|3 + (-5)| = 2 \ne 8\).
  • \(\sqrt{x^2} = x\) and \(|{-x}| = x\). Both fail for \(x < 0\); the correct statements are \(\sqrt{x^2} = |x|\) and \(|{-x}| = |x|\).
  • Writing \(|x - 1| > 3\) as \(-3 > x - 1 > 3\). That chain is impossible. A "greater than" absolute-value inequality splits into two separate pieces joined by "or".
  • AM–GM with negative numbers. \(a = b = -1\) gives AM \(-1\) and "GM" \(1\). The hypothesis \(a, b \ge 0\) is essential.
  • Ignoring equality cases. A bound from AM–GM or Cauchy–Schwarz is only the minimum or maximum if the equality condition can actually be met.

    Case 1: \(a, b \ge 0\). Then \(a + b \ge 0\) and \(|a + b| = a + b = |a| + |b|\). Case 2: \(a, b \le 0\). Then \(|a + b| = -(a + b) = (-a) + (-b) = |a| + |b|\). Sequences, Series & Sigma Notation

34m video45m practice

Sigma notation is a small algebra with four rules: linearity, index shifts, splitting, and swapping the order of a double sum. Add three tricks (pairing, telescoping, multiplying by the ratio) and you can find closed forms for nearly every finite sum the rest of the course needs.

Sequences

Definition

A sequence is a function \(a : \N \to \R\), written \(a_n\) instead of \(a(n)\). It can be given explicitly, \(a_n = 2n - 1\), or recursively, \(a_1 = 1,\ a_{n+1} = a_n + 2\) (the same sequence). A recursion needs enough initial values to start: Fibonacci, \(F_{n+1} = F_n + F_{n-1}\), needs two.

Recursive definitions are natural (each term from the last), explicit ones are useful (jump straight to term 1000). Converting the first into the second is the subject of recurrence relations (L32); proving that a guessed explicit formula satisfies a recursion is induction (L28).

Σ and Π, and the rules for moving them

\(\sum_{k=m}^{n} a_k = a_m + a_{m+1} + \dots + a_n\) has \(n - m + 1\) terms; \(\prod_{k=m}^{n} a_k\) is the same with multiplication, e.g. \(n! = \prod_{k=1}^{n} k\). The index \(k\) is a dummy: \(\sum_k a_k = \sum_j a_j\).

Rules
  • Linearity: \(\sum_k (c\,a_k + b_k) = c\sum_k a_k + \sum_k b_k\). In particular \(\sum_{k=m}^{n} c = (n - m + 1)c\).
  • Index shift: \(\sum_{k=1}^{n} a_k = \sum_{j=0}^{n-1} a_{j+1}\) (substitute \(k = j + 1\) and move both limits).
  • Splitting: \(\sum_{k=1}^{n} a_k = \sum_{k=1}^{m} a_k + \sum_{k=m+1}^{n} a_k\); or by parity, \(\sum_{k=1}^{2n} a_k = \sum_{k=1}^{n} a_{2k} + \sum_{k=1}^{n} a_{2k-1}\).
  • Logs turn \(\Pi\) into \(\Sigma\): \(\log \prod_k a_k = \sum_k \log a_k\) for positive \(a_k\) (L5).
Worked example

\(\sum_{k=1}^{n} (2k - 1)\).

By linearity and the sum of the first \(n\) integers (the Prove it):

$$\sum_{k=1}^{n}(2k - 1) = 2\sum_{k=1}^{n} k - \sum_{k=1}^{n} 1 = 2\cdot\frac{n(n+1)}{2} - n = n^2.$$

The first \(n\) odd numbers sum to a perfect square: \(1 + 3 + 5 + 7 = 16\).

Arithmetic and geometric sums

An arithmetic sequence adds a constant difference, \(a_k = a + (k-1)d\). Gauss's pairing: write the sum forwards and backwards and add; each of the \(n\) column pairs sums to first \(+\) last, so \(S = \frac{n}{2}(\text{first} + \text{last})\).

Derivation · finite geometric sum

Let \(S = a + ar + \dots + ar^{n-1}\). Then \(rS = ar + \dots + ar^{n-1} + ar^{n}\). Subtracting, everything but the ends cancels: \(S - rS = a - ar^n\), so for \(r \ne 1\)

$$\sum_{k=0}^{n-1} ar^k = a\,\frac{1 - r^n}{1 - r}.$$

Infinite series. If \(|r| < 1\) then \(r^n \to 0\), and the partial sums converge to \(\dfrac{a}{1 - r}\). If \(|r| \ge 1\) (and \(a \ne 0\)) the terms do not tend to 0 and the series diverges.

Worked example

\(3 + \tfrac34 + \tfrac{3}{16} + \cdots\).

First term \(a = 3\), ratio \(r = \tfrac14\), \(|r| < 1\): the sum is \(\dfrac{3}{1 - 1/4} = 4\). The partial sums \(3,\ 3.75,\ 3.9375, \dots\) close a quarter of the remaining gap each time.

Telescoping and sums of powers

Lemma · telescoping

\(\displaystyle\sum_{k=1}^{n}\big(f(k+1) - f(k)\big) = f(n + 1) - f(1)\): all intermediate terms cancel in pairs.

Worked example

Collapse \(\sum_{k=1}^{n}\left(\frac1k - \frac{1}{k+1}\right)\).

\(\left(1 - \tfrac12\right) + \left(\tfrac12 - \tfrac13\right) + \dots + \left(\tfrac1n - \tfrac{1}{n+1}\right) = 1 - \tfrac{1}{n+1}\), which tends to 1. Since \(\frac1k - \frac1{k+1} = \frac{1}{k(k+1)}\) (partial fractions, L7), this also shows \(\sum_{k\ge1} \frac{1}{k(k+1)} = 1\).

Derivation

\(\sum k^2\) by telescoping a cube.

Sum the identity \((k+1)^3 - k^3 = 3k^2 + 3k + 1\) over \(k = 1, \dots, n\). The left side telescopes:

$$(n+1)^3 - 1 = 3\sum_{k=1}^n k^2 + 3\cdot\frac{n(n+1)}{2} + n.$$

Solve: \(3\sum k^2 = (n+1)^3 - (n+1) - \tfrac32 n(n+1) = (n+1)\big(n^2 + 2n - \tfrac32 n\big) = \tfrac12 n(n+1)(2n+1)\). Telescoping \((k+1)^4 - k^4\) the same way gives \(\sum k^3\).

Double sums and swapping the order

A double sum adds a quantity over a set of index pairs. Any order of adding gives the same total (for finite sums), so you may swap the order, provided you re-describe the same set of pairs:

$$\sum_{i=1}^{n}\sum_{j=1}^{i} a_{ij} \;=\; \sum_{j=1}^{n}\sum_{i=j}^{n} a_{ij} \qquad\text{(both run over } 1 \le j \le i \le n\text{)}.$$

Example: \(\sum_{i=1}^{n}\sum_{j=1}^{n} ij = \left(\sum_i i\right)\left(\sum_j j\right) = \left(\frac{n(n+1)}{2}\right)^2\), because on a full square the inner sum factors out. Swapping order is the discrete ancestor of switching the order of integration (L84).

The harmonic series diverges

Theorem

\(H_n = \sum_{k=1}^{n} \frac1k \to \infty\), even though \(\frac1k \to 0\).

Proof (grouping). \(1 + \tfrac12 + \left(\tfrac13 + \tfrac14\right) + \left(\tfrac15 + \dots + \tfrac18\right) + \dots\). The group ending at \(1/2^m\) has \(2^{m-1}\) terms, each at least \(1/2^m\), so it sums to at least \(\tfrac12\). Hence \(H_{2^m} \ge 1 + \tfrac m2\), which is unbounded.

The growth is slow: \(H_n \approx \ln n + \gamma\) with \(\gamma \approx 0.5772\), so it takes about \(1.5 \times 10^{43}\) terms to pass 100. The lesson for later: terms tending to 0 is necessary for convergence, not sufficient (L74).

Common errors
  • \(\sum a_k b_k \ne \left(\sum a_k\right)\left(\sum b_k\right)\). Linearity lets constants out, not other sequences.
  • Counting terms. \(\sum_{k=3}^{10} 1 = 8\), not 7 or 10. The count is \(n - m + 1\).
  • Geometric formula with the wrong exponent. \(\sum_{k=0}^{n-1} r^k\) has \(n\) terms and ends at \(r^{n-1}\); \(\sum_{k=1}^{n} r^k = r\frac{1 - r^n}{1 - r}\) starts at \(r\).
  • Using \(\frac{a}{1-r}\) when \(|r| \ge 1\). \(1 + 2 + 4 + \dots\) is not \(-1\).
  • Telescoping with gaps. \(\sum\left(\frac1k - \frac1{k+2}\right)\) leaves two terms at each end, not one.

    Proof sketch

    Pairing. \(S = 1 + 2 + \dots + n\) and \(S = n + (n-1) + \dots + 1\). Adding column by column gives \(n\) copies of \(n + 1\): \(2S = n(n+1)\). Telescoping. Factorials, Binomial Theorem & Phase 0 Workshop

40m video60m practice

\(\binom nk\) counts the \(k\)-element subsets of an \(n\)-element set. Almost every identity about binomial coefficients, the Binomial Theorem included, is proved most cleanly by counting one collection of subsets in two ways.

Factorials and the convention \(0! = 1\)

\(n! = n(n-1)\cdots 2\cdot 1\) counts the orderings of \(n\) distinct objects. The recursion \(n! = n\cdot(n-1)!\) at \(n = 1\) reads \(1 = 1\cdot 0!\), which forces \(0! = 1\); it also matches the count of orderings of nothing (exactly one, the empty ordering) and makes \(\binom n0 = \binom nn = 1\) come out of the formula below.

Definition · falling and rising factorials

\(x^{\underline k} = x(x-1)\cdots(x - k + 1)\) and \(x^{\overline k} = x(x+1)\cdots(x + k - 1)\), each with \(k\) factors (and \(x^{\underline 0} = x^{\overline 0} = 1\)). For an integer \(n\), \(n^{\underline k}\) counts ordered selections of \(k\) of \(n\) objects; \(n^{\underline n} = n!\). The definitions make sense for any real \(x\), which is what the generalized binomial series needs.

Binomial coefficients and Pascal's triangle

Definition

\(\binom nk\) ("\(n\) choose \(k\)") is the number of \(k\)-element subsets of an \(n\)-element set, and

$$\binom nk = \frac{n^{\underline k}}{k!} = \frac{n!}{k!\,(n-k)!} \qquad (0 \le k \le n).$$

Why: there are \(n^{\underline k}\) ordered selections, and each subset appears \(k!\) times among them, once per ordering.

Symmetry \(\binom nk = \binom n{n-k}\): choosing the \(k\) elements to keep is the same as choosing the \(n - k\) to leave out.

Theorem · Pascal's rule

\(\displaystyle\binom nk = \binom{n-1}{k-1} + \binom{n-1}{k}\) for \(1 \le k \le n - 1\).

Proof (counting). Fix one element \(x\). A \(k\)-subset either contains \(x\), and then the other \(k - 1\) elements come from the remaining \(n - 1\) (\(\binom{n-1}{k-1}\) ways), or it does not, and then all \(k\) come from the remaining \(n - 1\) (\(\binom{n-1}{k}\) ways).

Pascal's rule builds the triangle row by row, each entry the sum of the two above it. Identities you can read off it:

  • Row sums \(\sum_k \binom nk = 2^n\) (the Prove it).
  • Alternating row sums \(\sum_k (-1)^k\binom nk = 0\) for \(n \ge 1\): set \(x = -1\), \(y = 1\) in the Binomial Theorem below, \((1 - 1)^n = 0\).
  • Hockey stick \(\sum_{i=k}^{n}\binom ik = \binom{n+1}{k+1}\). Count the \((k+1)\)-subsets of \(\{1, \dots, n+1\}\) by their largest element: if it is \(i + 1\), the other \(k\) elements come from \(\{1, \dots, i\}\), in \(\binom ik\) ways. (Algebraically: apply Pascal's rule to \(\binom{n+1}{k+1}\), then to the \(\binom{n}{k+1}\) it produces, and so on down the diagonal.)

The Binomial Theorem

Theorem · Binomial Theorem $$(x + y)^n = \sum_{k=0}^{n}\binom nk x^k y^{n-k}.$$
Proof (counting)

Expand \((x + y)(x + y)\cdots(x + y)\) without collecting terms: each of the \(2^n\) products picks \(x\) or \(y\) from every factor. A product equals \(x^k y^{n-k}\) exactly when \(x\) was picked from \(k\) of the \(n\) factors, and there are \(\binom nk\) ways to choose which ones. So the coefficient of \(x^ky^{n-k}\) is \(\binom nk\).

Worked example

Coefficient of \(x^5\) in \((2x - 3)^8\).

Write \((2x + (-3))^8\). The term with \(x^5\) takes \(k = 5\): \(\binom85 (2x)^5(-3)^3\).

$$\binom85\cdot 2^5\cdot(-3)^3 = 56 \cdot 32 \cdot (-27) = -48{,}384.$$

Keep the sign inside the bracket and raise the whole coefficient \(2\) to the fifth power: the two common slips.

Beyond integer exponents: the binomial series and Stirling

For real \(\alpha\), define \(\binom\alpha k = \alpha^{\underline k}/k!\). Then, for \(|x| < 1\),

$$(1 + x)^\alpha = \sum_{k=0}^{\infty}\binom\alpha k x^k = 1 + \alpha x + \frac{\alpha(\alpha-1)}{2!}x^2 + \frac{\alpha(\alpha-1)(\alpha-2)}{3!}x^3 + \cdots$$

(statement now; proof as a Taylor series in L69). For \(\alpha \in \N\) the coefficients vanish after \(k = \alpha\) and it is the Binomial Theorem; for \(\alpha = -1\) it is the geometric series \(1 - x + x^2 - \cdots\).

Worked example

\((1 + x)^{1/2}\) to four terms.

\(\binom{1/2}{1} = \tfrac12\); \(\binom{1/2}{2} = \frac{\frac12\cdot(-\frac12)}{2} = -\frac18\); \(\binom{1/2}{3} = \frac{\frac12(-\frac12)(-\frac32)}{6} = \frac1{16}\). So

$$\sqrt{1 + x} \approx 1 + \frac x2 - \frac{x^2}{8} + \frac{x^3}{16}.$$

At \(x = 0.1\): \(1.0488125\), against \(\sqrt{1.1} = 1.0488088\ldots\).

Theorem · Stirling's approximation (statement)

\(n! \sim \sqrt{2\pi n}\left(\dfrac ne\right)^n\), meaning the ratio tends to 1. At \(n = 10\) it gives about \(3.599\times10^6\) against \(10! = 3{,}628{,}800\), under 1% low. In log form, \(\ln n! = n\ln n - n + O(\ln n)\), which is how factorials enter entropy and large-deviation estimates.

Common errors
  • Dropping the coefficient inside the power. In \((2x - 3)^8\) the \(x^5\) term carries \(2^5\) and \((-3)^3\), not \(2\) and \(-3\).
  • Off-by-one exponents. The \(k\)-th term of \((x + y)^n\) pairs \(x^k\) with \(y^{n-k}\); the exponents always add to \(n\).
  • Using the binomial series outside \(|x| < 1\). For non-integer \(\alpha\) it diverges when \(|x| > 1\).
  • Treating \(\binom nk\) as \(n!/k!\). The \((n - k)!\) in the denominator is what removes the order of the unchosen elements.

Practice · 60 min

The workshop above is the main practice block (about 45 minutes). Then:

  1. Prove it. \(\sum_{k=0}^{n}\binom nk = 2^n\), combinatorially (count subsets) and algebraically (set \(x = 1\)). Hint: for the counting proof, decide for each element whether it is in the subset.
    Proof sketch

    Counting. Count the subsets of an \(n\)-element set. Sorting them by size gives \(\sum_k \binom nk\). Building one element at a time, each element is in or out independently, giving \(2^n\). Same set, so equal totals. Algebra. Put \(x = y = 1\) in the Binomial Theorem: \(2^n = (1 + 1)^n = \sum_k \binom nk 1^k1^{n-k}\).

  2. Find the term independent of \(x\) in \(\left(x + \frac{1}{x^2}\right)^9\).
    Answer

    General term \(\binom9k x^{9-k}x^{-2k} = \binom9k x^{9-3k}\); \(9 - 3k = 0\) at \(k = 3\): \(\binom93 = 84\).

  3. Prove \(k\binom nk = n\binom{n-1}{k-1}\) by counting committees with a chair, and deduce \(\sum_k k\binom nk = n2^{n-1}\).
    Answer

    Left: choose the \(k\)-member committee, then its chair. Right: choose the chair from \(n\), then the other \(k - 1\) members from \(n - 1\). Summing over \(k\): \(n\sum_k\binom{n-1}{k-1} = n2^{n-1}\).

  4. Use two terms beyond the linear one to estimate \(\sqrt[3]{1.03}\).
    Answer

    \(\binom{1/3}{2} = -\frac19\): \((1 + x)^{1/3} \approx 1 + \frac x3 - \frac{x^2}{9}\). At \(x = 0.03\): \(1.0099\); the true value is \(1.009902\ldots\).
