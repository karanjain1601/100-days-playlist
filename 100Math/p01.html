Functions, Geometry, Trigonometry & Complex Numbers

Phase 1 makes the function the central object: domains, inverses and transformations, then every standard family (polynomial, rational, exponential, logarithmic, trigonometric, hyperbolic) and the complex numbers that tie the exponential to rotation. It turns Phase 0's algebra into pictures you can sketch and invert, and it supplies the sigmoid, softmax, quadratic forms and complex eigenvalues that Phases 3, 4 and 7 build on.

By the end of this phase you can

  • Find the natural domain of any formula, decide whether a function is injective or surjective, and invert it on a suitable restricted domain.
  • Sketch any transformation \(a\,f(b(x - h)) + k\) of a library function, and any rational function from its intercepts, asymptotes, holes and sign chart.
  • Write lines and planes from given data, compute point-to-line and point-to-plane distances, and classify a conic by its discriminant and rotate it to standard form.
  • Prove \(\sigma(-x) = 1 - \sigma(x)\), show softmax is shift invariant, and evaluate log-sum-exp stably by subtracting the maximum.
  • Evaluate the six trig functions at standard angles, solve triangles (including the ambiguous SSA case), and derive the angle-sum formulas.
  • Derive the closed forms of the inverse hyperbolic functions and verify \(\tanh x = 2\sigma(2x) - 1\).
  • Compute powers and roots of complex numbers in polar form, and factor a real polynomial over \(\R\) and \(\C\) using conjugate pairs.

L12 · DAY 10

Functions: The Central Object

36m video50m practice

A function assigns to every input exactly one output. Its domain says where the rule can be run, and two properties, injectivity and surjectivity, decide whether it can be run backwards; everything later (inverse trig, logarithms, change of variables, invertible matrices) is an instance of this.

What a function is

Definition

A function \(f : A \to B\) assigns to each \(a \in A\) exactly one \(f(a) \in B\). Formally it is a set of ordered pairs \(f \subseteq A \times B\) in which every \(a \in A\) appears as a first coordinate exactly once. \(A\) is the domain, \(B\) the codomain, and the range (or image) is \(f(A) = \{f(a) : a \in A\} \subseteq B\).

The codomain is part of the declaration, the range is what actually gets hit. \(f : \R \to \R\), \(f(x) = x^2\) has codomain \(\R\) but range \([0, \infty)\). The difference matters: the same formula is not surjective onto \(\R\) but is surjective onto \([0,\infty)\).

Well-definedness means the rule really produces one output per input. Graphically, every vertical line meets the graph at most once (the vertical line test). It can fail subtly when inputs have several names: "\(f(p/q) = p + q\)" on \(\Q\) sends \(\tfrac12\) to 3 and \(\tfrac24\) to 6, though \(\tfrac12 = \tfrac24\). Not a function.

  • Identity \(\mathrm{id}_A(x) = x\) and constant functions \(f(x) = c\) are the simplest cases.
  • Piecewise definitions use different formulas on different parts of the domain, e.g. \(|x|\); the pieces must not disagree where they overlap.
  • Implicit definitions give a relation instead of a formula. \(x^2 + y^2 = 1\) is not the graph of one function (it fails the vertical line test), but it contains two explicit ones, \(y = \sqrt{1 - x^2}\) and \(y = -\sqrt{1 - x^2}\) on \([-1, 1]\).

Natural domains

When only a formula is given, the domain is understood to be the largest set of reals where it makes sense. Three rules cover almost everything: no division by zero; even roots only of non-negative numbers; logarithms only of positive numbers.

Worked example

Domain of \(\dfrac{\ln(x^2 - 4)}{\sqrt{6 - x}}\).

Log: \(x^2 - 4 > 0\), so \(x < -2\) or \(x > 2\). Root in a denominator: \(6 - x > 0\) (strictly, since the root is also a denominator), so \(x < 6\). Intersect:

$$\operatorname{dom} f = (-\infty, -2) \cup (2, 6).$$

Injective, surjective, bijective

Definition
  • Injective (one-to-one): \(f(a) = f(b) \Rightarrow a = b\). Every horizontal line meets the graph at most once.
  • Surjective (onto): every \(b \in B\) equals \(f(a)\) for some \(a\). Range = codomain.
  • Bijective: both. Every \(b \in B\) is hit exactly once.
Worked example

\(f(x) = x^3 + x\) is a bijection \(\R \to \R\).

Injective. Suppose \(a^3 + a = b^3 + b\). Then \((a - b)(a^2 + ab + b^2 + 1) = 0\). The second factor is \(\left(a + \tfrac b2\right)^2 + \tfrac34 b^2 + 1 \ge 1 > 0\), so \(a = b\). (Equivalently: \(f\) is strictly increasing, as a sum of two strictly increasing functions.)

Surjective. Given \(y\), \(f\) is continuous with \(f(x) \to \pm\infty\) as \(x \to \pm\infty\), so it takes a value below \(y\) and one above, and by the Intermediate Value Theorem (L61) it takes the value \(y\) in between. Note that we proved \(f^{-1}\) exists without finding a formula for it.

Composition

\((f\circ g)(x) = f(g(x))\): apply \(g\) first. Its domain is \(\{x \in \operatorname{dom} g : g(x) \in \operatorname{dom} f\}\), which can be smaller than the formula suggests. Composition is associative, \((f\circ g)\circ h = f\circ(g\circ h)\), but not commutative: with \(f(x) = x + 1\) and \(g(x) = x^2\), \(f(g(x)) = x^2 + 1\) while \(g(f(x)) = (x + 1)^2\).

Example of the domain shrinking: \(f(u) = u^2\), \(g(x) = \sqrt x\). The formula \(f(g(x)) = x\) looks defined everywhere, but \(f\circ g\) only accepts \(x \ge 0\), because \(g\) has to run first.

Inverse functions

Theorem · existence of an inverse

\(f : A \to B\) has an inverse \(f^{-1} : B \to A\), meaning \(f^{-1}(f(a)) = a\) for all \(a\) and \(f(f^{-1}(b)) = b\) for all \(b\), if and only if \(f\) is bijective.

Proof. If \(f\) is bijective, each \(b\) has exactly one preimage; call it \(f^{-1}(b)\). Conversely, if \(f^{-1}\) exists, \(f(a) = f(a')\) gives \(a = f^{-1}(f(a)) = f^{-1}(f(a')) = a'\) (injective), and every \(b = f(f^{-1}(b))\) is hit (surjective).

The picture. \((a, b)\) is on the graph of \(f\) iff \((b, a)\) is on the graph of \(f^{-1}\), so the two graphs are mirror images in the line \(y = x\). Restricting the domain rescues invertibility: \(x^2\) is not injective on \(\R\), but on \([0, \infty)\) it is a bijection onto \([0, \infty)\) with inverse \(\sqrt x\). Every inverse trig function (L19) is built this way.

Worked example

Invert \(f(x) = \dfrac{2x + 1}{x - 3}\).

Write \(y = \frac{2x + 1}{x - 3}\) and solve for \(x\): \(y(x - 3) = 2x + 1\), so \(xy - 2x = 3y + 1\) and \(x = \frac{3y + 1}{y - 2}\). Hence

$$f^{-1}(x) = \frac{3x + 1}{x - 2}, \qquad f : \R\setminus\{3\} \to \R\setminus\{2\}.$$

The value 2 is never attained (it is the horizontal asymptote), which is exactly the input \(f^{-1}\) cannot accept. Check: \(f(f^{-1}(x)) = \dfrac{2\frac{3x+1}{x-2} + 1}{\frac{3x+1}{x-2} - 3} = \dfrac{7x}{7} = x\).

Common errors
  • \(f^{-1}(x) \ne 1/f(x)\). The inverse undoes \(f\); the reciprocal divides by it. (\(x^{-1}\) means reciprocal; \(f^{-1}\) means inverse.)
  • Order of composition. \(f\circ g\) means "\(g\) first". Reading left to right gives the wrong function.
  • Domain of a composite from the simplified formula. \((\sqrt x)^2 = x\) only for \(x \ge 0\).
  • Claiming an inverse exists without injectivity. Solving \(y = x^2\) for \(x\) gives \(\pm\sqrt y\): two answers, so no function, until you restrict.
  • Range versus codomain. "Is \(e^x\) surjective?" has no answer until the codomain is stated: no onto \(\R\), yes onto \((0, \infty)\).

Practice · 50 min

  1. Prove it. If \(f\) and \(g\) are injective, then \(f\circ g\) is injective. Hint: start from \(f(g(a)) = f(g(b))\) and peel off one function at a time, outermost first.
    Proof sketch

    Suppose \((f\circ g)(a) = (f\circ g)(b)\), i.e. \(f(g(a)) = f(g(b))\). Since \(f\) is injective, \(g(a) = g(b)\). Since \(g\) is injective, \(a = b\). So \(f\circ g\) is injective. (The same pattern shows that a composition of surjections is surjective, hence of bijections is bijective, with \((f\circ g)^{-1} = g^{-1}\circ f^{-1}\).)

  2. With \(f(x) = \sqrt x\) and \(g(x) = x^2 - 4\), find \(f\circ g\) and \(g\circ f\) and their domains.
    Answer

    \(f(g(x)) = \sqrt{x^2 - 4}\), domain \(|x| \ge 2\). \(g(f(x)) = x - 4\), domain \(x \ge 0\) (not all of \(\R\)).

  3. Injective? Surjective? (a) \(e^x : \R \to \R\); (b) \(x^3 - x : \R \to \R\); (c) \(n \mapsto 2n : \Z \to \Z\).
    Answer

    (a) Injective, not surjective (misses \((-\infty, 0]\)). (b) Surjective (odd-degree polynomial, IVT), not injective: \(0\), \(1\), \(-1\) all map to 0. (c) Injective, not surjective (odd numbers missed).

  4. If \(g\circ f\) is injective, must \(f\) be injective? Must \(g\)?
    Answer

    \(f\) must: \(f(a) = f(b) \Rightarrow g(f(a)) = g(f(b)) \Rightarrow a = b\). \(g\) need not: \(f(x) = e^x\), \(g(x) = x^2\) gives \(g(f(x)) = e^{2x}\), injective, though \(g\) is not.

  5. Find the natural domain and the inverse of \(h(x) = \ln(x - 1) + 2\), and state the range of \(h\).
    Answer

    Domain \((1, \infty)\), range \(\R\). \(y - 2 = \ln(x - 1)\) gives \(h^{-1}(x) = e^{x-2} + 1\), defined on \(\R\) with range \((1, \infty)\): the roles swap.

Read Velleman, How to Prove It, Ch. 5 (Functions) · Spivak, Calculus, Ch. 3–4 (functions and graphs)

Graphs & Transformations

28m video35m practiceheavy lesson

Every shift, stretch and reflection of a graph is a composition with a linear map, applied either to the output (acting exactly as written) or to the input (acting backwards). Six memorized shapes plus that one rule let you sketch most formulas without plotting points.

The six library functions

Shifts, stretches and reflections

Rule · the point map

If \((u, v)\) is on the graph of \(y = f(x)\), then \(\left(\dfrac ub + h,\ a v + k\right)\) is on the graph of \(y = a\,f\big(b(x - h)\big) + k\) (for \(b \ne 0\)).

Check: at \(x = u/b + h\) the inner expression is \(b(x - h) = u\), so \(y = a f(u) + k = av + k\).

FormulaEffect on the graph
\(f(x) + k\)up by \(k\)
\(f(x - h)\)right by \(h\) (so \(f(x + 2)\) moves left)
\(a\,f(x)\)vertical stretch by \(|a|\); reflection in the \(x\)-axis if \(a < 0\)
\(f(bx)\)horizontal compression by \(|b|\) (stretch if \(|b| < 1\)); reflection in the \(y\)-axis if \(b < 0\)

Why horizontal changes run backwards. Outputs are changed after \(f\) acts, so \(f(x) + 3\) adds 3 to every height. Inputs are changed before \(f\) acts: to make \(f(x - 3)\) produce the value \(f\) had at \(u\), you must feed it \(x = u + 3\). Every feature arrives 3 units later, i.e. further right. Likewise \(f(2x)\) reaches each input twice as fast, so the graph is squeezed toward the axis.

Order of operations

Transformations do not commute, so read them as the order in which you would compute: inside first, factored. Write \(f(2x - 6) = f\big(2(x - 3)\big)\): compress by 2, then shift right 3 (or equivalently shift right 6, then compress by 2 toward the \(y\)-axis). On the outside, \(a f(\cdot) + k\) scales first, then shifts, exactly as in arithmetic.

Worked example

Graph \(y = -2|x - 3| + 1\) in stages.

  1. \(|x|\): V with corner at \((0, 0)\).
  2. \(|x - 3|\): shift right 3; corner at \((3, 0)\).
  3. \(-2|x - 3|\): stretch vertically by 2 and reflect in the \(x\)-axis; an upside-down V with slopes \(\pm2\).
  4. \(-2|x - 3| + 1\): shift up 1; vertex \((3, 1)\).

Key points: the \(x\)-intercepts solve \(|x - 3| = \tfrac12\), so \(x = 2.5\) and \(3.5\); the \(y\)-intercept is \(-2\cdot3 + 1 = -5\). Range \((-\infty, 1]\).

Even and odd functions

Definition

On a domain symmetric about 0, \(f\) is even if \(f(-x) = f(x)\) for all \(x\) (graph symmetric in the \(y\)-axis) and odd if \(f(-x) = -f(x)\) (graph symmetric under a half-turn about the origin; an odd function defined at 0 has \(f(0) = 0\)).

Parity algebra: sums of even functions are even, sums of odd are odd; even·even and odd·odd are even; even·odd is odd. Most functions are neither.

Worked example · classify
  • \(x^3 - x\): \((-x)^3 - (-x) = -x^3 + x = -(x^3 - x)\). Odd.
  • \(x^4 + \cos x\): \((-x)^4 + \cos(-x) = x^4 + \cos x\). Even.
  • \(x + \sin x\): \(-x + \sin(-x) = -(x + \sin x)\). Odd (sum of two odd functions).
  • For contrast, \(x + \cos x\): at \(x = 0\) it equals 1, so it is not odd; \(f(-1) = -1 + \cos1 \ne 1 + \cos1 = f(1)\), so it is not even. Neither.

Periodicity, monotonicity, bounds and concavity

Definitions
  • Periodic with period \(T > 0\): \(f(x + T) = f(x)\) for all \(x\). The smallest such \(T\), if it exists, is the fundamental period: \(2\pi\) for \(\sin\), \(\pi\) for \(\tan\). (A constant function has every period and no smallest one.)
  • Increasing on \(I\): \(a < b \Rightarrow f(a) < f(b)\) (non-decreasing with \(\le\)); decreasing similarly; monotone if one or the other.
  • Bounded above if \(f(x) \le M\) for all \(x\); below likewise. \(\sin\) is bounded; \(x^2\) only below; \(x^3\) neither.
  • Concave up (convex) on \(I\) if every chord lies on or above the graph; concave down if on or below. \(x^2\) and \(e^x\) are concave up, \(\sqrt x\) and \(\ln x\) concave down, and \(x^3\) switches at 0.

A strictly monotone function is injective, so it has an inverse on its range (L12). Concavity is defined here by chords; L66 connects it to the second derivative, and L90 makes convexity the central idea of optimization.

Common errors
  • \(f(x + 2)\) moves the graph left, not right.
  • Shifting before factoring. \(f(2x - 6)\) is a shift of 3 after the compression, not 6.
  • \(-f(x)\) versus \(f(-x)\). The first reflects in the \(x\)-axis, the second in the \(y\)-axis.
  • "Odd function" means odd powers. Parity is about \(f(-x)\); \(\cos x\) has no powers at all and is even, and \(x^3 + 1\) has an odd power and is neither.
  • Asymmetric domains. \(\sqrt x\) cannot be even or odd: \(f(-x)\) is not even defined for \(x > 0\).

Practice · 35 min

  1. Prove it. Every \(f : \R \to \R\) can be written uniquely as the sum of an even and an odd function. Hint: if \(f = E + O\), evaluate at \(x\) and \(-x\) and solve the two equations for \(E(x)\) and \(O(x)\).
    Proof sketch

    Uniqueness (and the formulas). If \(f = E + O\), then \(f(x) = E(x) + O(x)\) and \(f(-x) = E(x) - O(x)\). Adding and subtracting forces \(E(x) = \frac{f(x) + f(-x)}{2}\) and \(O(x) = \frac{f(x) - f(-x)}{2}\). Existence. Define \(E, O\) by those formulas; then \(E(-x) = E(x)\), \(O(-x) = -O(x)\), and \(E + O = f\). (Alternative uniqueness argument: if \(E_1 + O_1 = E_2 + O_2\), then \(E_1 - E_2 = O_2 - O_1\) is both even and odd, and \(g(x) = g(-x) = -g(x)\) forces \(g = 0\).) Example: \(e^x = \cosh x + \sinh x\) (L20).

  2. Describe \(y = \sqrt{4 - x} - 1\) as transformations of \(\sqrt x\), and give its domain and range.
    Answer

    \(\sqrt{-(x - 4)} - 1\): reflect in the \(y\)-axis, shift right 4, down 1. Domain \((-\infty, 4]\), range \([-1, \infty)\), starting point \((4, -1)\).

  3. Find the even and odd parts of \(f(x) = \frac{1}{1 - x}\) (\(x \ne \pm1\)).
    Answer

    \(E(x) = \frac12\left(\frac1{1-x} + \frac1{1+x}\right) = \frac{1}{1 - x^2}\), \(O(x) = \frac{x}{1 - x^2}\).

  4. Show that a product of two odd functions is even, and a composition of two odd functions is odd. What is \(f\circ g\) if \(g\) is even?
    Answer

    \(f(-x)g(-x) = (-f(x))(-g(x)) = f(x)g(x)\). \(f(g(-x)) = f(-g(x)) = -f(g(x))\). If \(g\) is even, \(f(g(-x)) = f(g(x))\): even, whatever \(f\) is.

  5. Find the fundamental period of \(\sin 3x + \cos 2x\), and sketch \(y = \frac{1}{x + 2} - 1\) with its asymptotes.
    Answer

    Periods \(2\pi/3\) and \(\pi\); the smallest common multiple is \(2\pi\). The hyperbola \(1/x\) shifted left 2 and down 1: asymptotes \(x = -2\), \(y = -1\); it crosses the \(x\)-axis at \(x = -1\).

L14 · DAY 11

Lines, Planes & Coordinate Geometry in 2D and 3D

30m video40m practiceheavy lesson

Coordinates turn geometry into algebra: lines in the plane and planes in space are single linear equations, and the coefficient vector of that equation is a normal vector. Perpendicularity, distances and intersections all come from that one observation.

Coordinates, distance and midpoint

A point in \(\R^2\) is a pair \((x, y)\); in \(\R^3\) a triple \((x, y, z)\). By Pythagoras, once in the plane and once more for the vertical leg,

$$d = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2 + (z_2 - z_1)^2}, \qquad M = \left(\tfrac{x_1 + x_2}{2}, \tfrac{y_1 + y_2}{2}, \tfrac{z_1 + z_2}{2}\right),$$

(drop the \(z\) terms in 2D). The 3D axes are right-handed: curl the fingers of your right hand from the positive \(x\)-axis to the positive \(y\)-axis and your thumb points along positive \(z\). The coordinate planes split space into eight octants; the first has \(x, y, z > 0\). Handedness matters because the cross product (L37) and orientation of determinants depend on it.

Lines in the plane

The slope through \((x_1, y_1)\), \((x_2, y_2)\) is \(m = \frac{y_2 - y_1}{x_2 - x_1}\) (undefined for vertical lines). Four equivalent forms:

FormEquationUse when you know
slope-intercept\(y = mx + b\)slope and \(y\)-intercept
point-slope\(y - y_1 = m(x - x_1)\)slope and one point
two-point\(y - y_1 = \frac{y_2 - y_1}{x_2 - x_1}(x - x_1)\)two points
general\(Ax + By = C\)any line, vertical ones included

Non-vertical lines are parallel iff \(m_1 = m_2\) and perpendicular iff \(m_1 m_2 = -1\) (the Prove it). In general form the slope is \(-A/B\), so the vector \(\mathbf n = (A, B)\) has slope \(B/A\), and \((-A/B)(B/A) = -1\): \((A, B)\) is perpendicular to the line. It is the line's normal vector. Two lines are parallel iff their normals are proportional.

Distance from a point to a line

Theorem · point-to-line distance

The distance from \((x_0, y_0)\) to the line \(Ax + By + C = 0\) is \(\ d = \dfrac{|Ax_0 + By_0 + C|}{\sqrt{A^2 + B^2}}\).

Derivation

The shortest path to the line is perpendicular to it, i.e. along \(\mathbf n = (A, B)\). So the foot of the perpendicular is \((x_0 - tA,\ y_0 - tB)\) for the \(t\) that puts it on the line: \(A(x_0 - tA) + B(y_0 - tB) + C = 0\), giving \(t = \frac{Ax_0 + By_0 + C}{A^2 + B^2}\). The distance is the length of \(t\,\mathbf n\): \(|t|\sqrt{A^2 + B^2} = \frac{|Ax_0 + By_0 + C|}{\sqrt{A^2 + B^2}}\).

Worked example

Distance from \((3, 4)\) to \(3x - 4y + 5 = 0\).

$$d = \frac{|3\cdot 3 - 4\cdot 4 + 5|}{\sqrt{3^2 + 4^2}} = \frac{|-2|}{5} = \frac25.$$

Here \(t = -2/25\), so the foot is \((3, 4) + \tfrac{2}{25}(3, -4) = (3.24, 3.68)\); check: \(3(3.24) - 4(3.68) + 5 = 0\).

Planes in 3D

A plane is determined by a point \(P_0 = (x_0, y_0, z_0)\) on it and a normal vector \(\mathbf n = (a, b, c)\): a point \(P\) is on the plane iff \(P - P_0\) is perpendicular to \(\mathbf n\),

$$a(x - x_0) + b(y - y_0) + c(z - z_0) = 0, \qquad\text{i.e.}\qquad ax + by + cz = d.$$

As in 2D, the coefficients are the normal. Three non-collinear points determine a plane.

Worked example

The plane through \(P = (1, 2, 3)\), \(Q = (2, 0, 1)\), \(R = (0, 1, 1)\).

Two directions in the plane: \(Q - P = (1, -2, -2)\) and \(R - P = (-1, -1, -2)\). The normal \((a, b, c)\) must be perpendicular to both:

$$a - 2b - 2c = 0, \qquad -a - b - 2c = 0.$$

Adding: \(-3b - 4c = 0\), so \(b = -\tfrac43 c\), then \(a = 2b + 2c = -\tfrac23 c\). Take \(c = -3\): \(\mathbf n = (2, 4, -3)\). Then \(d = 2(1) + 4(2) - 3(3) = 1\), so the plane is \(2x + 4y - 3z = 1\). Check \(Q\): \(4 + 0 - 3 = 1\); \(R\): \(0 + 4 - 3 = 1\). (The cross product of L37 produces \(\mathbf n\) in one step.)

Lines, intersections and spheres in 3D

In 3D a single equation is a plane, so a line needs a parametric description: a point \(P_0\) and a direction \(\mathbf v = (v_1, v_2, v_3)\),

$$\mathbf r(t) = P_0 + t\,\mathbf v, \qquad\text{or, if all } v_i \ne 0,\qquad \frac{x - x_0}{v_1} = \frac{y - y_0}{v_2} = \frac{z - z_0}{v_3}\ \ \text{(symmetric form)}.$$
Worked example

The line through \(A = (1, -1, 2)\) and \(B = (3, 2, -1)\).

Direction \(\mathbf v = B - A = (2, 3, -3)\). Parametric: \(\mathbf r(t) = (1 + 2t,\ -1 + 3t,\ 2 - 3t)\), with \(t = 0\) at \(A\) and \(t = 1\) at \(B\). Symmetric: \(\frac{x - 1}{2} = \frac{y + 1}{3} = \frac{z - 2}{-3}\).

Where does it meet the plane \(2x + 4y - 3z = 1\)? Substitute: \(2(1 + 2t) + 4(-1 + 3t) - 3(2 - 3t) = 25t - 8 = 1\), so \(t = \tfrac{9}{25}\) and the point is \(\left(\tfrac{43}{25}, \tfrac{2}{25}, \tfrac{23}{25}\right)\).

  • Line and plane: substituting gives a linear equation in \(t\): one solution (they cross), none (parallel), or every \(t\) (the line lies in the plane).
  • Two planes: parallel (proportional normals) or meeting in a line whose direction is perpendicular to both normals.
  • Two lines: they intersect, are parallel, or are skew: not parallel and never meeting, which cannot happen in the plane.
  • Sphere with centre \((a, b, c)\) and radius \(r\): \((x - a)^2 + (y - b)^2 + (z - c)^2 = r^2\). Complete the square to read off centre and radius: \(x^2 + y^2 + z^2 - 2x + 4y - 6z + 5 = 0\) is \((x - 1)^2 + (y + 2)^2 + (z - 3)^2 = 9\).
Common errors
  • Using \(m_1m_2 = -1\) with a vertical line. A vertical and a horizontal line are perpendicular but the vertical slope is undefined. Normals \((A, B)\) handle every case: perpendicular iff \(A_1A_2 + B_1B_2 = 0\).
  • Sign of \(C\) in the distance formula. The formula needs the line as \(Ax + By + C = 0\). For \(3x + 4y = 2\), \(C = -2\).
  • Normal versus direction. In \(Ax + By = C\), \((A, B)\) is perpendicular to the line; a direction vector is \((B, -A)\).
  • Symmetric form with a zero component. If \(v_2 = 0\), write \(\frac{x - x_0}{v_1} = \frac{z - z_0}{v_3},\ y = y_0\); never divide by 0.
  • Three collinear points do not determine a plane: the two difference vectors are parallel and the normal equations have a whole plane of solutions.

Quadratics & Conic Sections

32m video45m practice

Every conic is the zero set of a quadratic in \(x\) and \(y\). Without an \(xy\) term, completing the square reads off its shape; with one, a rotation removes it, and that rotation is exactly the eigenvector problem for a symmetric \(2\times2\) matrix.

Completing the square in two variables

A quadratic \(y = ax^2 + bx + c\) has vertex form \(y = a(x - h)^2 + k\), with vertex \((h, k)\), found by completing the square (L8). With both \(x^2\) and \(y^2\) present, complete the square separately in each variable, multiplying each added constant by its coefficient.

Worked example

\(9x^2 + 4y^2 - 36x + 8y + 4 = 0\).

$$9(x^2 - 4x) + 4(y^2 + 2y) = -4$$ $$9\big[(x - 2)^2 - 4\big] + 4\big[(y + 1)^2 - 1\big] = -4 \quad\Longrightarrow\quad 9(x - 2)^2 + 4(y + 1)^2 = 36$$ $$\frac{(x - 2)^2}{4} + \frac{(y + 1)^2}{9} = 1.$$

An ellipse with centre \((2, -1)\), semi-axes 2 (horizontal) and 3 (vertical), so the major axis is vertical. \(c = \sqrt{9 - 4} = \sqrt5\), foci \((2, -1 \pm \sqrt5)\), eccentricity \(\sqrt5/3\).

The conics as loci

Definitions
  • Parabola: points equidistant from a focus and a line (the directrix). With focus \((0, p)\) and directrix \(y = -p\): \(x^2 + (y - p)^2 = (y + p)^2\), which simplifies to \(x^2 = 4py\).
  • Circle: points at distance \(r\) from a centre: \((x - h)^2 + (y - k)^2 = r^2\).
  • Ellipse: points whose distances to two foci sum to a constant \(2a\). Standard form \(\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1\) (\(a \ge b > 0\)), foci \((\pm c, 0)\) with \(c^2 = a^2 - b^2\), major axis length \(2a\), minor \(2b\), eccentricity \(e = c/a \in [0, 1)\) (0 for a circle).
  • Hyperbola: points whose distances to two foci differ by \(2a\). Standard form \(\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1\), foci \((\pm c, 0)\) with \(c^2 = a^2 + b^2\), asymptotes \(y = \pm\frac ba x\), eccentricity \(e = c/a > 1\).

The sign in front of \(b^2\) is the whole difference: \(c^2 = a^2 - b^2\) for an ellipse (the foci are inside), \(c^2 = a^2 + b^2\) for a hyperbola (the foci are beyond the vertices). The Prove it derives the focal property from the equation.

The general equation and the discriminant

Every conic has an equation \(Ax^2 + Bxy + Cy^2 + Dx + Ey + F = 0\). Its type is decided by the discriminant \(B^2 - 4AC\):

DiscriminantType (if non-degenerate)Example
\(< 0\)ellipse (circle if \(B = 0\), \(A = C\))\(x^2 + 3y^2 = 1\): \(-12\)
\(= 0\)parabola\(y = x^2\): \(0\)
\(> 0\)hyperbola\(xy = 1\): \(1\)

Degenerate cases pass the same test: \(x^2 + y^2 = -1\) is empty, \(x^2 + y^2 = 0\) a single point, \(x^2 - y^2 = 0\) a pair of lines.

Rotation of axes

Rotate coordinates by \(\theta\): \(x = x'\cos\theta - y'\sin\theta\), \(y = x'\sin\theta + y'\cos\theta\). Substituting into \(Ax^2 + Bxy + Cy^2\) and collecting the \(x'y'\) terms gives the new cross coefficient

$$B' = B\cos2\theta - (A - C)\sin2\theta, \qquad\text{so } B' = 0 \text{ when } \cot2\theta = \frac{A - C}{B}.$$

A short calculation shows \(B'^2 - 4A'C' = B^2 - 4AC\): the discriminant does not depend on how the axes are drawn, which is why it can classify the curve.

Worked example

Classify \(5x^2 + 4xy + 5y^2 = 9\) and find its axes.

\(B^2 - 4AC = 16 - 100 = -84 < 0\): an ellipse. \(A = C\) gives \(\cot2\theta = 0\), so \(\theta = 45^\circ\). With \(x = \frac{x' - y'}{\sqrt2}\), \(y = \frac{x' + y'}{\sqrt2}\): \(x^2 + y^2 = x'^2 + y'^2\) and \(xy = \frac{x'^2 - y'^2}{2}\). So

$$5(x'^2 + y'^2) + 2(x'^2 - y'^2) = 9 \quad\Longrightarrow\quad 7x'^2 + 3y'^2 = 9 \quad\Longrightarrow\quad \frac{x'^2}{9/7} + \frac{y'^2}{3} = 1.$$

Semi-axis \(\sqrt{9/7} \approx 1.13\) along the line \(y = x\), and \(\sqrt3 \approx 1.73\) along \(y = -x\), which is therefore the major axis.

Conics as quadratic forms

The quadratic part of any conic is a quadratic form:

$$Ax^2 + Bxy + Cy^2 = \begin{pmatrix} x & y \end{pmatrix}\begin{pmatrix} A & B/2 \\ B/2 & C\end{pmatrix}\begin{pmatrix} x \\ y\end{pmatrix} = \mathbf x^{\mathsf T} M\mathbf x,$$

with a symmetric \(M\) (the \(xy\) coefficient is split evenly). A centred conic is \(\mathbf x^{\mathsf T}M\mathbf x = 1\), and \(B^2 - 4AC = -4\det M\): an ellipse when \(\det M > 0\) (eigenvalues of the same sign), a hyperbola when \(\det M < 0\). This is the bridge to two later results. In Phase 3, the spectral theorem says every symmetric \(M\) has perpendicular eigenvectors, so every conic can be rotated to standard form. In Phase 7, the multivariate Gaussian density is constant on the ellipses \(\mathbf x^{\mathsf T}\Sigma^{-1}\mathbf x = k\) (L105), whose axes are the eigenvectors of the covariance matrix \(\Sigma\): the picture behind PCA.

Common errors
  • Forgetting the coefficient when completing the square. \(9(x^2 - 4x) = 9(x - 2)^2 - 36\), not \(-4\).
  • Mixing up \(a\) and \(b\). The major axis goes with the larger denominator, whichever variable it sits under.
  • \(c^2\) with the wrong sign. Ellipse \(a^2 - b^2\), hyperbola \(a^2 + b^2\).
  • Using \(B/2\) in the discriminant, or \(B\) in the matrix. The discriminant uses the full \(xy\) coefficient; the matrix splits it in half.
  • Trusting the classifier on degenerate equations. \(x^2 + y^2 + 1 = 0\) has negative discriminant and no points at all.

Polynomial & Rational Function Behaviour

30m video40m practice

Far from the origin a polynomial behaves like its leading term; near a root it behaves like a power of \((x - r)\). Rational functions add asymptotes, and every asymptote comes out of a polynomial division. Those three facts are enough to sketch any of them before calculus.

End behaviour

For \(p(x) = a_n x^n + \dots + a_0\) with \(a_n \ne 0\), factor out the leading term: \(p(x) = a_n x^n\left(1 + \frac{a_{n-1}}{a_n x} + \dots + \frac{a_0}{a_n x^n}\right)\). The bracket tends to 1 as \(|x| \to \infty\), so the sign and growth of \(p\) for large \(|x|\) are those of \(a_n x^n\).

Leading coefficient positiveLeading coefficient negative
\(n\) evenup on both endsdown on both ends
\(n\) odddown on the left, up on the rightup on the left, down on the right

Roots and multiplicity: crossing versus touching

If \(r\) is a root of multiplicity \(m\), then \(p(x) = (x - r)^m q(x)\) with \(q(r) \ne 0\) (L6). Near \(r\), \(q(x) \approx q(r)\), so \(p(x) \approx q(r)(x - r)^m\): the graph looks like a shifted, scaled \(x^m\).

  • \(m\) odd: \((x - r)^m\) changes sign, so the graph crosses the axis. For \(m \ge 3\) it flattens as it crosses, like \(x^3\).
  • \(m\) even: no sign change; the graph touches the axis and turns back, like \(x^2\).

The sign of \(p\) can therefore change only at roots of odd multiplicity, which is why the sign charts of L8 work.

Locating roots: the intermediate-value idea

A polynomial's graph has no jumps (it is continuous; L61 proves the theorem). So if \(p(a) < 0 < p(b)\), there is a root between \(a\) and \(b\). Halving the interval repeatedly (bisection) traps it as tightly as you like.

Example

Bracket the real root of \(x^3 - 2x - 5\).

\(p(2) = -1\), \(p(3) = 16\): a root in \((2, 3)\). \(p(2.5) = 5.625 > 0\): root in \((2, 2.5)\). \(p(2.25) \approx 1.89\): \((2, 2.25)\). \(p(2.125) \approx 0.346\): \((2, 2.125)\). \(p(2.0625) \approx -0.351\): \((2.0625, 2.125)\). Each step halves the uncertainty; the root is about \(2.0946\).

Rational functions: asymptotes and holes

For \(f = p/q\) in which \(p\) and \(q\) share a factor \(x - a\), cancel it first. What remains decides the behaviour at \(a\):

  • Hole (removable discontinuity): if \(x - a\) cancels completely from the denominator, \(f\) is undefined at \(a\) but approaches the value of the reduced formula there.
  • Vertical asymptote \(x = a\): if \(x - a\) survives in the reduced denominator, \(|f(x)| \to \infty\) as \(x \to a\).
Worked example

The hole in \(\dfrac{x^2 - 4}{x - 2}\).

\(\dfrac{(x - 2)(x + 2)}{x - 2} = x + 2\) for \(x \ne 2\). The graph is the line \(y = x + 2\) with the single point \((2, 4)\) removed: a hole, not an asymptote. Had we not factored, "denominator zero at 2" would have suggested an asymptote that is not there.

Horizontal and oblique asymptotes come from comparing degrees, \(\deg p = n\), \(\deg q = d\):

DegreesFar from the originExample
\(n < d\)\(f \to 0\): asymptote \(y = 0\)\(\frac{x}{x^2 + 1}\)
\(n = d\)\(f \to\) ratio of leading coefficients\(\frac{3x^2 + 1}{x^2 - 4} \to 3\)
\(n = d + 1\)oblique (slant) line: the quotient of \(p \div q\)\(\frac{x^2 - x - 6}{x - 1}\), below
\(n \ge d + 2\)curvilinear: a polynomial of degree \(n - d\)\(\frac{x^3 + 1}{x} = x^2 + \frac1x\), asymptotic to \(y = x^2\)

The rule behind every row: divide, \(p = qs + r\) with \(\deg r < \deg q\), so \(f = s + r/q\) and \(r/q \to 0\). The polynomial \(s\) is the asymptote. A graph may cross a horizontal or slant asymptote at finite \(x\); asymptotes describe only the ends.

The sketching checklist

Algorithm

Sketch \(y = f(x)\) for a rational \(f\).

  1. Domain: exclude zeros of the denominator. Factor and cancel; record holes.
  2. Intercepts: \(x\)-intercepts from zeros of the reduced numerator; \(y\)-intercept \(f(0)\).
  3. Asymptotes: vertical from the reduced denominator; horizontal, slant or curvilinear from division.
  4. Sign chart: signs between consecutive critical points; which side of each vertical asymptote goes up.
  5. Shape: join the pieces consistently with signs, intercepts and asymptotes; note whether the graph lies above or below the end asymptote from the sign of \(r/q\).
Worked example

Full sketch of \(f(x) = \dfrac{x^2 - x - 6}{x - 1}\).

  1. Domain \(x \ne 1\). Numerator \((x - 3)(x + 2)\) shares no factor with \(x - 1\): no holes.
  2. \(x\)-intercepts \(-2\) and \(3\); \(y\)-intercept \(f(0) = \frac{-6}{-1} = 6\).
  3. Vertical asymptote \(x = 1\). Division: \(x^2 - x - 6 = (x - 1)\cdot x - 6\), so \(f(x) = x - \frac{6}{x - 1}\): slant asymptote \(y = x\).
  4. Signs on \((-\infty, -2), (-2, 1), (1, 3), (3, \infty)\): \(-, +, -, +\). So \(f \to +\infty\) as \(x \to 1^-\) and \(f \to -\infty\) as \(x \to 1^+\).
  5. \(f(x) - x = -\frac{6}{x - 1}\) is positive for \(x < 1\) and negative for \(x > 1\): the left branch lies above \(y = x\), the right branch below.
Common errors
  • Every zero of the denominator is a vertical asymptote. Not if it cancels; then it is a hole.
  • "The graph never crosses an asymptote." Horizontal and slant asymptotes can be crossed: \(\frac{2x^2 + x}{x^2 + 1}\) equals its asymptote value 2 at \(x = 2\).
  • Leading-coefficient ratio when degrees differ. That rule is only for \(n = d\).
  • Sign change at a double root. \((x - 2)^2\) does not change sign; the graph bounces.
  • Forgetting the hole in the final answer. Draw an open circle at \((a, \text{value})\).

Exponential & Logarithmic Functions

34m video45m practice

Exponentials model anything whose rate of change is proportional to its size, and \(e\) is the base that makes the proportionality constant 1. Normalize exponentials and you get the sigmoid, softmax and log-sum-exp, the functions at the output of almost every classifier.

The exponential \(a^x\)

For \(a > 0\), \(a^x\) is defined for rational \(x\) by L4 and extended to all reals by continuity. Domain \(\R\), range \((0, \infty)\), \(a^0 = 1\), horizontal asymptote \(y = 0\), and it never touches it. For \(a > 1\) it increases (growth); for \(0 < a < 1\) it decreases (decay), and \(a^x = (1/a)^{-x}\) is the mirror image of a growth curve in the \(y\)-axis. All the exponent laws hold, the key one being \(a^{x + y} = a^x a^y\): adding inputs multiplies outputs.

Two definitions of \(e\), and why they agree

Definition $$e = \lim_{n\to\infty}\left(1 + \frac1n\right)^n \qquad\text{and}\qquad e = \sum_{k=0}^{\infty}\frac{1}{k!} = 1 + 1 + \frac12 + \frac16 + \frac1{24} + \cdots \approx 2.71828.$$
Why they agree

Let \(a_n = (1 + 1/n)^n\) and \(s_n = \sum_{k=0}^{n} 1/k!\). By the Binomial Theorem (L11),

$$a_n = \sum_{k=0}^{n}\binom nk\frac{1}{n^k} = \sum_{k=0}^{n}\frac{1}{k!}\cdot\frac{n}{n}\cdot\frac{n-1}{n}\cdots\frac{n-k+1}{n} = \sum_{k=0}^{n}\frac{1}{k!}\prod_{j=0}^{k-1}\left(1 - \frac jn\right).$$

Every product is at most 1, so \(a_n \le s_n < 3\); and each product grows with \(n\), so \(a_n\) is increasing. An increasing bounded sequence converges (completeness, L3), and \(\lim a_n \le \sum 1/k!\). In the other direction, fix \(m\); for \(n > m\), dropping the terms with \(k > m\) gives \(a_n \ge \sum_{k=0}^{m}\frac{1}{k!}\prod_{j<k}(1 - j/n)\), and as \(n \to \infty\) each of these finitely many products tends to 1. So \(\lim a_n \ge s_m\) for every \(m\), hence \(\lim a_n \ge \sum 1/k!\). Together, the two limits are equal. (The series converges far faster: \(s_6 \approx 2.71806\), while \(a_{1000} \approx 2.71692\).)

Growth, decay and compounding

Compounding. Interest at annual rate \(r\) compounded \(n\) times a year grows a principal \(P\) to \(P(1 + r/n)^{nt}\). Letting \(n \to \infty\) (substitute \(m = n/r\) and use the limit above) gives continuous compounding \(Pe^{rt}\): $1000 at 6% becomes $1060 compounded annually and about $1061.84 continuously.

Models. \(P(t) = P_0 e^{kt}\) is growth for \(k > 0\), decay for \(k < 0\). The doubling time solves \(e^{kT} = 2\): \(T = \ln 2/k\); the half-life is \(\ln 2/|k|\). The natural log is the inverse of \(e^x\), so it is the tool for solving: take \(\ln\) of both sides once the exponential is isolated (L5).

Worked example · population doubling

A culture of 500 cells doubles every 3 hours. Then \(P(t) = 500\cdot2^{t/3} = 500e^{kt}\) with \(k = \frac{\ln2}{3} \approx 0.231\) per hour. It reaches 10,000 when \(2^{t/3} = 20\): \(t = 3\log_2 20 = \frac{3\ln20}{\ln2} \approx 12.97\) hours.

Conversely, a population growing continuously at 5% a year doubles in \(\ln2/0.05 \approx 13.9\) years; this is the "rule of 70" (\(100\ln 2 \approx 69.3\), divided by the percentage rate).

The logistic sigmoid

Definition

\(\displaystyle\sigma(x) = \frac{1}{1 + e^{-x}}\). Domain \(\R\), range \((0, 1)\), strictly increasing, \(\sigma(0) = \tfrac12\), \(\sigma(x) \to 1\) as \(x \to \infty\) and \(\to 0\) as \(x \to -\infty\).

It squashes any real score into a probability. Its inverse is the logit, \(\sigma^{-1}(p) = \ln\frac{p}{1 - p}\), the log-odds. Two properties matter for learning. Symmetry: \(\sigma(-x) = 1 - \sigma(x)\) (the Prove it), so \(\sigma - \tfrac12\) is odd and the graph is symmetric about \((0, \tfrac12)\). Saturation: for \(|x|\) beyond about 5 the curve is nearly flat, its slope is nearly 0, and gradient-based learning through a saturated sigmoid stalls.

Worked example

The identity behind \(\sigma' = \sigma(1 - \sigma)\).

In Phase 4 the chain rule (L64) gives \(\frac{d}{dx}(1 + e^{-x})^{-1} = \frac{e^{-x}}{(1 + e^{-x})^2}\). The algebra that turns this into \(\sigma(1 - \sigma)\) can be done now:

$$1 - \sigma(x) = \frac{(1 + e^{-x}) - 1}{1 + e^{-x}} = \frac{e^{-x}}{1 + e^{-x}}, \qquad\text{so}\qquad \sigma(x)\big(1 - \sigma(x)\big) = \frac{1}{1 + e^{-x}}\cdot\frac{e^{-x}}{1 + e^{-x}} = \frac{e^{-x}}{(1 + e^{-x})^2}.$$

The derivative is a function of the output alone, which is why backpropagation through a sigmoid is cheap. Since \(t(1 - t) \le \tfrac14\), the slope never exceeds \(\tfrac14\).

Softmax and log-sum-exp

Definition

For scores \(\mathbf z = (z_1, \dots, z_n)\): \(\ \operatorname{softmax}(\mathbf z)_i = \dfrac{e^{z_i}}{\sum_{j} e^{z_j}}\) and \(\ \operatorname{LSE}(\mathbf z) = \log\sum_{j} e^{z_j}\).

Softmax outputs are positive and sum to 1: a probability distribution over \(n\) classes. With two classes it is the sigmoid of the score difference, \(\frac{e^{z_1}}{e^{z_1} + e^{z_2}} = \frac{1}{1 + e^{-(z_1 - z_2)}} = \sigma(z_1 - z_2)\). LSE is a smooth maximum: \(\max_i z_i \le \operatorname{LSE}(\mathbf z) \le \max_i z_i + \log n\), because the sum lies between its largest term and \(n\) times it. And \(\log\operatorname{softmax}(\mathbf z)_i = z_i - \operatorname{LSE}(\mathbf z)\), so the log-probabilities used in cross-entropy losses are computed through LSE.

Worked example · shift invariance, and why it saves the computation

Add a constant \(c\) to every score: \(\frac{e^{z_i + c}}{\sum_j e^{z_j + c}} = \frac{e^c e^{z_i}}{e^c\sum_j e^{z_j}} = \operatorname{softmax}(\mathbf z)_i\). Softmax is unchanged, and \(\operatorname{LSE}(\mathbf z + c) = \operatorname{LSE}(\mathbf z) + c\).

Take \(\mathbf z = (1000, 1001, 1002)\). Computed directly, \(e^{1000}\) overflows any floating-point format (double precision tops out near \(e^{709}\)). Subtract \(m = \max z_i = 1002\) first:

$$\operatorname{LSE}(\mathbf z) = 1002 + \log\left(e^{-2} + e^{-1} + 1\right) \approx 1002 + \log 1.5032 \approx 1002.408,$$

and \(\operatorname{softmax}(\mathbf z) \approx (0.090, 0.245, 0.665)\). Every exponent is now \(\le 0\), so nothing overflows, and the largest term is exactly 1, so the sum cannot underflow to 0.

Common errors
  • \(e^{a + b} = e^a + e^b\). It is \(e^a e^b\). Similarly \((e^x)^2 = e^{2x}\), not \(e^{x^2}\).
  • Taking logs of a sum. \(e^{2x} - 5e^x + 6 = 0\) is solved by substituting \(u = e^x\), not by taking \(\ln\) term by term.
  • Doubling time with the wrong log. \(T = \ln2/k\) uses the natural log because the model is \(e^{kt}\).
  • Softmax is invariant to adding a constant, not to scaling. \(\operatorname{softmax}(2\mathbf z)\) is sharper than \(\operatorname{softmax}(\mathbf z)\); dividing scores by a "temperature" changes the distribution.
  • \(\sigma(-x) = -\sigma(x)\). \(\sigma\) is not odd; \(\sigma(x) - \tfrac12\) is.

Trigonometry I: Unit Circle & the Six Functions

38m video50m practice

Cosine and sine are the coordinates of a point moving around the unit circle, with the angle measured as the arc length travelled. Every exact value, sign rule, identity and graph in trigonometry is read off that one picture.

Angles in radians

An angle of \(\theta\) radians cuts off an arc of length \(\theta\) on the unit circle. A full turn is the circumference \(2\pi\), so \(\pi\ \text{rad} = 180^\circ\): multiply by \(\pi/180\) to convert degrees to radians. On a circle of radius \(r\), the arc length is \(s = r\theta\) and the sector area is \(A = \tfrac12 r^2\theta\) (the fraction \(\theta/2\pi\) of \(\pi r^2\)).

Radians are the only unit in which the calculus of trig functions is clean: \(\sin\theta \approx \theta\) for small \(\theta\), \(\frac{d}{d\theta}\sin\theta = \cos\theta\), and the series \(\sin\theta = \theta - \theta^3/6 + \cdots\) all hold in radians only. In degrees, every one of them picks up a factor \(\pi/180\).

The unit circle and exact values

Definition

Walk a distance \(\theta\) counterclockwise around the unit circle from \((1, 0)\) (clockwise if \(\theta < 0\)). The point reached is \((\cos\theta, \sin\theta)\). Then \(\tan\theta = \frac{\sin\theta}{\cos\theta}\), \(\cot\theta = \frac{\cos\theta}{\sin\theta}\), \(\sec\theta = \frac{1}{\cos\theta}\), \(\csc\theta = \frac{1}{\sin\theta}\), wherever the denominators are nonzero.

\(\theta\)0\(\pi/6\)\(\pi/4\)\(\pi/3\)\(\pi/2\)
\(\sin\theta\)0\(\tfrac12\)\(\tfrac{\sqrt2}{2}\)\(\tfrac{\sqrt3}{2}\)1
\(\cos\theta\)1\(\tfrac{\sqrt3}{2}\)\(\tfrac{\sqrt2}{2}\)\(\tfrac12\)0
\(\tan\theta\)0\(\tfrac{1}{\sqrt3}\)1\(\sqrt3\)undefined

The \(\pi/4\) values come from the isosceles right triangle with hypotenuse 1; the \(\pi/6\) and \(\pi/3\) values from half an equilateral triangle of side 1. For any other angle, find the reference angle (the acute angle to the \(x\)-axis), take its value from the table, and attach the sign of the quadrant: \(\cos\frac{2\pi}{3} = -\cos\frac\pi3 = -\tfrac12\), \(\sin\frac{7\pi}{6} = -\tfrac12\).

The six graphs

Sinusoids: amplitude, period, phase, shift

\(y = A\sin(Bx - C) + D\) is \(\sin\) transformed as in L13. Write it as \(A\sin\big(B(x - C/B)\big) + D\): amplitude \(|A|\), period \(2\pi/|B|\), phase shift \(C/B\) (to the right if positive), midline \(y = D\). Any quantity that oscillates smoothly and regularly (tides, daylight hours, alternating current, seasonal demand) is modelled by choosing these four numbers: \(D\) is the average level, \(|A|\) half the peak-to-trough range, \(2\pi/B\) the cycle length, and \(C/B\) the time of the first upward crossing of the midline.

Worked example

Sketch \(y = 3\sin(2x - \pi/3) + 1\).

\(3\sin\big(2(x - \pi/6)\big) + 1\): amplitude 3, period \(\pi\), phase shift \(\pi/6\) right, midline \(y = 1\), range \([-2, 4]\). Divide one period, starting at \(x = \pi/6\), into quarters of length \(\pi/4\):

\((\tfrac\pi6, 1)\) midline, rising; \((\tfrac{5\pi}{12}, 4)\) maximum; \((\tfrac{2\pi}{3}, 1)\) midline, falling; \((\tfrac{11\pi}{12}, -2)\) minimum; \((\tfrac{7\pi}{6}, 1)\) back to the start.

Solving triangles: the Laws of Sines and Cosines

Theorem · area, Law of Cosines, Law of Sines

In a triangle with sides \(a, b, c\) opposite angles \(A, B, C\):

$$\text{Area} = \tfrac12 ab\sin C, \qquad c^2 = a^2 + b^2 - 2ab\cos C, \qquad \frac{\sin A}{a} = \frac{\sin B}{b} = \frac{\sin C}{c}.$$
Derivations

Put \(C\) at the origin, \(B = (a, 0)\), and \(A = (b\cos C, b\sin C)\). The height over side \(a\) is \(b\sin C\), giving the area. The distance formula gives \(c^2 = (b\cos C - a)^2 + b^2\sin^2 C = a^2 + b^2 - 2ab\cos C\), using \(\cos^2 + \sin^2 = 1\). The area formula is symmetric: \(\tfrac12ab\sin C = \tfrac12bc\sin A = \tfrac12ca\sin B\); divide through by \(\tfrac12abc\) to get the Law of Sines.

Heron's formula \(\text{Area} = \sqrt{s(s-a)(s-b)(s-c)}\), \(s = \tfrac{a+b+c}{2}\), follows by eliminating the angle: \(16\,\text{Area}^2 = 4a^2b^2 - (2ab\cos C)^2 = 4a^2b^2 - (a^2 + b^2 - c^2)^2\), and factoring twice as a difference of squares gives \((a+b+c)(-a+b+c)(a-b+c)(a+b-c) = 16s(s-a)(s-b)(s-c)\).

Worked example

SAS: \(a = 5\), \(b = 7\), \(C = 60^\circ\).

Law of Cosines: \(c^2 = 25 + 49 - 2\cdot35\cdot\tfrac12 = 39\), so \(c = \sqrt{39} \approx 6.245\). Law of Sines for the angle opposite the smaller side (which must be acute): \(\sin A = \frac{5\sin60^\circ}{\sqrt{39}} \approx 0.6934\), \(A \approx 43.9^\circ\). Then \(B = 180^\circ - 60^\circ - A \approx 76.1^\circ\).

Worked example

SSA, the ambiguous case: \(a = 6\), \(b = 8\), \(A = 30^\circ\).

\(B \approx 41.8^\circ,\ C \approx 108.2^\circ,\ c = \frac{6\sin C}{\sin30^\circ} \approx 11.40\); or \(B \approx 138.2^\circ,\ C \approx 11.8^\circ,\ c \approx 2.46\).

The test: with the height \(h = b\sin A = 4\), the side \(a\) can swing to meet the base in two places exactly when \(h < a < b\). If \(a < h\) there is no triangle; if \(a \ge b\), one.

Common errors
  • Degree mode. \(\sin 2\) means 2 radians (\(\approx 0.909\)), not \(2^\circ\) (\(\approx 0.035\)).
  • Period and phase. The period of \(\sin Bx\) is \(2\pi/B\), not \(2\pi B\); the phase shift of \(\sin(2x - \pi/3)\) is \(\pi/6\), not \(\pi/3\).
  • SSA with one answer. \(\arcsin\) returns only the acute angle; the obtuse supplement may also be valid.
  • \(\sec = 1/\sin\). It is \(1/\cos\) (and \(\csc = 1/\sin\)): each "co-" function pairs with a non-"co" reciprocal.
  • \(\sin^2\theta\) versus \(\sin\theta^2\). \(\sin^2\theta = (\sin\theta)^2\); \(\sin(\theta^2)\) is a different function.

Trigonometry II: Identities, Equations & Inverses

36m video50m practice

Two facts generate essentially every trig identity: \(\sin^2 + \cos^2 = 1\) and the angle-sum formulas. Inverse trig functions are the trig functions with their domains cut down until they are one-to-one, and the cut is why equations have families of solutions.

The basic identities

Identities from the unit circle
  • Pythagorean (L18): \(\sin^2\theta + \cos^2\theta = 1\), \(1 + \tan^2\theta = \sec^2\theta\), \(1 + \cot^2\theta = \csc^2\theta\).
  • Even/odd: \(\cos(-\theta) = \cos\theta\), \(\sin(-\theta) = -\sin\theta\), \(\tan(-\theta) = -\tan\theta\). Walking \(-\theta\) instead of \(\theta\) reflects the point in the \(x\)-axis.
  • Cofunction: \(\sin\left(\tfrac\pi2 - \theta\right) = \cos\theta\), \(\cos\left(\tfrac\pi2 - \theta\right) = \sin\theta\). The angle \(\tfrac\pi2 - \theta\) is the reflection of \(\theta\) in the line \(y = x\), which swaps coordinates. ("Co-sine" is the sine of the complementary angle.)

Sum and difference formulas

Theorem · angle sums $$\sin(A \pm B) = \sin A\cos B \pm \cos A\sin B, \qquad \cos(A \pm B) = \cos A\cos B \mp \sin A\sin B,$$ $$\tan(A \pm B) = \frac{\tan A \pm \tan B}{1 \mp \tan A\tan B}.$$
Derivation for all angles · the distance argument

Let \(P = (\cos A, \sin A)\) and \(Q = (\cos B, \sin B)\). Then \(|PQ|^2 = (\cos A - \cos B)^2 + (\sin A - \sin B)^2 = 2 - 2(\cos A\cos B + \sin A\sin B)\). Rotating both points by \(-B\) preserves distances and moves them to \((\cos(A - B), \sin(A - B))\) and \((1, 0)\), whose squared distance is \(2 - 2\cos(A - B)\). Equating:

$$\cos(A - B) = \cos A\cos B + \sin A\sin B \qquad\text{for all } A, B.$$

Replacing \(B\) by \(-B\) (even/odd) gives \(\cos(A + B)\). The sine formulas follow from cofunctions (the Prove it), and \(\tan(A \pm B)\) from dividing the sine formula by the cosine formula and then top and bottom by \(\cos A\cos B\).

Double angles, half angles, products and sums

Set \(A = B = \theta\) in the sum formulas:

$$\sin2\theta = 2\sin\theta\cos\theta, \qquad \cos2\theta = \cos^2\theta - \sin^2\theta = 2\cos^2\theta - 1 = 1 - 2\sin^2\theta, \qquad \tan2\theta = \frac{2\tan\theta}{1 - \tan^2\theta}.$$

The three forms of \(\cos2\theta\) come from replacing \(\sin^2\) or \(\cos^2\) with Pythagoras. Solving the last two for the squares gives the half-angle (power-reduction) formulas \(\sin^2\frac\theta2 = \frac{1 - \cos\theta}{2}\), \(\cos^2\frac\theta2 = \frac{1 + \cos\theta}{2}\), and \(\tan\frac\theta2 = \frac{1 - \cos\theta}{\sin\theta} = \frac{\sin\theta}{1 + \cos\theta}\). Adding and subtracting the sum and difference formulas gives product-to-sum:

$$\sin A\cos B = \tfrac12[\sin(A+B) + \sin(A-B)],\quad \cos A\cos B = \tfrac12[\cos(A-B) + \cos(A+B)],\quad \sin A\sin B = \tfrac12[\cos(A-B) - \cos(A+B)],$$

and substituting \(A = \frac{P+Q}{2}\), \(B = \frac{P-Q}{2}\) turns them into sum-to-product, e.g. \(\sin P + \sin Q = 2\sin\frac{P+Q}{2}\cos\frac{P-Q}{2}\) and \(\cos P - \cos Q = -2\sin\frac{P+Q}{2}\sin\frac{P-Q}{2}\). (Two nearby frequencies added give a fast oscillation inside a slow envelope: beats.)

Worked example

Prove \(\dfrac{1 - \cos2\theta}{\sin2\theta} = \tan\theta\).

Work on the more complicated side and choose the form of \(\cos2\theta\) that cancels the 1:

$$\frac{1 - \cos2\theta}{\sin2\theta} = \frac{1 - (1 - 2\sin^2\theta)}{2\sin\theta\cos\theta} = \frac{2\sin^2\theta}{2\sin\theta\cos\theta} = \frac{\sin\theta}{\cos\theta} = \tan\theta,$$

valid wherever \(\sin2\theta \ne 0\). With \(\theta\) replaced by \(\theta/2\) this is the half-angle formula for \(\tan\).

Harmonic addition

Theorem

\(a\sin x + b\cos x = R\sin(x + \varphi)\).

With \(R = \sqrt{a^2 + b^2}\) and \(\varphi\) chosen so that \(\cos\varphi = a/R\), \(\sin\varphi = b/R\).

Proof. \(R\sin(x + \varphi) = (R\cos\varphi)\sin x + (R\sin\varphi)\cos x\); match coefficients. The point \((a, b)/R\) is on the unit circle, so such \(\varphi\) exists.

So any combination of a sine and a cosine of the same frequency is a single sinusoid with amplitude \(\sqrt{a^2 + b^2}\), which is its maximum value. Example: \(\sin x + \sqrt3\cos x = 2\sin\left(x + \tfrac\pi3\right)\). L22 redoes this as addition of complex numbers.

Proving identities and solving equations

Strategy
  • Start from the more complicated side and transform it into the other; never start by assuming the identity and "cross-multiplying" both sides.
  • Rewrite everything in \(\sin\) and \(\cos\); combine fractions; look for a Pythagorean substitution or a double-angle form; factor.
  • State where the identity holds: it is only claimed where both sides are defined.

General solutions. Because the functions are periodic, an equation has infinitely many solutions. If \(\sin x = s\): \(x = \arcsin s + 2\pi k\) or \(x = \pi - \arcsin s + 2\pi k\). If \(\cos x = c\): \(x = \pm\arccos c + 2\pi k\). If \(\tan x = t\): \(x = \arctan t + \pi k\). Here \(k \in \Z\). On a restricted interval, list the members of these families that fall inside it.

Worked example

\(2\cos^2x - \cos x - 1 = 0\) on \([0, 2\pi)\).

A quadratic in \(u = \cos x\): \(2u^2 - u - 1 = (2u + 1)(u - 1) = 0\), so \(\cos x = -\tfrac12\) or \(\cos x = 1\).

\(\cos x = 1\): \(x = 0\). \(\cos x = -\tfrac12\): reference angle \(\pi/3\) in quadrants II and III, \(x = \tfrac{2\pi}{3}, \tfrac{4\pi}{3}\). Solution set \(\{0, \tfrac{2\pi}3, \tfrac{4\pi}3\}\); over all reals, \(x = 2\pi k\) or \(x = \pm\tfrac{2\pi}{3} + 2\pi k\).

Inverse trigonometric functions

No trig function is injective on \(\R\), so each is restricted to an interval on which it is one-to-one and hits its whole range (L12):

InverseDomainRange (the restricted interval)Shape
\(\arcsin x\)\([-1, 1]\)\([-\pi/2, \pi/2]\)increasing, odd
\(\arccos x\)\([-1, 1]\)\([0, \pi]\)decreasing; \(\arccos(-x) = \pi - \arccos x\)
\(\arctan x\)\(\R\)\((-\pi/2, \pi/2)\)increasing, odd, horizontal asymptotes \(y = \pm\pi/2\)

So \(\sin(\arcsin x) = x\) for \(x \in [-1, 1]\), but \(\arcsin(\sin x) = x\) only for \(x \in [-\pi/2, \pi/2]\): \(\arcsin(\sin\frac{3\pi}{4}) = \frac\pi4\). To evaluate a composite such as \(\sin(\arctan x)\), draw a reference triangle: an angle \(\theta\) with \(\tan\theta = x\) has opposite side \(x\), adjacent 1, hypotenuse \(\sqrt{1 + x^2}\), so \(\sin(\arctan x) = \frac{x}{\sqrt{1 + x^2}}\) (the signs work for negative \(x\) too, since \(\theta \in (-\pi/2, \pi/2)\)).

Worked example

Simplify \(\cos(\arcsin x)\).

Let \(\theta = \arcsin x\), so \(\sin\theta = x\) and \(\theta \in [-\pi/2, \pi/2]\), where \(\cos\theta \ge 0\). Then \(\cos\theta = +\sqrt{1 - \sin^2\theta}\):

$$\cos(\arcsin x) = \sqrt{1 - x^2}, \qquad -1 \le x \le 1.$$

This is the identity that turns the inverse-function rule into \(\frac{d}{dx}\arcsin x = \frac{1}{\sqrt{1 - x^2}}\), and \(\sec^2(\arctan x) = 1 + x^2\) gives \(\frac{d}{dx}\arctan x = \frac{1}{1 + x^2}\) (L63).

Common errors
  • \(\sin(A + B) = \sin A + \sin B\). False already at \(A = B = \pi/2\): \(\sin\pi = 0 \ne 2\).
  • Dividing by a trig function. From \(\sin x\cos x = \cos x\), dividing by \(\cos x\) loses \(x = \pi/2 + k\pi\). Factor: \(\cos x(\sin x - 1) = 0\).
  • One family of solutions. \(\sin x = \tfrac12\) has \(x = \frac\pi6 + 2\pi k\) and \(x = \frac{5\pi}6 + 2\pi k\).
  • \(\sin^{-1}x = 1/\sin x\). \(\sin^{-1}\) means \(\arcsin\); the reciprocal is \(\csc x = (\sin x)^{-1}\).
  • Sign of the square root. \(\cos(\arcsin x)\) is never negative; \(\sin(\arccos x) = \sqrt{1 - x^2}\) likewise, because \(\arccos\) lands in \([0, \pi]\).

Hyperbolic Functions

24m video30m practice

\(\cosh\) and \(\sinh\) are the even and odd parts of \(e^x\). They parametrize the hyperbola \(x^2 - y^2 = 1\) the way \(\cos\) and \(\sin\) parametrize the circle, and every trig identity has a hyperbolic twin that differs only by predictable signs.

Definitions and graphs

Definition $$\sinh x = \frac{e^x - e^{-x}}{2}, \qquad \cosh x = \frac{e^x + e^{-x}}{2}, \qquad \tanh x = \frac{\sinh x}{\cosh x} = \frac{e^x - e^{-x}}{e^x + e^{-x}},$$

with reciprocals \(\operatorname{sech} x = 1/\cosh x\), \(\operatorname{csch} x = 1/\sinh x\) (\(x \ne 0\)), \(\coth x = 1/\tanh x\) (\(x \ne 0\)).

By the even–odd decomposition of L13, \(\cosh\) is the even part of \(e^x\) and \(\sinh\) the odd part, so \(e^x = \cosh x + \sinh x\) and \(e^{-x} = \cosh x - \sinh x\).

DomainRangeSymmetryBehaviour
\(\cosh\)\(\R\)\([1, \infty)\)evenminimum 1 at 0; \(\approx \frac12e^{|x|}\) for large \(|x|\)
\(\sinh\)\(\R\)\(\R\)oddincreasing; \(\sinh x \approx x\) near 0
\(\tanh\)\(\R\)\((-1, 1)\)oddincreasing; asymptotes \(y = \pm1\); slope 1 at 0

The fundamental identity and the unit hyperbola

Theorem

\(\cosh^2x - \sinh^2x = 1\) for every real \(x\) (the Prove it). Dividing by \(\cosh^2 x\): \(1 - \tanh^2x = \operatorname{sech}^2x\).

So the point \((\cosh t, \sinh t)\) lies on the unit hyperbola \(x^2 - y^2 = 1\), and since \(\cosh t \ge 1\) it stays on the right branch, which it covers exactly once as \(t\) goes from \(-\infty\) to \(\infty\). Compare the circle: \((\cos\theta, \sin\theta)\) satisfies \(x^2 + y^2 = 1\), is periodic and bounded; \((\cosh t, \sinh t)\) satisfies \(x^2 - y^2 = 1\), is not periodic and runs off to infinity along the asymptotes \(y = \pm x\). The area statement in the figure is a short integral, worth checking once you have trigonometric and hyperbolic substitution (L72).

Addition formulas and Osborn's rule

Identities $$\sinh(x \pm y) = \sinh x\cosh y \pm \cosh x\sinh y, \qquad \cosh(x \pm y) = \cosh x\cosh y \pm \sinh x\sinh y,$$ $$\sinh2x = 2\sinh x\cosh x, \qquad \cosh2x = \cosh^2x + \sinh^2x = 2\cosh^2x - 1 = 1 + 2\sinh^2x.$$
Derivation

Of \(\cosh(x + y)\).

\(\cosh x\cosh y + \sinh x\sinh y = \tfrac14\big[(e^x + e^{-x})(e^y + e^{-y}) + (e^x - e^{-x})(e^y - e^{-y})\big]\). Expanding, the cross terms \(e^{x-y}\) and \(e^{-x+y}\) cancel and the others double: \(\tfrac14\big[2e^{x+y} + 2e^{-x-y}\big] = \cosh(x + y)\). Every hyperbolic identity can be checked this way, by expanding exponentials.

Osborn's rule

To turn a trig identity into a hyperbolic one, replace \(\cos \to \cosh\), \(\sin \to \sinh\), and flip the sign of every term containing a product of two sines (including products hidden inside \(\tan^2 = \sin^2/\cos^2\)). Examples: \(\cos^2 + \sin^2 = 1 \to \cosh^2 - \sinh^2 = 1\); \(\cos2x = 1 - 2\sin^2x \to \cosh2x = 1 + 2\sinh^2x\); \(\cos(x + y) = \cos x\cos y - \sin x\sin y \to \cosh(x + y) = \cosh x\cosh y + \sinh x\sinh y\). The reason, seen in L21: \(\cosh x = \cos(ix)\) and \(\sinh x = -i\sin(ix)\), so each product of two sines carries a factor \(i^2 = -1\). A mnemonic, not a proof: verify anything important from the exponentials.

Inverse hyperbolic functions

\(\sinh\) and \(\tanh\) are injective on \(\R\); \(\cosh\) is not, so it is restricted to \([0, \infty)\). Because the functions are built from \(e^x\), their inverses are logarithms:

InverseClosed formDomain

Worked example

Derive \(\operatorname{arcosh} x = \ln\big(x + \sqrt{x^2 - 1}\big)\).

Let \(y = \operatorname{arcosh} x\), so \(y \ge 0\) and \(x = \frac{e^y + e^{-y}}{2}\), with \(x \ge 1\). Put \(u = e^y \ge 1\): \(2x = u + \frac1u\), i.e. \(u^2 - 2xu + 1 = 0\), so \(u = x \pm\sqrt{x^2 - 1}\).

The two roots multiply to 1, so one is \(\ge 1\) and the other \(\le 1\). Since \(u = e^y \ge 1\), take the \(+\) sign: \(e^y = x + \sqrt{x^2 - 1}\), and \(y = \ln\big(x + \sqrt{x^2 - 1}\big)\). (The other root gives \(-y\), the negative solution we excluded by restricting \(\cosh\).)

\(\tanh\) as an activation, and the catenary

Worked example

Verify \(\tanh x = 2\sigma(2x) - 1\).

$$2\sigma(2x) - 1 = \frac{2}{1 + e^{-2x}} - 1 = \frac{1 - e^{-2x}}{1 + e^{-2x}} = \frac{e^{x} - e^{-x}}{e^{x} + e^{-x}} = \tanh x,$$

multiplying top and bottom by \(e^x\) in the third step. So \(\tanh\) is the sigmoid of L17 stretched vertically to \((-1, 1)\) and compressed horizontally by 2.

As a neural-network activation, \(\tanh\) has the sigmoid's S-shape but is zero-centred (odd, with \(\tanh 0 = 0\)), so the outputs feeding the next layer average closer to 0, and its slope at 0 is 1 rather than \(\tfrac14\). It still saturates for large \(|x|\), with derivative \(1 - \tanh^2x\) (Phase 4). Recurrent networks such as LSTMs use \(\tanh\) for candidate values and \(\sigma\) for gates.

The catenary \(y = a\cosh(x/a)\) is the shape of a uniform chain or cable hanging under its own weight. Near the bottom, \(\cosh u \approx 1 + u^2/2\), so it looks like the parabola \(y \approx a + \frac{x^2}{2a}\), but it rises exponentially, not quadratically, further out.

Common errors
  • \(\cosh^2 + \sinh^2 = 1\). The sign is minus. (\(\cosh^2 + \sinh^2 = \cosh 2x\).)
  • Thinking \(\sinh\) behaves like \(\sin\). It is unbounded and not periodic; \(\cosh\) is never below 1.
  • Wrong root for \(\operatorname{arcosh}\). \(x - \sqrt{x^2 - 1}\) is the reciprocal of the right answer and gives the negative branch.
  • \(\tanh x = 2\sigma(x) - 1\). The argument is \(2x\); \(2\sigma(x) - 1 = \tanh(x/2)\).
  • Osborn's rule on hidden products. \(\tan^2\) contains \(\sin^2\), so \(1 + \tan^2 = \sec^2\) becomes \(1 - \tanh^2 = \operatorname{sech}^2\).

Complex Numbers I: Algebra & Geometry

32m video40m practiceheavy lesson

\(\C\) is the plane \(\R^2\) equipped with a multiplication. Adding complex numbers adds vectors; multiplying them multiplies lengths and adds angles. Euler's formula \(e^{i\theta} = \cos\theta + i\sin\theta\) turns that rule into the ordinary law of exponents.

\(\C\) as ordered pairs

Definition

A complex number is a pair \((a, b)\) of reals, written \(a + bi\), with

$$(a + bi) + (c + di) = (a + c) + (b + d)i, \qquad (a + bi)(c + di) = (ac - bd) + (ad + bc)i.$$

\(\operatorname{Re} z = a\), \(\operatorname{Im} z = b\). The pair \(i = (0, 1)\) satisfies \(i^2 = (0\cdot0 - 1\cdot1) + 0i = -1\): the solution of \(x^2 = -1\) that \(\R\) lacks (L1).

The multiplication rule is exactly what you get by expanding \((a + bi)(c + di)\) with the usual algebra and replacing \(i^2\) by \(-1\). With these operations \(\C\) is a field: every rule of L1 holds, and the reals sit inside as the pairs \((a, 0)\).

Conjugate, modulus and division

Definition

The conjugate of \(z = a + bi\) is \(\bar z = a - bi\) (reflection in the real axis). The modulus is \(|z| = \sqrt{a^2 + b^2}\), its distance from 0.

Properties

\(\overline{z + w} = \bar z + \bar w\), \(\ \overline{zw} = \bar z\,\bar w\), \(\ \bar{\bar z} = z\), \(\ z + \bar z = 2\operatorname{Re}z\), \(\ z - \bar z = 2i\operatorname{Im}z\), \(\ z\) is real iff \(z = \bar z\), and

$$z\bar z = (a + bi)(a - bi) = a^2 + b^2 = |z|^2.$$

Each is a one-line check from the definitions; for the product, both sides equal \((ac - bd) - (ad + bc)i\).

Division. Multiply top and bottom by the conjugate of the denominator, which makes the denominator the real number \(|w|^2\). In particular \(\frac1z = \frac{\bar z}{|z|^2}\) for \(z \ne 0\). Example:

$$\frac{3 + 4i}{1 - 2i} = \frac{(3 + 4i)(1 + 2i)}{(1 - 2i)(1 + 2i)} = \frac{3 + 6i + 4i + 8i^2}{5} = \frac{-5 + 10i}{5} = -1 + 2i.$$

The Argand plane and polar form

Plot \(a + bi\) at \((a, b)\). Addition is vector addition (the parallelogram rule), so \(|z - w|\) is the distance between \(z\) and \(w\), and the triangle inequality \(|z + w| \le |z| + |w|\) of L9 holds in \(\C\). The argument \(\arg z\) is the angle from the positive real axis to \(z\); the principal value lies in \((-\pi, \pi]\). Then

$$z = r(\cos\theta + i\sin\theta), \qquad r = |z|,\ \theta = \arg z,$$

and \(a = r\cos\theta\), \(b = r\sin\theta\). Finding \(\theta\) needs the quadrant, not just \(\tan\theta = b/a\): \(-1 - i\) and \(1 + i\) have the same ratio, but \(\arg(1 + i) = \frac\pi4\) and \(\arg(-1 - i) = -\frac{3\pi}{4}\).

Euler's formula

Theorem · Euler's formula

For real \(\theta\): \(\ e^{i\theta} = \cos\theta + i\sin\theta\).

Justification by power series

Take as given (they are proved in L69) the series \(e^x = \sum_n \frac{x^n}{n!}\), \(\cos x = \sum_k \frac{(-1)^kx^{2k}}{(2k)!}\), \(\sin x = \sum_k \frac{(-1)^kx^{2k+1}}{(2k+1)!}\), and use the first one to define \(e^z\) for complex \(z\). The powers of \(i\) cycle \(1, i, -1, -i\), so \(i^{2k} = (-1)^k\) and \(i^{2k+1} = (-1)^k i\). Splitting \(\sum_n \frac{(i\theta)^n}{n!}\) into even and odd \(n\) (allowed, because the series converges absolutely):

$$e^{i\theta} = \sum_{k}\frac{(-1)^k\theta^{2k}}{(2k)!} + i\sum_k\frac{(-1)^k\theta^{2k+1}}{(2k+1)!} = \cos\theta + i\sin\theta.$$

So \(e^{i\theta}\) is the point at angle \(\theta\) on the unit circle, and every complex number is \(z = re^{i\theta}\). This is a compact notation, but also a theorem: the exponential law \(e^{i\alpha}e^{i\beta} = e^{i(\alpha + \beta)}\) is the pair of angle-sum formulas of L19.

Multiplication in polar form and De Moivre

Theorem · polar multiplication

If \(z_1 = r_1e^{i\theta_1}\) and \(z_2 = r_2e^{i\theta_2}\), then \(z_1z_2 = r_1r_2\,e^{i(\theta_1 + \theta_2)}\) and \(\dfrac{z_1}{z_2} = \dfrac{r_1}{r_2}e^{i(\theta_1 - \theta_2)}\) (\(z_2 \ne 0\)). Lengths multiply, angles add (the Prove it).

De Moivre: for every integer \(n\), \((\cos\theta + i\sin\theta)^n = \cos n\theta + i\sin n\theta\), i.e. \((e^{i\theta})^n = e^{in\theta}\). (Induct on \(n\) using the product rule; negative \(n\) from the quotient rule.)

So multiplying by \(w = \rho e^{i\varphi}\) is the geometric map "scale by \(\rho\), rotate by \(\varphi\)". Multiplying by \(i = e^{i\pi/2}\) rotates by a right angle, which is why \(i^2 = -1\): two quarter turns make a half turn.

Worked example

\((1 + i)^8\) via polar form.

\(1 + i = \sqrt2\,e^{i\pi/4}\). By De Moivre, \((1 + i)^8 = (\sqrt2)^8 e^{i\cdot8\pi/4} = 16\,e^{2\pi i} = 16\). (Expanding by the Binomial Theorem would need nine terms.)

Worked example

\(\cos3\theta\) in terms of \(\cos\theta\).

Write \(c = \cos\theta\), \(s = \sin\theta\). De Moivre: \(\cos3\theta + i\sin3\theta = (c + is)^3 = c^3 + 3c^2(is) + 3c(is)^2 + (is)^3 = (c^3 - 3cs^2) + i(3c^2s - s^3)\). Compare real parts and use \(s^2 = 1 - c^2\):

$$\cos3\theta = c^3 - 3c(1 - c^2) = 4\cos^3\theta - 3\cos\theta.$$

\(n\)-th roots and roots of unity

Theorem

\(n\)-th roots.

A nonzero \(w = Re^{i\varphi}\) has exactly \(n\) distinct \(n\)-th roots: \(\ z_k = R^{1/n}e^{i(\varphi + 2\pi k)/n}\), \(k = 0, 1, \dots, n-1\).

Why: \(z = re^{i\theta}\) solves \(z^n = w\) iff \(r^n = R\) and \(n\theta = \varphi + 2\pi k\) for some integer \(k\). Values of \(k\) that differ by a multiple of \(n\) give the same point.

Worked example

All cube roots of \(-8\).

\(-8 = 8e^{i\pi}\), so \(z_k = 2e^{i(\pi + 2\pi k)/3}\): \(z_0 = 2e^{i\pi/3} = 1 + i\sqrt3\), \(z_1 = 2e^{i\pi} = -2\), \(z_2 = 2e^{i5\pi/3} = 1 - i\sqrt3\). Check one: \((1 + i\sqrt3)^2 = -2 + 2i\sqrt3\), and \((-2 + 2i\sqrt3)(1 + i\sqrt3) = -2 - 6 + 0i = -8\).

The \(n\)-th roots of unity \(\omega^k\), with \(\omega = e^{2\pi i/n}\), are the vertices of a regular \(n\)-gon inscribed in the unit circle. For \(n \ge 2\) they sum to 0: \(1 + \omega + \dots + \omega^{n-1} = \frac{1 - \omega^n}{1 - \omega} = 0\), a geometric series (L10). They are the frequencies of the discrete Fourier transform.

Common errors
  • \(\arg z = \arctan(b/a)\) without a quadrant check. \(\arctan\) only returns angles in \((-\pi/2, \pi/2)\).
  • \(|a + bi| = a + b\) or \(\sqrt{a^2 - b^2}\), or with an \(i\) inside. The modulus is \(\sqrt{a^2 + b^2}\), a non-negative real.
  • \(\sqrt{-4}\sqrt{-9} = \sqrt{36} = 6\). The rule \(\sqrt{ab} = \sqrt a\sqrt b\) needs \(a, b \ge 0\). Here \(2i\cdot3i = -6\).
  • One root instead of \(n\). \(z^3 = -8\) has three solutions, not just \(-2\).
  • Ordering \(\C\). "\(z < w\)" means nothing for non-real numbers; compare moduli instead.

L22 · DAY 18

Complex Numbers II & Phase 1 Workshop

26m video45m practiceheavy lesson

Over \(\C\) every polynomial splits completely into linear factors; over \(\R\) the non-real roots come in conjugate pairs that fuse into irreducible quadratics. And complex exponentials are the natural language of rotation and oscillation, which is exactly how they reappear as eigenvalues.

The Fundamental Theorem of Algebra

Theorem · Fundamental Theorem of Algebra (statement)

Every non-constant polynomial with complex coefficients has at least one root in \(\C\).

The proof needs analysis or topology and is not given here. Its consequence is the useful form: a polynomial of degree \(n \ge 1\) has exactly \(n\) complex roots, counted with multiplicity, so \(p(z) = a_n(z - z_1)(z - z_2)\cdots(z - z_n)\). Induct on \(n\): the theorem gives a root \(z_1\), the Factor Theorem (L6, which works verbatim over \(\C\)) gives \(p(z) = (z - z_1)q(z)\) with \(\deg q = n - 1\), and the hypothesis factors \(q\). This is the end of the tower of L1: unlike \(\N \to \Z \to \Q \to \R \to \C\), no polynomial equation forces a further extension. (\(\C\) is algebraically closed.)

Conjugate roots and factoring over \(\R\)

Theorem · Conjugate root theorem

If \(p\) has real coefficients and \(p(z) = 0\), then \(p(\bar z) = 0\) (the Prove it).

So non-real roots of a real polynomial come in pairs \(z, \bar z\), and each pair multiplies to a real quadratic:

$$(x - z)(x - \bar z) = x^2 - (z + \bar z)x + z\bar z = x^2 - 2\operatorname{Re}(z)\,x + |z|^2,$$

whose discriminant \(4(\operatorname{Re}z)^2 - 4|z|^2 = -4(\operatorname{Im}z)^2 < 0\): it is irreducible over \(\R\). Hence every real polynomial factors over \(\R\) into linear factors and irreducible quadratics, which is exactly the hypothesis partial fractions needed (L7). Since non-real roots pair off, a real polynomial of odd degree must have a real root, a second proof of the Prove it of L16.

Worked example

Factor \(x^4 + 4\) over \(\C\) and over \(\R\).

Over \(\C\). \(x^4 = -4 = 4e^{i\pi}\), so \(x = \sqrt2\,e^{i(\pi/4 + k\pi/2)}\), \(k = 0, 1, 2, 3\): the four numbers \(\pm1 \pm i\). Thus \(x^4 + 4 = (x - 1 - i)(x - 1 + i)(x + 1 - i)(x + 1 + i)\).

Over \(\R\). Pair conjugates: \((x - (1 + i))(x - (1 - i)) = x^2 - 2x + 2\) and \((x - (-1 + i))(x - (-1 - i)) = x^2 + 2x + 2\). So

$$x^4 + 4 = (x^2 - 2x + 2)(x^2 + 2x + 2).$$

Check without complex numbers: \(x^4 + 4 = (x^2 + 2)^2 - (2x)^2\), a difference of squares (Sophie Germain's identity). A "sum of squares" can factor over \(\R\) after all, just not into linear pieces.

Worked example

\(2 + 3i\) is a root of \(p(x) = x^3 - 5x^2 + 17x - 13\); find the others.

The coefficients are real, so \(2 - 3i\) is also a root, and \(p\) is divisible by \((x - 2)^2 + 9 = x^2 - 4x + 13\). Divide: \(x^3 - 5x^2 + 17x - 13 = (x^2 - 4x + 13)(x - 1)\). The third root is \(1\).

Faster with Vieta (L6): the roots sum to \(5\), so \(r + (2 + 3i) + (2 - 3i) = 5\) and \(r = 1\). Check: \(p(1) = 1 - 5 + 17 - 13 = 0\).

\(e^{i\pi} + 1 = 0\), and phasors

Euler's formula (L21) at \(\theta = \pi\) gives \(e^{i\pi} = \cos\pi + i\sin\pi = -1\), i.e. \(e^{i\pi} + 1 = 0\). It also gives \(\cos\theta = \frac{e^{i\theta} + e^{-i\theta}}{2}\) and \(\sin\theta = \frac{e^{i\theta} - e^{-i\theta}}{2i}\), the complex versions of \(\cosh\) and \(\sinh\) (L20).

The phasor idea: a sinusoid of angular frequency \(\omega\) is the real part of a rotating complex number,

$$A\cos(\omega t + \varphi) = \operatorname{Re}\big(Ae^{i\varphi}\,e^{i\omega t}\big),$$

and the fixed complex number \(Ae^{i\varphi}\) (the phasor) records amplitude and phase. Sinusoids of the same frequency add by adding phasors. Example: \(\cos t \leftrightarrow 1\) and \(\sqrt3\sin t = \sqrt3\cos(t - \pi/2) \leftrightarrow -\sqrt3\,i\), so \(\cos t + \sqrt3\sin t \leftrightarrow 1 - \sqrt3\,i = 2e^{-i\pi/3}\), i.e. \(2\cos(t - \pi/3)\). This is the harmonic addition formula of L19 done as vector addition; it is how circuits, signals and Fourier analysis handle oscillations.

Why this matters later: complex eigenvalues

The rotation matrix \(R_\theta = \begin{pmatrix}\cos\theta & -\sin\theta\\ \sin\theta & \cos\theta\end{pmatrix}\) turns every nonzero vector in \(\R^2\) (for \(\theta \ne 0, \pi\)), so it has no real eigenvector: no real direction is merely stretched. Its characteristic polynomial \(\lambda^2 - 2\cos\theta\,\lambda + 1\) has discriminant \(-4\sin^2\theta < 0\) and roots \(e^{\pm i\theta}\), and indeed \(R_\theta\binom{1}{-i} = e^{i\theta}\binom{1}{-i}\). In general, a real \(2\times2\) matrix with complex eigenvalues \(re^{\pm i\theta}\) acts, in a suitable basis, as "rotate by \(\theta\), scale by \(r\)": its powers spiral inward if \(r < 1\), outward if \(r > 1\), and circle if \(r = 1\). Complex eigenvalues are the algebraic signature of oscillation, in iterated maps, in linear differential equations (\(e^{(\alpha \pm i\beta)t}\)), and in the dynamics of optimizers. L54 computes these eigenvalues, and L55 uses them for matrix powers.

Common errors
  • Applying the conjugate root theorem to complex coefficients. \(z - i\) has the root \(i\) but not \(-i\). The theorem needs real coefficients.
  • Pairing the wrong roots. Only a conjugate pair multiplies to a real quadratic; \((x - (1 + i))(x - (-1 + i))\) has complex coefficients.
  • "Exactly \(n\) distinct roots". The count is with multiplicity: \((x - 1)^3\) has one root of multiplicity 3.
  • Adding phasors of different frequencies. \(\cos t + \cos2t\) is not a single sinusoid; the phasor method needs a common \(\omega\).

  1. Prove it. If \(p\) has real coefficients and \(p(z) = 0\), then \(p(\bar z) = 0\). Hint: take the conjugate of the equation \(\sum a_k z^k = 0\) and push the bar inside using the rules of L21.
    Proof sketch

    Write \(p(z) = \sum_{k=0}^{n} a_k z^k\) with every \(a_k \in \R\), so \(\bar a_k = a_k\). Conjugation respects sums and products, hence powers: \(\overline{z^k} = \bar z^k\). So \(p(\bar z) = \sum a_k\bar z^k = \sum \bar a_k\,\overline{z^k} = \overline{\sum a_k z^k} = \overline{p(z)} = \bar 0 = 0\). The only place reality of the coefficients is used is \(\bar a_k = a_k\).
