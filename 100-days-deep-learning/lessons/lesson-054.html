Everything from Phase 3 applied to one concrete problem. CIFAR-10 is 60,000 32×32 images in 10 classes, small enough that a full run takes minutes on one GPU — which makes it the right place to feel each trick's contribution rather than read about it.

Pitfall · using an ImageNet stem on 32×32 images

A stock torchvision.models.resnet18 begins with a 7×7 stride-2 conv followed by a stride-2 max pool. On a 224×224 image that reduces to 56×56, which is fine. On a 32×32 image it reduces to 8×8 before the first residual block has run — you have thrown away 94% of the spatial information in two operations, and the network never recovers. Every "CIFAR ResNet" replaces the stem with a single 3×3 stride-1 conv and deletes the max pool. This one change is worth roughly 5 percentage points, and it is the most common reason people report that "ResNet doesn't work on CIFAR".

import torch, torch.nn as nn, torchvision
from torchvision.transforms import v2

# Statistics computed on the TRAINING SPLIT ONLY (Lesson 14)
MEAN, STD = (0.4914, 0.4822, 0.4465), (0.2470, 0.2435, 0.2616)

train_tf = v2.Compose([
    v2.RandomCrop(32, padding=4, padding_mode="reflect"),
    v2.RandomHorizontalFlip(),
    v2.TrivialAugmentWide(),
    v2.ToImage(), v2.ToDtype(torch.float32, scale=True), v2.Normalize(MEAN, STD),
    v2.RandomErasing(p=0.25)])                       # after normalize (Lesson 38)

def cifar_resnet18(num_classes=10):
    m = torchvision.models.resnet18(weights=None, num_classes=num_classes)
    m.conv1 = nn.Conv2d(3, 64, 3, stride=1, padding=1, bias=False)   # 7x7/2 -> 3x3/1
    m.maxpool = nn.Identity()                                        # delete it
    return m

model = cifar_resnet18().cuda().to(memory_format=torch.channels_last)
model = torch.compile(model)

decay = [p for n, p in model.named_parameters() if p.ndim >= 2]
nodecay = [p for n, p in model.named_parameters() if p.ndim < 2]
opt = torch.optim.SGD([{"params": decay, "weight_decay": 5e-4},
                       {"params": nodecay, "weight_decay": 0.0}],
                      lr=0.1, momentum=0.9, nesterov=True)

EPOCHS, steps = 60, len(train_loader)
sched = torch.optim.lr_scheduler.OneCycleLR(opt, max_lr=0.2,
                                            total_steps=EPOCHS * steps, pct_start=0.15)
criterion = nn.CrossEntropyLoss(label_smoothing=0.1)
scaler = torch.amp.GradScaler("cuda")
ema = torch.optim.swa_utils.AveragedModel(
    model, avg_fn=lambda a, c, n: 0.999 * a + 0.001 * c)

for epoch in range(EPOCHS):
    model.train()
    for xb, yb in train_loader:
        xb = xb.cuda(non_blocking=True).to(memory_format=torch.channels_last)
        yb = yb.cuda(non_blocking=True)
        with torch.autocast("cuda", dtype=torch.bfloat16):
            loss = criterion(model(xb), yb)
        opt.zero_grad(set_to_none=True)
        scaler.scale(loss).backward()
        scaler.step(opt); scaler.update(); sched.step()
        ema.update_parameters(model)

What each piece buys

ResNet-18, ImageNet stem, no augmentation~86.5%—

Read the shape of that table, not the numbers. The two changes that mattered — fixing the stem and adding basic augmentation — are both about respecting the data, and together they are worth more than everything else combined. The clever tricks each contribute a few tenths. That ordering is typical of real projects and is the opposite of how the literature is usually read.

EMA — free accuracy, almost

Keep a shadow copy of the weights updated as \(\theta_{\text{ema}}\leftarrow\rho\,\theta_{\text{ema}}+(1-\rho)\,\theta\) with \(\rho\approx0.999\), and evaluate that. SGD's final iterate is still bouncing inside the noise ball from Lesson 33; the average sits closer to its centre. Costs one extra copy of the weights and no extra compute in the backward pass. Nearly every strong vision and diffusion result uses it. Remember to update the EMA model's BatchNorm statistics before evaluating — torch.optim.swa_utils.update_bn does this.

Pitfall · CIFAR-specific traps

Reporting the best epoch's test accuracy. If you evaluate on test every epoch and report the maximum, you have selected on test — worth a spurious 0.3–0.5% (Lesson 39). Hold out 5,000 training images as validation and touch test once.

Normalizing with ImageNet statistics. CIFAR's channel means differ; use CIFAR's own.

Believing a 0.2% improvement. The seed-to-seed standard deviation on CIFAR-10 is roughly 0.15–0.25%. Three seeds, or do not claim it.
