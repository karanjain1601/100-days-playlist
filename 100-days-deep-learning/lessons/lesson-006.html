The Jacobian

For \(\mathbf f:\R^n\to\R^m\), the Jacobian \(J\in\R^{m\times n}\) has \(J_{ij}=\partial f_i/\partial x_j\). Row \(i\) is the gradient of output \(i\). It is the best linear approximation of \(\mathbf f\) near a point: \(\mathbf f(\mathbf x+\boldsymbol\delta)\approx \mathbf f(\mathbf x)+J\boldsymbol\delta\).

Composition is matrix multiplication: for \(\mathbf z=\mathbf g(\mathbf y)\), \(\mathbf y=\mathbf f(\mathbf x)\),

\[ J_{\mathbf z\mathbf x}=J_{\mathbf z\mathbf y}\,J_{\mathbf y\mathbf x} \]

An \(L\)-layer network is therefore a product of \(L\) Jacobians. Whether that product explodes or vanishes depends on the singular values of each factor — Lesson 4 meets Lesson 6, and together they explain Day 26.

The vector-Jacobian product is why autodiff is cheap

Nobody ever materialises a Jacobian in deep learning. For a network with \(P=10^9\) parameters and a scalar loss, the Jacobian of the loss w.r.t. an intermediate activation of size \(n\) is \(1\times n\) — a row vector. Backprop propagates such row vectors:

\[ \underbrace{\bar{\mathbf x}\T}_{1\times n} = \underbrace{\bar{\mathbf y}\T}_{1\times m}\underbrace{J_{\mathbf y \mathbf x}}_{m\times n} \]

where \(\bar{\mathbf v}\) denotes \(\partial L/\partial \mathbf v\). Each layer only needs a rule for "given the gradient flowing in, produce the gradient flowing out" — it never builds \(J\). For most layers that rule is a cheap closed form:

ForwardJacobian (conceptually)VJP actually computed
\(\mathbf y=W\mathbf x\)\(W\)gx = gy @ W and gW = gy.T @ x
\(\mathbf y=\mathbf a\odot\mathbf x\)\(\diag(\mathbf a)\)gx = gy * a
\(\mathbf y=\relu(\mathbf x)\)\(\diag(\mathbb 1[x\gt0])\)gx = gy * (x > 0)
\(\mathbf y=\softmax(\mathbf x)\)\(\diag(\mathbf y)-\mathbf y\mathbf y\T\) (dense!)gx = y * (gy - (gy*y).sum())

Note the softmax row. Its Jacobian is a full \(K\times K\) matrix, but the VJP is a two-line elementwise computation. That gap — dense Jacobian, cheap VJP — is the entire performance argument for reverse-mode autodiff.

Worked: ∂loss/∂W for a 2-layer network

Forward, for a single example, with \(\mathbf x\in\R^{d}\):

\[ \mathbf z^{(1)} = W^{(1)}\mathbf x + \mathbf b^{(1)},\quad \mathbf a = \relu(\mathbf z^{(1)}),\quad \mathbf z^{(2)} = W^{(2)}\mathbf a + \mathbf b^{(2)},\quad L=\tfrac12\lVert \mathbf z^{(2)}-\mathbf y\rVert^2 \]

Backward, right to left, naming each intermediate gradient:

\[ \begin{aligned} \bar{\mathbf z}^{(2)} &= \mathbf z^{(2)} - \mathbf y \\[2pt] \bar W^{(2)} &= \bar{\mathbf z}^{(2)}\,\mathbf a\T &&\text{outer product: } (m\times1)(1\times h)=m\times h\;\checkmark\\[2pt] \bar{\mathbf b}^{(2)} &= \bar{\mathbf z}^{(2)} \\[2pt] \bar{\mathbf a} &= {W^{(2)}}\T\,\bar{\mathbf z}^{(2)} &&\text{transpose sends the signal back}\\[2pt] \bar{\mathbf z}^{(1)} &= \bar{\mathbf a}\odot\mathbb 1[\mathbf z^{(1)}\gt 0] &&\text{gate through the ReLU mask}\\[2pt] \bar W^{(1)} &= \bar{\mathbf z}^{(1)}\,\mathbf x\T,\qquad \bar{\mathbf b}^{(1)} = \bar{\mathbf z}^{(1)} \end{aligned} \]
The pattern to memorise

Three motifs repeat for every linear layer in every architecture you will ever write: weight gradient = outer product of (gradient out, input in); input gradient = \(W\T\) times gradient out; elementwise nonlinearity = multiply by its local derivative. Learn these three and you can hand-derive backprop for anything.

Hessians and curvature — what you need, no more

\(H_{ij}=\partial^2 f/\partial x_i\partial x_j\). Its eigenvalues describe curvature: all positive is a local minimum, all negative a maximum, mixed signs a saddle. Two facts carry over into everything that follows:

  • The condition number \(\kappa=\lambda_{\max}/\lambda_{\min}\) controls how badly gradient descent zig-zags. A long thin valley has huge \(\kappa\), and plain SGD bounces across it instead of running down it. That is what momentum fixes (Day 28).
  • In high dimensions, saddles vastly outnumber local minima. For a random critical point, needing all \(P\) eigenvalues to share a sign is exponentially unlikely. So the classical fear of "getting stuck in a local minimum" is mostly misplaced; plateaus around saddles are the real problem.

Full Newton steps need \(H^{-1}\), which is \(O(P^3)\) — impossible at \(P=10^9\). Adam's per-parameter scaling is a cheap diagonal caricature of this idea, and that is as close to second order as mainstream deep learning gets.

Exercise

Implement the 2-layer backward pass above in NumPy for a batch. The only change is that outer products become gz.T @ a over the batch axis and bias gradients become gz.sum(axis=0). Verify every gradient against finite differences: \(\frac{f(\theta+\varepsilon)-f(\theta-\varepsilon)}{2\varepsilon}\) with \(\varepsilon=10^{-5}\) in float64. Relative error should be below \(10^{-7}\).
