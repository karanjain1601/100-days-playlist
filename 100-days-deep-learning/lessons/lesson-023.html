Backprop By Hand — Full Numeric Walkthrough

No abstractions in this lesson. Two inputs, two hidden units with sigmoid, one output with sigmoid, binary cross-entropy. Every number written out.

Setup
QuantityValue
Input \(\mathbf x\)\([0.05,\;0.10]\)
Target \(y\)\(1\)
\(W^{(1)}\)\(\begin{bmatrix}0.15 & 0.20\\ 0.25 & 0.30\end{bmatrix}\), \(\mathbf b^{(1)}=[0.35,\,0.35]\)
\(W^{(2)}\)\([0.40,\;0.45]\), \(b^{(2)}=0.60\)
Learning rate\(\eta=0.5\)
Forward
\[ \begin{aligned} z^{(1)}_1 &= 0.15(0.05)+0.20(0.10)+0.35 = 0.3775 &&\Rightarrow\; h_1=\sigma(0.3775)=0.593270 \\ z^{(1)}_2 &= 0.25(0.05)+0.30(0.10)+0.35 = 0.3925 &&\Rightarrow\; h_2=\sigma(0.3925)=0.596884 \\ z^{(2)} &= 0.40(0.593270)+0.45(0.596884)+0.60 = 1.105906 &&\Rightarrow\; \hat p=\sigma(1.105906)=0.751365 \end{aligned} \] \[ L=-\log(0.751365)=0.285759 \]
Backward

Start at the loss and walk left, using the table from Lesson 22.

\[ \begin{aligned} \bar z^{(2)} &= \hat p - y = 0.751365 - 1 = -0.248635 &&\text{(the cancellation from L17)}\\[3pt] \bar W^{(2)}_1 &= \bar z^{(2)}\,h_1 = -0.248635\times0.593270 = -0.147505\\ \bar W^{(2)}_2 &= \bar z^{(2)}\,h_2 = -0.248635\times0.596884 = -0.148404\\ \bar b^{(2)} &= -0.248635\\[3pt] \bar h_1 &= \bar z^{(2)}\,W^{(2)}_1 = -0.248635\times0.40 = -0.099454\\ \bar h_2 &= \bar z^{(2)}\,W^{(2)}_2 = -0.248635\times0.45 = -0.111886\\[3pt] \bar z^{(1)}_1 &= \bar h_1\,h_1(1-h_1) = -0.099454\times0.593270\times0.406730 = -0.023999\\ \bar z^{(1)}_2 &= \bar h_2\,h_2(1-h_2) = -0.111886\times0.596884\times0.403116 = -0.026922 \end{aligned} \] \[ \begin{aligned} \bar W^{(1)}_{11} &= \bar z^{(1)}_1 x_1 = -0.023999\times0.05 = -0.00119995 \qquad \bar W^{(1)}_{12} = \bar z^{(1)}_1 x_2 = -0.00239990\\ \bar W^{(1)}_{21} &= \bar z^{(1)}_2 x_1 = -0.00134610 \qquad\qquad\;\;\;\; \bar W^{(1)}_{22} = \bar z^{(1)}_2 x_2 = -0.00269220 \end{aligned} \]
Look at the magnitudes

The output-layer gradients are around \(1.5\times10^{-1}\). The first-layer gradients are around \(1.2\times10^{-3}\) — a hundredfold smaller after only one hidden layer. Two causes: the sigmoid derivative (\(\approx0.24\)) and the tiny inputs (0.05, 0.10). Extend this to ten layers and the first layer gets nothing. You have just watched the vanishing gradient problem happen in arithmetic you did by hand.

Update and re-run
\[ W^{(2)}_1 \leftarrow 0.40 - 0.5(-0.147505) = 0.473753,\qquad W^{(2)}_2 \leftarrow 0.45+0.074202=0.524202,\qquad b^{(2)}\leftarrow 0.724318 \]

Recompute the forward pass with the updated parameters: \(\hat p\) rises to about \(0.7867\) and \(L\) falls from \(0.285759\) to about \(0.239866\). It worked. Every model in this course is that step, repeated.

Gradient checking — the test that ends all arguments

Use the two-sided difference, which has \(O(\varepsilon^2)\) error instead of \(O(\varepsilon)\):

\[ \frac{\partial L}{\partial\theta_i}\approx\frac{L(\theta+\varepsilon e_i)-L(\theta-\varepsilon e_i)}{2\varepsilon},\qquad \text{relative error}=\frac{\lvert g_{\text{analytic}}-g_{\text{numeric}}\rvert}{\max(\lvert g_a\rvert,\lvert g_n\rvert,10^{-8})} \]
Rules for gradient checking
  • Use float64. In float32 the numeric gradient is noise.
  • \(\varepsilon=10^{-5}\). Smaller and rounding dominates; larger and truncation does.
  • Turn off dropout and any other randomness, or the two evaluations are of different functions.
  • Below \(10^{-7}\): correct. Around \(10^{-5}\): suspicious, check the ReLU kinks. Above \(10^{-3}\): you have a bug.
  • Check a random sample of parameters, not all of them — it is \(O(P)\) forward passes.
Exercise

Reproduce every number in this lesson in a spreadsheet — genuinely, a spreadsheet, one cell per quantity. It forces you to be explicit about what depends on what. Then deliberately break one backward formula (drop the \(h(1-h)\) factor) and watch the gradient check catch it.
