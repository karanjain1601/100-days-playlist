X (N, 784)→h₁ (N, 256) →h₂ (N, 128)→logits (N, 10) 
import numpy as np

# ---------- data ----------
# X_train (60000, 784) float32 in [0,1]; y_train (60000,) int
X_train = X_train.reshape(-1, 784).astype(np.float32) / 255.0
X_test  = X_test.reshape(-1, 784).astype(np.float32) / 255.0

mu, sd = X_train.mean(), X_train.std()        # fit on TRAIN ONLY (Lesson 14)
X_train = (X_train - mu) / sd
X_test  = (X_test  - mu) / sd

def one_hot(y, K=10):
    return np.eye(K, dtype=np.float32)[y]

# ---------- init: He, because we use ReLU (Lesson 27) ----------
rng = np.random.default_rng(0)
sizes = [784, 256, 128, 10]
W = [rng.normal(0, np.sqrt(2.0 / sizes[i]), (sizes[i], sizes[i+1])).astype(np.float32)
     for i in range(3)]
b = [np.zeros(sizes[i+1], dtype=np.float32) for i in range(3)]

def forward(X):
    z1 = X  @ W[0] + b[0];  h1 = np.maximum(0, z1)
    z2 = h1 @ W[1] + b[1];  h2 = np.maximum(0, z2)
    z3 = h2 @ W[2] + b[2]                        # logits, no activation
    return z1, h1, z2, h2, z3

def softmax_ce(logits, Y):
    """Stable (Lesson 10). Returns loss and dL/dlogits."""
    z = logits - logits.max(axis=1, keepdims=True)
    e = np.exp(z)
    p = e / e.sum(axis=1, keepdims=True)
    N = logits.shape[0]
    loss = -np.log(p[np.arange(N), Y.argmax(1)] + 1e-12).mean()
    return loss, (p - Y) / N                     # the cancellation, batched

def backward(X, Y, cache):
    z1, h1, z2, h2, z3 = cache
    loss, dz3 = softmax_ce(z3, Y)

    dW2 = h2.T @ dz3;            db2 = dz3.sum(0)      # outer product / sum
    dh2 = dz3 @ W[2].T
    dz2 = dh2 * (z2 > 0)                               # ReLU mask

    dW1 = h1.T @ dz2;            db1 = dz2.sum(0)
    dh1 = dz2 @ W[1].T
    dz1 = dh1 * (z1 > 0)

    dW0 = X.T  @ dz1;            db0 = dz1.sum(0)
    return loss, [dW0, dW1, dW2], [db0, db1, db2]

# ---------- train ----------
lr, bs, epochs = 0.1, 128, 20
n = len(X_train)
Y_train = one_hot(y_train)

for ep in range(epochs):
    perm = rng.permutation(n)                    # shuffle EVERY epoch (Lesson 29)
    for i in range(0, n - bs + 1, bs):
        idx = perm[i:i+bs]
        xb, yb = X_train[idx], Y_train[idx]
        cache = forward(xb)
        loss, dW, db = backward(xb, yb, cache)
        for j in range(3):
            W[j] -= lr * dW[j]
            b[j] -= lr * db[j]

    acc = (forward(X_test)[-1].argmax(1) == y_test).mean()
    print(f"epoch {ep:2d}  loss {loss:.4f}  test acc {acc:.4f}")

The bugs you will actually hit here, in order

Pitfall checklist for this exact script
  1. Loss starts at 6+, not 2.303. Initialisation scale too large, or you forgot to divide pixels by 255.
  2. Loss is exactly 2.303 and never moves. Gradients not reaching the weights — check you are updating W[j] in place and not rebinding a copy.
  3. Accuracy stuck near 0.10. Labels misaligned with inputs after shuffling. Shuffle an index array, never the two arrays separately.
  4. NaN after a few hundred steps. LR too high, or a naive softmax. Both were covered on Day 10.
  5. ~88% and stops. You applied softmax inside forward and again inside the loss.
  6. Works with batch 128, breaks with batch 1. A reduction over the wrong axis, or dz.sum(0) collapsing a dimension you needed.

Look at what it learned

Reshape the columns of W[0] to 28×28 and plot 64 of them with a diverging colormap. You will see localised stroke detectors, edges at various orientations, and blob detectors — none of which you specified. Also plot the 20 most confidently wrong test images. They are mostly genuinely ambiguous digits, which tells you that you are close to the label-noise floor of the dataset.

Why this matters more than the accuracy number

Every framework you use for the next 76 days is doing exactly this, faster. When a PyTorch model misbehaves later, your mental model will be this script — and that is what lets you debug instead of guess.

Exercise

Add L2 regularisation (add \(\lambda W\) to each dW) and momentum (keep a velocity buffer per parameter). Then swap ReLU for sigmoid, keep everything else fixed, and watch accuracy collapse. Explain the collapse using the numbers from Lesson 23.
