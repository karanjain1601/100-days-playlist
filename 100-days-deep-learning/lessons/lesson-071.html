The idea in one sentence

Add a second state that is updated by addition rather than matrix multiplication, and let the network learn when to write to it, when to erase it and when to read from it.

\[ \begin{aligned} \mathbf f_t&=\sigma\big(W_f[\mathbf h_{t-1},\mathbf x_t]+\mathbf b_f\big) &&\text{forget: what to erase}\\[2pt] \mathbf i_t&=\sigma\big(W_i[\mathbf h_{t-1},\mathbf x_t]+\mathbf b_i\big) &&\text{input: how much to write}\\[2pt] \tilde{\mathbf c}_t&=\tanh\big(W_c[\mathbf h_{t-1},\mathbf x_t]+\mathbf b_c\big) &&\text{candidate: what to write}\\[2pt] \mathbf c_t&=\mathbf f_t\odot\mathbf c_{t-1}+\mathbf i_t\odot\tilde{\mathbf c}_t &&\text{the cell state update}\\[2pt] \mathbf o_t&=\sigma\big(W_o[\mathbf h_{t-1},\mathbf x_t]+\mathbf b_o\big) &&\text{output: what to expose}\\[2pt] \mathbf h_t&=\mathbf o_t\odot\tanh(\mathbf c_t) &&\text{the visible hidden state} \end{aligned} \]
Why the gradient survives

Differentiate the cell-state update along the direct path:

\[ \frac{\partial \mathbf c_t}{\partial \mathbf c_{t-1}}=\diag(\mathbf f_t) \qquad\Longrightarrow\qquad \frac{\partial \mathbf c_T}{\partial \mathbf c_k}=\prod_{t=k+1}^{T}\diag(\mathbf f_t) \]

Compare with the RNN's \(\prod W_{hh}\T\diag(\tanh')\). Here the product is of diagonal gate values the network controls, not of a fixed weight matrix. If the model decides a piece of information matters, it drives \(f_t\to1\) for that coordinate and the product stays at 1 for hundreds of steps — the gradient arrives undiminished. Note the structural resemblance to the residual connection in Lesson 52: both work by creating a path where the Jacobian is (close to) the identity. That is the same idea twice, discovered eighteen years apart.

Pitfall · the forget-gate bias, and why it must not start at zero

With \(\mathbf b_f=0\), the sigmoid outputs 0.5, so the cell state is halved at every step: after 20 steps only \(2^{-20}\approx10^{-6}\) survives. The LSTM begins life forgetting, and it has to climb out of that before it can learn anything long-range. Initialise \(\mathbf b_f\) to 1.0 (or 2.0) so gates start near 0.73–0.88 and the default behaviour is remembering. This is one of the highest-value one-line changes in the whole of recurrent modelling, it was documented in 2015, and PyTorch still does not do it for you — nn.LSTM initialises all biases uniformly and you must fix it yourself.

class LSTMCell(nn.Module):
    def __init__(self, d_in, d_hid):
        super().__init__()
        # one matrix producing all four gates at once: 1 GEMM instead of 4
        self.W = nn.Linear(d_in + d_hid, 4 * d_hid)
        self.d = d_hid
        with torch.no_grad():
            self.W.bias.zero_()
            self.W.bias[d_hid:2 * d_hid].fill_(1.0)      # forget-gate bias = 1

    def forward(self, x, state):
        h, c = state
        gates = self.W(torch.cat([h, x], dim=-1))
        i, f, g, o = gates.chunk(4, dim=-1)              # order: input, forget, candidate, output
        i, f, o = torch.sigmoid(i), torch.sigmoid(f), torch.sigmoid(o)
        c = f * c + i * torch.tanh(g)                    # the highway
        h = o * torch.tanh(c)
        return h, (h, c)

Parameter count: \(4\big((d_{\text{in}}+d_{\text{hid}})d_{\text{hid}}+d_{\text{hid}}\big)\) — four times a vanilla RNN cell, because there are four gate matrices. A 512-unit LSTM over 512-dimensional inputs holds about 2.1M parameters per layer.

What the gates actually learn

Karpathy's analysis of a character-level LSTM found individual cells that had learned interpretable jobs with no supervision: one tracked whether the model was inside quotation marks, another counted position within a line to predict newlines, another switched on inside brackets. These are exactly the long-range, discrete state variables that a vanilla RNN cannot hold, and finding them is convincing evidence that the cell-state highway is doing what the derivation says. Log your gate activations over a sequence; it is one of the more rewarding things you can plot.
