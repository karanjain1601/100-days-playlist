D097

Decomposing a Monolith

34 min · Phase 07 · Prereq: Day 96

What the lesson covers

  • Decomposition strategies (by business capability, by subdomain, by volatility, by team)
  • DDD essentials — ubiquitous language, entities, value objects, aggregates, bounded contexts, context maps
  • Identifying seams in legacy code
  • The strangler fig pattern with a real migration sequence
  • Branch-by-abstraction
  • Anti-corruption layers
  • Splitting the database (the hard part) and the order of operations
Whiteboard. a monolith decomposed into 6 bounded contexts, with the migration order justified.
HomeworkDraw bounded contexts for a system you know and mark the shared-data conflicts.
D098

Service Boundaries, Contracts & Versioning

30 min · Phase 07 · Prereq: Day 97

What the lesson covers

  • What belongs inside one service (data ownership, transactional boundary, team ownership)
  • The single-writer principle
  • API contracts as products
  • Consumer-driven contract testing (Pact) in CI
  • Backward/forward compatibility rules
  • Versioning and deprecation policy with timelines
  • Shared libraries vs shared services vs duplication
  • The DRY-vs-coupling tradeoff across service boundaries
Whiteboard. a breaking change rolled out safely across 4 consumers.
HomeworkWrite a contract test that fails on a breaking change before deploy.
D099

Inter-Service Communication & Anti-Patterns

30 min · Phase 07 · Prereq: Day 98

What the lesson covers

  • Sync vs async per interaction type
  • Choosing REST/gRPC/messaging per call
  • The aggregator, chained, and branch patterns
  • Chatty services and N+1 across the network
  • The distributed monolith (deploy-together services) and how to detect it
  • Shared database anti-pattern
  • Cyclic dependencies
  • Data duplication as a deliberate strategy
  • API composition vs CQRS read models for cross-service queries
Whiteboard. one page load requiring 47 internal calls, then redesigned to 4.
HomeworkAudit a call graph for cycles and synchronous chains deeper than 3.
D100

Resilience Patterns

34 min · Phase 07 · Prereq: Day 99

What the lesson covers

  • Timeouts (connect, read, total) and how to derive budget values
  • Retries — only for idempotent ops, with exponential backoff plus full jitter, retry budgets, and why retry amplification kills fleets
  • Circuit breakers (closed/open/half-open, thresholds, and tuning)
  • Bulkheads (thread pool and connection isolation)
  • Fallbacks and graceful degradation tiers
  • Hedged requests for tail latency
  • Deadline propagation across hops
  • Failing fast vs queuing
Whiteboard. a retry storm amplifying 1× traffic into 8×, then the same call path with budgets and breakers.
HomeworkAdd timeouts, jittered retries, and a circuit breaker; verify with fault injection.
D101

Service Mesh

32 min · Phase 07 · Prereq: Day 100

What the lesson covers

  • What a sidecar proxy takes over (mTLS, retries, timeouts, circuit breaking, routing, telemetry)
  • Control plane vs data plane
  • Istio vs Linkerd vs Consul Connect
  • Ambient/sidecar-less modes and why they emerged
  • Traffic shifting and mirroring at the mesh layer
  • Zero-trust networking and identity-based auth
  • The latency, memory, and complexity tax
  • When a mesh is premature
Whiteboard. a request path with and without sidecars, with added hops and latency labeled.
HomeworkConfigure mTLS plus a canary traffic split in a mesh.
D102

Containers & Images

30 min · Phase 07 · Prereq: Day 101

What the lesson covers

  • Namespaces, cgroups, union filesystems — what a container actually is
  • Images, layers, and caching
  • Multi-stage builds and image size discipline
  • The container lifecycle, PID 1 and signal handling
  • Resource requests vs limits, CPU throttling, and OOM kills
  • Container networking basics
  • Registries, tags, and immutable/digest-pinned deploys
  • Supply-chain scanning and SBOMs
Whiteboard. what happens between docker run and a running process, layer by layer.
HomeworkCut an image size by 70% with multi-stage builds and measure cold start.
D103

Kubernetes for System Designers

36 min · Phase 07 · Prereq: Day 102

What the lesson covers

  • Control plane components and the reconciliation loop
  • Pods, ReplicaSets, Deployments, rolling update mechanics, and maxSurge/maxUnavailable
  • Services, kube-proxy, Ingress, and Gateway API
  • ConfigMaps and Secrets
  • Probes (liveness/readiness/startup) done correctly
  • HPA, VPA, KEDA, and cluster autoscaler
  • StatefulSets, PVs, and running databases on K8s (and whether you should)
  • PodDisruptionBudgets, affinity, topology spread
  • Namespaces, quotas, and multi-tenancy
  • Operators and CRDs
Whiteboard. a deployment rolling out across 3 AZs while keeping quorum and zero downtime.
HomeworkDeploy a service with correct probes, PDB, HPA, and prove zero-downtime rollout.
D104

Serverless & Edge Compute

30 min · Phase 07 · Prereq: Day 103

What the lesson covers

  • FaaS execution model, cold starts (causes, measurement, mitigation), concurrency models, and provisioned concurrency
  • Limits (duration, payload, memory, /tmp) and how they constrain design
  • State, connections, and why RDBMS + Lambda needs a proxy
  • Event sources and fan-out
  • Step functions/durable workflows
  • Cost model and the crossover point vs containers
  • Edge functions and their constraints
  • When serverless is genuinely the right architecture

D105

Multi-Tenancy

32 min · Phase 07 · Prereq: Day 104

What the lesson covers

  • Tenancy models — silo, pool, bridge — with isolation/cost tradeoffs
  • Database strategies (DB per tenant, schema per tenant, shared tables with tenant_id) and migration implications
  • Noisy neighbor prevention with per-tenant quotas and rate limits
  • Tenant-aware sharding and routing
  • Per-tenant encryption and data residency
  • Onboarding/offboarding automation
  • Cost attribution per tenant
  • Tenant-level observability
Whiteboard. the same SaaS drawn in all three models with cost per tenant compared.

D106

API Patterns for Scale

32 min · Phase 07 · Prereq: Day 105

What the lesson covers

  • Idempotent APIs and the key lifecycle
  • Pagination at scale (cursor/keyset, stable ordering, deep-paging pain)
  • Bulk and batch endpoints with partial success semantics
  • Long-running operations (202 + status resource, polling, callbacks)
  • Webhooks — delivery guarantees, retries, signing, replay protection, consumer failure handling
  • API quotas and tiers
  • Response compression and payload trimming
  • API deprecation at scale
Whiteboard. a long-running export designed end to end, including client polling and expiry.
HomeworkImplement a signed, retrying webhook delivery system with a DLQ.
D107

Job Scheduling & Workflow Orchestration

32 min · Phase 07 · Prereq: Day 106

What the lesson covers

  • Cron's failure modes at scale (overlap, missed runs, single host)
  • Distributed schedulers, leader-based scheduling, and time-wheel/delayed-queue designs
  • At-least-once execution plus idempotency
  • Long-running workflows with Temporal/Cadence — event history, replay determinism, activities, retries, timers, signals
  • Human-in-the-loop steps
  • Scheduling millions of per-user timers
  • Job prioritization and fairness
Whiteboard. a "send reminder in 30 days" feature designed 3 ways at 100M users.
HomeworkBuild a delayed job system that survives a restart with no lost or duplicated jobs.
D108

26 min · Phase 07 · Prereq: Day 107

What the lesson covers

  • The 12-factor config principle and its limits
  • Static vs dynamic configuration, hot reload, and config-change-caused outages
  • Config as a deploy artifact vs a runtime service
  • Feature flag systems — targeting, gradual rollout, kill switches, flag debt and cleanup
  • Secrets management (Vault, KMS, cloud secret managers), rotation, and short-lived credentials
  • Environment parity
  • Config validation in CI
Whiteboard. a bad config change taking down production, then the same change guarded by staged rollout.
HomeworkAdd a kill switch to a risky code path and rehearse using it.
