D085

Sync vs Async Communication

26 min · Phase 06 · Prereq: Day 84

What the lesson covers

  • Request/response vs fire-and-forget vs request/async-response
  • Temporal coupling and how queues remove it
  • Latency perception vs actual work
  • When async makes things worse (debugging, ordering, consistency, user feedback)
  • The async decision checklist
  • Async response patterns (polling, webhooks, WebSocket push)
Whiteboard. the same checkout flow, synchronous vs event-driven, with failure behavior compared.
HomeworkConvert one synchronous call into an async flow and handle the failure path properly.

  • Push vs pull consumption
  • Acknowledgements, visibility timeouts, and redelivery
  • Message ordering guarantees and how partitions break global ordering
  • Priority queues
  • Delay/scheduled messages

  • Durability, persistence, and lazy queues

  • Topics, partitions, offsets, and ordering guarantees per partition
  • Partition assignment and keying strategy (and hot partitions)
